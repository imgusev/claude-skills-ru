# Генератор целевой страницы { #landing-page-generator }

Создавайте целевые страницы с высокой конверсией на основе описания продукта. Выводите полные компоненты Next.js /React с несколькими вариантами разделов, проверенными фреймворками копирования, SEO-оптимизацией и шаблонами, ориентированными на производительность. Не lorem ipsum — фактическая копия, которая преобразуется.

**Цель:** LCP < 1 с · CLS < 0,1 · FID < 100 мс  
** Выходные данные:** Компоненты TSX + стили попутного ветра + SEO-мета + варианты копирования

---

## Основные возможности { #core-capabilities }

- 5 вариантов раздела героев (центрированный, разделенный, градиентный, видео-bg, минимальный)
- Разделы функций (сетка, чередующиеся, карточки со значками)
- Таблицы цен (2-4 уровня со списками функций и переключателями)
- Часто задаваемые вопросы аккордеон с разметкой схемы
- Отзывы (сетка, карусель, одиночные кавычки)
- Разделы CTA (баннер, полностраничный, встроенный)
- Нижний колонтитул (простой, мега, минимальный)
- 4 стиля дизайна с наборами классов попутного ветра

## Генерация воркфлоу { #generation-workflow }

Выполните следующие действия по порядку для каждого запроса на целевую страницу:

1. ** Соберите исходные данные** — соберите название продукта, слоган, аудиторию, болевую точку, ключевую выгоду, уровни ценообразования, стиль дизайна и скопируйте фреймворк, используя приведенный ниже формат триггера. Запрашивайте только отсутствующие поля.
2. ** Проанализируйте голос бренда ** (рекомендуется) — если у пользователя есть существующий контент бренда (копия веб-сайта, записи в блоге, маркетинговые материалы), прогоните его через `marketing-skill/skills/content-production/scripts/brand_voice_analyzer.py` чтобы получить голосовой профиль (формальность, тон, перспектива). Используйте профиль для определения стиля дизайна и выбора фреймворка копирования:
   - формальный + профессиональный → **корпоративный** стиль, **AIDA** фреймворк
   - повседневный + дружелюбный → **смелый-стиль стартапа**, **БАБ** фреймворк
   - профессиональный + авторитетный → **стиль dark-saas**, **PAS** фреймворк
   - повседневный + разговорный → **чистый-минимальный** стиль, **БАБСКИЙ** фреймворк
3. **Выберите стиль дизайна** — сопоставьте выбор пользователя (или сделайте вывод на основе анализа голоса бренда) с одним из четырех наборов классов Tailwind в справочнике по стилю дизайна.
4. **Примените фреймворк копирования** — напишите все заголовки и основную часть текста, используя выбранный фреймворк (PAS / AIDA / BAB) перед созданием компонентов. Во всем соблюдайте официальность и тональность голосового профиля.
5. ** Создайте разделы по порядку ** — Герой → Характеристики → Цены → Часто задаваемые вопросы → Отзывы → CTA → Нижний колонтитул. Пропустите разделы, не относящиеся к продукту.
6. ** Проверка по чек—листу SEO** - просмотрите каждый элемент в чек-листе SEO перед выводом окончательного кода. Исправьте все пробелы в строке.
7. ** Вывод конечных компонентов ** — предоставление полных, готовых к копированию и вставке файлов TSX со всеми классами Tailwind, SEO-метаданными и структурированными данными.

## Копирование фреймворков { #copy-frameworks }

**PAS (Проблема → Агитация → решение)**
- H1: Болезненное состояние, в котором они находятся
- Саб: Что произойдет, если они это не исправят
- CTA: Что вы предлагаете
- *Пример — H1: * "Ваша команда тратит 3 часа в день на составление отчетов вручную" / * Вспомогательный: * "Каждый час, потраченный на электронные таблицы, - это час без закрытия сделок. Ваши конкуренты уже автоматизированы". / *CTA:* "Автоматизируйте свои отчеты за 10 минут →"

**АИДА (Внимание → Интерес → Желание → Действие)**
- H1: Смелое заявление, привлекающее внимание → Подзаголовок: Интересный факт или выгода → Особенности: Подтверждающие моменты, вызывающие желание → CTA: Четкие действия

**БАБ (до → после → Мост)**
- H1: "[Предшествующее состояние] → [После состояния]" → Sub: "Вот как [продукт] устраняет разрыв" → Особенности: Как это работает (the bridge)

## Другие модели сечений { #other-section-patterns }

### Раздел характеристик (чередующийся) { #feature-section-alternating }

Карта поверх `features` массив с `{ title, description, image, badge }`. Переключите направление компоновки с помощью `i % 2 === 1 ? "lg:flex-row-reverse" : ""`. Используйте `<Image>` с явным `width`/`height` и `rounded-2xl shadow-xl`. Завернуть в `<section className="py-24">` с `max-w-6xl` контейнер.

### Таблица ценообразования { #pricing-table }

Карта поверх `plans` массив с `{ name, price, description, features[], cta, highlighted }`. Выделенный план получает `border-2 border-violet-500 bg-violet-950/50 ring-4 ring-violet-500/20`; другие получают `border border-gray-800 bg-gray-900`. Рендеринг `null` цена указана как "Индивидуальная". Использование `<Check>` значок для каждой строки объектов. Планировка: `grid gap-8 lg:grid-cols-3`.

### Часто задаваемые вопросы с разметкой схемы { #faq-with-schema-markup }

Вводить `FAQPage` JSON-LD через `<script type="application/ld+json" dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }} />` внутри секции. Часто задаваемые вопросы по карте с `{ q, a }` в тень `<Accordion>` с `type="single" collapsible`. Контейнер: `max-w-3xl`.

### Отзывы, CTA, Нижний колонтитул { #testimonials-cta-footer }

- ** Отзывы:** Сетка (`grid-cols-1 md:grid-cols-3`) или блок героя в одиночных кавычках с аватаром, именем, ролью и текстом цитаты.
- **Баннер CTA:** Раздел во всю ширину с заголовком, подзаголовком и двумя кнопками (основная + призрачная). Добавьте сигналы доверия (гарантия возврата денег, полоса с логотипом) непосредственно ниже.
- ** Нижний колонтитул:** Логотип + навигационные колонки + социальные ссылки + юридические. Использование `border-t border-gray-800` разделитель.

## Чек-лист по SEO-поиску SEO SEO { #seo-checklist }

- [ ] `<title>` тег: основное ключевое слово + бренд (50-60 символов)
- [ ] Мета-описание: выгода + CTA (150-160 символов)
- [ ] Изображение OG: 1200×630 пикселей с названием продукта и слоганом
- [ ] H1: по одному на страницу, включает основное ключевое слово
- [ ] Структурированные данные: страница часто задаваемых вопросов, схема продукта или организации
- [ ] Канонический набор URL-адресов
- [ ] Изображение с измененным текстом на всех `<Image>` компоненты
- [ ] robots.txt и sitemap.xml сконфигурированный
- [ ] Основные показатели работы сети: LCP < 1s, CLS < 0,1
- [ ] Присутствует мета-тег мобильного видового экрана
- [ ] Внутренняя ссылка на цены и документы

> ** Шаг проверки:** Перед выводом окончательного кода убедитесь, что выполнены все пункты приведенного выше чек-листа. Исправьте все пробелы в строке — не пропускайте элементы.

## Целевые показатели эффективности { #performance-targets }

| Метрика | Цель | Техника |
|---|---|---|
| LCP | < 1 с | Предварительно загрузите изображение героя, используйте `priority` на следующем/изображении |
| CLS | < 0.1 | Установите явную ширину/высоту для всех изображений |
| FID/INP | < 100 мс | Отложите некритичный JS, используйте `loading="lazy"` |
| TTFB | < 200 мс | Используйте ISR или статическую генерацию для целевых страниц |
| Связка | < 100 КБАЙТ JS | Аудит с `@next/bundle-analyzer` |

## Распространенные подводные камни { #common-pitfalls }

- Изображение героя не загружено предварительно — добавить `priority` подпорка к первому `<Image>`
- Отсутствующие мобильные точки останова — всегда разрабатывайте мобильные устройства в первую очередь с `sm:` префиксы
- Копия CTA слишком расплывчата — "Начать" заменяет "Узнать больше"; "Начать бесплатную пробную версию" заменяет "Зарегистрироваться".
- На странице цен отсутствуют сигналы доверия — добавьте гарантию возврата денег и отзывы рядом с CTA
- Нет CTA выше сгиба на мобильном устройстве - убедитесь, что кнопка видна без прокрутки на экране просмотра размером 375 пикселей
