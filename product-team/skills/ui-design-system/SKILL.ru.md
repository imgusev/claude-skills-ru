## Воркфлоу { #workflows }

### Воркфлоу 1: Генерируем дизайнерские токены { #workflow-1-generate-design-tokens }

** Ситуация: ** У вас есть фирменный цвет, и вам нужна полная система маркеров дизайна.

**Шаги:**

1. **Определить цвет и стиль бренда**
   - Основной цвет бренда (шестнадцатеричный формат)
   - Предпочтения в стиле: `modern` | `classic` | `playful`

2. **Генерировать токены с помощью скрипта**
   ```bash
   python scripts/design_token_generator.py "#0066CC" modern json
   ```

3. **Ревью сгенерированных категорий**
   - Цвета: первичный, вторичный, нейтральный, семантический, поверхностный
   - Типография: Семейство шрифтов, размер шрифта, вес шрифта, высота строки
   - Интервал: 8-дюймовая шкала на основе сетки (0-64)
   - Границы: радиус, ширина
   - Тени: отсутствуют до 2xl
   - Анимация: продолжительность, ослабление
   - Контрольные точки: от xs до 2xl

4. **Экспорт в целевом формате**
   ```bash
   # CSS custom properties
   python scripts/design_token_generator.py "#0066CC" modern css > design-tokens.css

   # SCSS variables
   python scripts/design_token_generator.py "#0066CC" modern scss > _design-tokens.scss

   # JSON for Figma/tooling
   python scripts/design_token_generator.py "#0066CC" modern json > design-tokens.json
   ```

5. **Проверка доступности**
   - Проверьте, соответствует ли цветовой контраст стандарту WCAG AA (обычный 4,5:1, крупный текст 3:1)
   - Убедитесь, что для семантических цветов определены контрастные цвета

### Воркфлоу 2: Создание компонентной системы { #workflow-2-create-component-system }

** Ситуация:** Вам нужно структурировать библиотеку компонентов, используя токены проектирования.

**Шаги:**

1. **Определить иерархию компонентов**
   - Атомы: Кнопка, ввод, Значок, метка, Бейдж
   - Молекулы: Поле формы, панель поиска, карточка, список элементов
   - Организмы: Верхний, нижний колонтитул, данные, модальный
   - Шаблоны: DashboardLayout, AuthLayout

2. **Сопоставление токенов с компонентами**

   | Компонент | Используемые токены |
   |-----------|-------------|
   | Кнопка | цвета, размер, границы, тени, типографика |
   | Входной сигнал | цвета, размер, границы, интервалы |
   | Карточка | цвета, границы, тени, интервалы |
   | Модальный | цвета, тени, интервал, z-индекс, анимация |

3. **Определение вариантных шаблонов**

   Варианты размеров:
   ```
   sm: height 32px, paddingX 12px, fontSize 14px
   md: height 40px, paddingX 16px, fontSize 16px
   lg: height 48px, paddingX 20px, fontSize 18px
   ```

   Варианты цвета:
   ```
   primary: background primary-500, text white
   secondary: background neutral-100, text neutral-900
   ghost: background transparent, text neutral-700
   ```

4. **API компонента документа**
   - Интерфейс Props с типами
   - Возможные варианты
   - Обработка состояния (наведение курсора, активен, фокус, отключен)
   - Требования к доступности

5. **Ссылка:** Смотрите `references/component-architecture.md`

### Воркфлоу 3: Адаптивный дизайн { #workflow-3-responsive-design }

** Ситуация:** Вам нужны точки останова, плавная типография или адаптивный интервал.

**Шаги:**

1. **Определение точек останова**

   | Имя | Ширина | Цель |
   |------|-------|--------|
   | xs | 0 | Маленькие телефоны |
   | см | 480 пикселей | Большие телефоны |
   | доктор медицинских наук | 640 пикселей | Таблетки |
   | lg | 768 пикселей | Маленькие ноутбуки |
   | xl | 1024 пикселя | Рабочие столы |
   | 2xl | 1280 пикселей | Большие экраны |

2. **Рассчитать плавную типографику**

   Формула: `clamp(min, preferred, max)`

   ```css
   /* 16px to 24px between 320px and 1200px viewport */
   font-size: clamp(1rem, 0.5rem + 2vw, 1.5rem);
   ```

   Предварительно рассчитанные шкалы:
   ```css
   --fluid-h1: clamp(2rem, 1rem + 3.6vw, 4rem);
   --fluid-h2: clamp(1.75rem, 1rem + 2.3vw, 3rem);
   --fluid-h3: clamp(1.5rem, 1rem + 1.4vw, 2.25rem);
   --fluid-body: clamp(1rem, 0.95rem + 0.2vw, 1.125rem);
   ```

3. **Настройка адаптивного интервала**

   | Токен | Мобильный | Таблетка | Рабочий стол |
   |-------|--------|--------|---------|
   | --космос-md | 12 пикселей | 16 пикселей | 16 пикселей |
   | --космос-lg | 16 пикселей | 24 пикселя | 32 пикселя |
   | --пространство-xl | 24 пикселя | 32 пикселя | 48 пикселей |
   | --пространство-секция | 48 пикселей | 80 пикселей | 120 пикселей |

4. **Ссылка:** Смотрите `references/responsive-calculations.md`

### Воркфлоу 4: Хэндофф разработчика { #workflow-4-developer-handoff }

** Ситуация:** Вам нужно передать дизайнерские токены команде разработчиков.

**Шаги:**

1. **Экспорт токенов в требуемые форматы**
   ```bash
   # For CSS projects
   python scripts/design_token_generator.py "#0066CC" modern css

   # For SCSS projects
   python scripts/design_token_generator.py "#0066CC" modern scss

   # For JavaScript/TypeScript
   python scripts/design_token_generator.py "#0066CC" modern json
   ```

2. **Подготовить интеграцию с фреймворком**

   **Переменные React + CSS:**
   ```tsx
   import './design-tokens.css';

   <button className="btn btn-primary">Click</button>
   ```

   **Настройка попутного ветра:**
   ```javascript
   const tokens = require('./design-tokens.json');

   module.exports = {
     theme: {
       colors: tokens.colors,
       fontFamily: tokens.typography.fontFamily
     }
   };
   ```

   **стилизованные компоненты:**
   ```typescript
   import tokens from './design-tokens.json';

   const Button = styled.button`
     background: ${tokens.colors.primary['500']};
     padding: ${tokens.spacing['2']} ${tokens.spacing['4']};
   `;
   ```

3. **Синхронизация с Figma**
   - Установите плагин Tokens Studio
   - Импорт design-tokens.json
   - Токены автоматически синхронизируются со стилями Figma

4. **Чек-лист для хэндоффа в режиме "Контрольная ведомость"offoff**
   - [ ] Файлы токенов добавлены в проект
   - [ ] Сконфигурирован пайплайн сборки
   - [ ] Импортированные переменные темы/CSS
   - [ ] Библиотека компонентов выровнена
   - [ ] Сгенерированная документация

5. **Ссылка:** Смотрите `references/developer-handoff.md`

## Ссылка на инструмент { #tool-reference }

### design_token_generator.py { #design_token_generatorpy }

Генерирует полную систему дизайнерских токенов на основе фирменного цвета.

| Аргумент | Ценности | Значение по умолчанию | Описание |
|----------|--------|---------|-------------|
| фирменный цвет | Шестигранный цвет | #0066CC | Основной цвет бренда |
| стиль | современный, классический, игривый | современный | Предустановленный стиль дизайна |
| формат | json, css, scss, сводка | json | Выходной формат |

**Примеры:**

```bash
# Generate JSON tokens (default)
python scripts/design_token_generator.py "#0066CC"

# Classic style with CSS output
python scripts/design_token_generator.py "#8B4513" classic css

# Playful style summary view
python scripts/design_token_generator.py "#FF6B6B" playful summary
```

**Категории выходных данных:**

| Категория | Описание | Ключевые значения |
|----------|-------------|------------|
| цвета | Цветовые палитры | первичный, вторичный, нейтральный, семантический, поверхностный |
| типография | Система шрифтов | Семейство шрифтов, размер шрифта, вес шрифта, высота строки |
| расстояние | сетка 8pt | шкала 0-64, семантическая (xs-3xl) |
| определение размера | Размеры компонентов | контейнер, кнопка, ввод, значок |
| границы | Граничные значения | радиус (для каждого стиля), ширина |
| тени | Стили теней | нет до 2xl, внутренний |
| анимация | Знаки движения | продолжительность, ослабление, ключевые кадры |
| точки останова | Отзывчивый | xs, sm, md, lg, xl, 2xl |
| z-индекс | Многослойная система | база через уведомление |

## Чек-лист для проверки подлинности (#) { #validation-checklist }

### Генерация токена { #token-generation }
- [ ] Фирменный цвет представлен в шестнадцатеричном формате
- [ ] Стиль соответствует требованиям проекта
- [ ] Сгенерированы все категории токенов
- [ ] Семантические цвета включают значения контрастности

### Компонентная система { #component-system }
- [ ] Реализованы все размеры (sm, md, lg)
- [ ] Реализованы все варианты (первичный, вторичный, призрачный)
- [ ] Все состояния работают (наведение курсора, активен, фокус, отключен)
- [ ] Использует только дизайнерские токены (без жестко заданных значений)

### Доступность { #accessibility }
- [ ] Цветовой контраст соответствует стандарту WCAG AA
- [ ] Видны индикаторы фокусировки
- [ ] Коснитесь целей размером ≥ 44×44 пикселей
- [ ] Используемые семантические элементы HTML

### Хэндофф разработчика { #developer-handoff }
- [ ] Токены, экспортированные в требуемом формате
- [ ] Интеграция с фреймворком задокументирована
- [ ] Синхронизирован инструмент проектирования
- [ ] Документация по компонентам завершена
