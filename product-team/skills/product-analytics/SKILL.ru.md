# Аналитика продуктов { #product-analytics }

Определяйте, отслеживайте и интерпретируйте показатели продукта на этапах обнаружения, роста и зрелости продукта.

## Когда использовать { #when-to-use }

Используйте этот скилл для:
- Выбор фреймворка метрики (AARRR, Полярная звезда, СЕРДЦЕ)
- Определение ключевых показателей эффективности по стадиям производства продукта (pre-PMF, рост, зрелость)
- Дизайн дашборда и иерархия показателей
- Анализ когорты и удержания
- Внедрение функций и интерпретация воронки

## Воркфлоу { #workflow }

1. Выберите фреймворк метрики
- AARRR для обеспечения видимости циклов роста и воронки
- Полярная звезда для межфункционального стратегического согласования
- СЕРДЦЕ для измерения качества UX и пользовательского опыта

2. Определите ключевые показатели эффективности, соответствующие этапу
- Pre-PMF: активация, раннее удержание, качественный успех
- Рост: эффективность приобретения, расширение, скорость конверсии
- Зрелый: глубина удержания, качество выручки, операционная эффективность

3. Слои дизайна дашборда
- Исполнительный уровень: 5-7 показателей направленности
- Уровень работоспособности продукта: приобретение, активация, удержание, вовлечение
- Слой объектов: внедрение, глубина, повторное использование, корреляция результатов

4. Провести анализ когорты + удержания
- Сегментировать по когорте подписчиков или когорте показа функций
- Сравнивайте кривые удержания, а не одноточечные снимки
- Определите точки перегиба вокруг онбординга и момента первого значения

5. Интерпретировать и действовать
- Свяжите движение показателей с изменениями продукта и сроками выпуска
- Отличать сигнал от шума, используя контекст "период за периодом"
- Предложите одно четкое действие по продукту для каждого основного показателя риска/opportunity

## Поэтапное определение ключевых показателей эффективности { #kpi-guidance-by-stage }

### Предварительная ПМФ { #pre-pmf }
- Скорость активации
- Задержка на 1 неделю
- Время до первого значения
- Оценка соответствия проблемы и решения результатам собеседования

### Рост { #growth }
- Конверсия воронки по этапам
- Ежемесячно удерживаемые пользователи
- Внедрение функций среди новых когорт
- Показатели прокси-сервера расширения/увеличения продаж

### Зрелый { #mature }
- Показатели продукта, согласованные с сохранением чистой выручки
- Доля опытных пользователей и глубина использования
- Показатели риска оттока по сегментам
- Показатели надежности и поддержки-отклонение продукта

## Принципы проектирования дашбордов { #dashboard-design-principles }

- Показывайте тенденции, а не изолированные точечные оценки.
- Держите одного владельца на каждый ключевой показатель.
- Сопоставьте каждый ключевой показатель с целью, порогом и правилом принятия решения.
- По умолчанию используйте когортные и сегментные фильтры.
- Предпочитайте сопоставимые временные интервалы (неделя против недели, месяц против месяца).

Видишь:
- `references/metrics-frameworks.md`
- `references/dashboard-templates.md`

## Метод когортного анализа { #cohort-analysis-method }

1. Определите событие привязки когорты (регистрация, активация, первая покупка).
2. Определите сохраняемое поведение (активный день, ключевое действие, повторный сеанс).
3. Составьте матрицу удержания по неделям когорты/month и возрастной период.
4. Сравните форму кривой в разных когортах.
5. Отмечайте ранние точки высадки и исследуйте трения в пути.

## Интерпретация кривой удержания { #retention-curve-interpretation }

- Резкое раннее падение, низкое плато: несоответствие онбордингу или слабое начальное значение.
- Умеренный спад, стабильное плато: здоровая основная аудитория с предсказуемым оттоком.
- Выравнивание на низком уровне: продукт используется время от времени, пересмотрите показатель ценности.
- Улучшение новых когорт: Онбординг или улучшения позиционирования работают.

## Анти-паттерны { #anti-patterns }

| Анти-паттерн | Исправить |
|---|---|
| ** Показатели тщеславия ** — отслеживание просмотров страниц или общего количества регистраций без контекста активации | Всегда сопоставляйте показатели приобретения с частотой активации и удержания |
| **Одноточечное удержание** — отчет "30-дневное удержание составляет 20%" | Сравнивайте кривые удержания в разных группах, а не изолированные снимки |
| **Перегрузка дашбордов** — 30+ показатели на одном экране | Исполнительный уровень: 5-7 показателей. Векторный слой: только для каждого объекта |
| **Нет правила принятия решений ** — отслеживание ключевых показателей эффективности без порогового значения или плана действий | Каждому KPI нужны: цель, порог, владелец и "если ниже X, то Y". |
| **Усреднение по сегментам** — представление смешанных показателей, скрывающих различия между сегментами | Всегда сегментируйте по когорте, уровню плана, каналу или географии |
| ** Игнорирование сезонности** — сравнение этой недели с прошлой без корректировки | Используйте период за периодом в контексте того же периода прошлого года |

## Оснастка { #tooling }

### `scripts/metrics_calculator.py` { #scriptsmetrics_calculatorpy }

Утилита CLI для анализа удержания, когорты и воронки на основе данных CSV. Поддерживает вывод текста и JSON.

```bash
# Retention analysis
python3 scripts/metrics_calculator.py retention events.csv
python3 scripts/metrics_calculator.py retention events.csv --format json

# Cohort matrix
python3 scripts/metrics_calculator.py cohort events.csv --cohort-grain month
python3 scripts/metrics_calculator.py cohort events.csv --cohort-grain week --format json

# Funnel conversion
python3 scripts/metrics_calculator.py funnel funnel.csv --stages visit,signup,activate,pay
python3 scripts/metrics_calculator.py funnel funnel.csv --stages visit,signup,activate,pay --format json
```

**Формат CSV для хранения/cohort:**
```csv
user_id,cohort_date,activity_date
u001,2026-01-01,2026-01-01
u001,2026-01-01,2026-01-03
u002,2026-01-02,2026-01-02
```

**Формат CSV для воронки:**
```csv
user_id,stage
u001,visit
u001,signup
u001,activate
u002,visit
u002,signup
```
