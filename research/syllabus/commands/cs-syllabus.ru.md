# /cs:syllabus — Список дополнительного чтения курса { #cssyllabus--course-supplementary-reading-list }

**Команда:** `/cs:syllabus <syllabus-file-or-paste>`

Тот `cs-syllabus` персона создает `.docx` список для чтения недавних ревью-исследований, прошедших экспертную оценку, по каждому разделу курса.

## Когда запускать { #when-to-run }

- Добавление дополнительных чтений к существующему курсу
- Обновление учебной программы с учетом текущих исследований
- Проверка последних достижений в вашей области для планирования курса
- Даже случайные упоминания, когда прилагается учебная программа

## Принудительный прием пищи (3 вопроса, по одному за раз) { #forcing-intake-3-questions-one-at-a-time }

| Вопрос | Спрашивает | Примечания |
|---|---|---|
| Вопрос 1 | Ввод программы: путь к файлу / вставленное содержимое / изображение | отказывается от пропущенной учебной программы |
| Q2 | Аудитория курса: старшекурсники-вводные / старшекурсники-продвинутые / выпускники-магистры / выпускники-докторанты / профессиональные / смешанные | приводит к краткому изложению жаргона + обсуждению-сложность вопроса |
| Вопрос 3 | Диапазон лет: 1 / 2 / 5 годы | приводы `year_min` при каждом поиске консенсуса; по умолчанию 2 |

## Что Вы получаете { #what-you-get }

```
reading_list_<course-slug>_<YYYY-MM-DD>.docx

Structure:
- Title page (course name, subtitle, date)
- Introduction (with Consensus app link)
- Course Learning Outcomes (boxed section)
- Sections (6-12, from grouping):
    Each section = numbered papers, each with:
      - Clickable hyperlinked title
      - Author / journal / year (italic)
      - Summary (plain language, audience-calibrated)
      - Discussion Question (Bloom higher-order, tied to learning outcome)
- Footer (generation metadata)
```

## Контрольная точка группировки (после этапа 2) { #grouping-checkpoint-after-phase-2 }

После разбора учебного плана скилл ** останавливается** с промптом принудительных опций:

```
Proposed sections: [list with item counts]. Pick one:
  1. Looks good — proceed with these sections
  2. Merge sections [X] and [Y]
  3. Split section [X] into two
  4. Add a section for [topic]
  5. Remove section [X]
```

Это последний дешевый момент скорректировать курс до того, как будет израсходован бюджет поиска. **Отказывается запускать фазу 3 без явного выбора пользователя.**

## Дисциплина { #discipline }

- **Один прием Q за оборот.** Никогда не связывайте.
- ** Остановка на контрольной точке группировки.** Нет фазы 3 без пользователя.
- **Последовательный консенсус.** 1 вопрос/sec.
- **Ткачество в прикладной области ** — ищите "ферментативная кинетика пищевой промышленности", а не просто "ферментативная кинетика". Значительно повышает актуальность статьи.
- ** Резюме, рассчитанное на аудиторию ** - вводная часть для старшекурсников определяет каждый термин; степень магистра предполагает свободное владение техническими науками.
- ** Задавайте вопросы для обсуждения более высокого порядка ** — применяйте / анализируйте / оценивайте. НЕ припоминаю ("что нашли авторы?").
- **Исходная дисциплина** — только согласованные результаты сессии. Учебные знания помечены.
- ** Отслеживание по трем счетам** — отправлено / получено / процитировано.
- ** Встроенный генератор JS DOCX** — не вставляйте 300 строк кода макета.

| ✅ Хороший | ❌ Плохо |
|---|---|

## Воркфлоу { #workflow }

```bash
# Phase 0 intake (Q1-Q3)
python ../skills/syllabus/scripts/citation_tracker.py --action start --session NAME

# Phase 1 parse (PDF/DOCX/text/image-appropriate reader)
# Phase 2 group + CHECKPOINT (wait for user)
python ../skills/syllabus/scripts/topic_grouper.py --topics-file /tmp/topics.json

# Phase 3 search (sequential Consensus 1 q/sec, applied-domain weaving)
# Phase 4 write summaries + discussion questions
python ../skills/syllabus/scripts/discussion_question_validator.py --questions-file /tmp/qs.json

# Phase 5 generate .docx via bundled script
node ../skills/syllabus/scripts/generate_reading_list.js \
  --input /tmp/data.json \
  --output /path/to/reading_list_<course>_<date>.docx

# Phase 6 deliver
python ../skills/syllabus/scripts/citation_tracker.py --action close --session NAME
```

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Распараллеливание согласованных вызовов (ограничение скорости)
- Поиск по темам без учета прикладной области (низкая релевантность)
- Заполнение разделов сфабрикованными записями при достижении консенсуса тонким
- Общие вопросы для обсуждения ("Что обнаружили авторы?")
- Насыщенные жаргоном резюме, неподходящие для аудитории курса
- Пропуск шага группирования и подтверждения
- Усечение согласованных URL-адресов в гиперссылках
- Встраивание 300 строк JavaScript-кода поколения docx в тело скилла
