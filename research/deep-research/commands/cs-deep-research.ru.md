# /cs:deep-research — Дисциплинированное метаисследование { #csdeep-research--disciplined-meta-research }

**Команда:** `/cs:deep-research <question>`

Тот `cs-deep-research` персона превращает "исследуй это" в проверяемое, многократно используемое исследование — воркфлоу, к которому нужно обратиться, когда получаешь неправильный ответ, стоит дороже, чем токены, потраченные на то, чтобы получить правильный ответ.

## Когда запускать { #when-to-run }

- Некачественный ответ обходится дорого: стратегия, бизнес-план, отчет или основа для статьи.
- Сравнение N институтов / продуктов / методов /рынков с обоснованной аргументацией.
- Проверка гипотезы или необратимого решения на основе внешних данных.
- Метаисследования: "понять, как работает X", "составить карту ландшафта Y".

## Когда не следует бегать { #when-not-to-run }

- Быстрая проверка фактов → отвечайте напрямую.
- Структурированный 12-мерный рейтинг конкурентов → `competitive-teardown`.
- Быстрый обзор тем, где риск принятия решения невелик → ** исследовательский маршрутизатор ** (`/cs:research`).

## Что Вы получаете { #what-you-get }

1. **Переосмысление** — вопрос переписан с учетом реального решения + 2-4 фальсифицируемые гипотезы.
2. **`plan.md`** — жанр, стратегия поиска поставщиков, оппозиционные запросы, реестр рисков, критерии остановки.
3. **Параллельный поиск** — саб-агенты распределены по каналам; каждый источник сохраняется в `sources/NN_slug.md` с дословными цитатами + оценками достоверности / новизны / предвзятости.
4. ** Триангулированный синтез** — каждый тезис подкрепляется >=3 независимыми источниками разного типа (или помеченными как "недостаточные доказательства"), плюс обязательное состязательное голосование.
5. ** Папка для повторного использования** — `sources.csv`, `findings/`, окончательный отчет и `refresh_targets.md` для дельта-обновлений позже.

## Фразы-триггеры (автоматический вызов без /cs:) { #trigger-phrases-auto-invoke-without-cs }

- "глубокое исследование по [тема]" / "совершите глубокое погружение в [тема]"
- "исследуйте это тщательно" / "исследование с высокими ставками"
- "сравнить [N вариантов] и приведите мне обоснованные доводы"
- "подтвердите эту гипотезу с помощью внешних данных"

## Дисциплина { #discipline }

- **Никаких сфабрикованных цитат** — пустая выборка = пустая претензия.
- **Обязательная триангуляция** — < 3 независимых источника разного типа → "недостаточно доказательств", а не факт.
- **Требуется состязательный проход ** на среднем/deep расследования.
- **Параллельные саб-агенты** — никогда не подключаются последовательно на этапе поиска.
- **Сохраняется в файлах** — значением повторного использования является папка, а не расшифровка.

## Условия остановки { #stop-conditions }

- Написанный отчет + каждый тезис триангулирован или помечен флажком + `refresh_targets.md` испущено → выполнено.
- На `update <slug>` выполнить: создать дельту в `diffs/` вместо того, чтобы повторять все расследование заново.
