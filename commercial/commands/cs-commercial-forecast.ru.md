# /cs:реклама-прогноз — Предварительные заказы + совокупный доход + уверенность в воронке { #cscommercial-forecast--forward-bookings--cohort-arr--funnel-confidence }

Запустите `commercial-forecaster` скилл на основе этого ввода:

**$АРГУМЕНТЫ**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`bookings_forecaster.py`** — Прогноз бронирований на основе поэтапной конверсии с использованием взвешенных показателей за последние 4 квартала (самый последний более тяжелый). Выводит фиксацию / наилучший вариант / только для канала. Отраслевая настройка `--profile {saas,api,enterprise-software,marketplace,services}`.

2. **`cohort_arr_projector.py`** — Прогноз NRR + GRR по когорте приобретения. Выявляет "дырявые" когорты до того, как они появятся в сводном номере NRR.

3. **`funnel_confidence_scorer.py`** — Доверительный интервал для каждого этапа: насколько стабилен коэффициент конверсии q по сравнению с q? Высокая дисперсия = прогноз с низкой степенью достоверности.

## Жесткое правило { #hard-rule }

** Предположение о конверсии ВСЕГДА появлялось явно.** Прогнозы без раскрытых предположений являются театральными. В выходных данных указывается используемый коэффициент конверсии и окно данных, на котором он основан.

## Отличный от { #distinct-from }

- `finance/financial-analysis` — **закрыть + сообщить** (оглядываясь назад). Commercial-forecaster - это **прямой** коммерческий пайплайн.
- `c-level-advisor/cfo-advisor` — стратегическое финансовое планирование. Коммерческий прогнозист - это тактический прогноз на квартал.
- `c-level-advisor/cro-advisor` — стратегический CRO. Коммерческий прогнозист передает суждения CRO.
- Родной брат `pricing-strategist` — устанавливает цены; коммерческий прогнозист прогнозирует выручку по этим ценам.
