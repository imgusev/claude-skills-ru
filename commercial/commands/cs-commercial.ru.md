# /cs:commercial — Коммерческий маршрутизатор { #cscommercial--commercial-router }

Используйте `cs-commercial-orchestrator` агент + `commercial-skills` скилл оркестратора для обработки этого запроса:

**$ARGUMENTS**

## Протокол маршрутизации { #routing-protocol }

1. Классифицируйте запрос по семи коммерческим полосам:
   - **ЦЕНООБРАЗОВАНИЕ** — модель ценообразования, упаковка, WTP, ценообразование по стоимости → `pricing-strategist`
   - **СДЕЛКА** — ревью сделки, утверждение скидки, красная линия, маржа → `deal-desk`
   - **ПАРТНЕРСТВО** — партнерский уровень, совместный GTM, revshare → `partnerships-architect`
   - **CHANNEL_ECON** — сочетание каналов, стоимость обслуживания, прямой эфир и партнер → `channel-economics`
   - **ПОЛИТИКА** — матрица скидок, коммерческая политика, фреймворк исключений → `commercial-policy`
   - **ЗАПРОС предложения** — ЗАПРОС предложения/RFI/RFQ/security анкета → `rfp-responder`
   - **ПРОГНОЗ** — количество бронирований, предварительная оценка, прогноз NRR → `commercial-forecaster`

2. Наивысший балл на дорожке ≥ 2 → задействуйте этот вспомогательный скилл в раздвоенном контексте.

3. Одиночный сигнал или ничья → один уточняющий вопрос.

4. После запуска вспомогательного скилла верните дайджест из 200 слов.

## Ожидаемые результаты { #output-expectations }

- Что было проанализировано
- Топ-3 результатов по степени тяжести
- Топ-3 следующих действия с ** назначенным утверждающим человеком** там, где это применимо
- Путь к артефакту
- Предлагаемая цепочка

## Жесткие правила { #hard-rules }

- Выходные данные о ценах: ** модель + ассортимент**, никогда не указывается конкретное количество.
- Результаты сделки: ** оценка + маршрутизация по имени утверждающего **, никогда автоматическое утверждение.
- Выходные данные прогноза: явно укажите ** предположение о преобразовании**.

## Анти-паттерны { #anti-patterns }

- ❌ Отработка всех 7 вспомогательных скилл "досконально" — выберите один, переварите, соедините в цепочку
- ❌ Разрешение прецеденту устанавливать политику — помечать сделки, нарушающие политику, для ревью
