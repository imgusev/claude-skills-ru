# /cs:оценка по сделке-ревью за каждую сделку + распределение скидок + красная линия { #csdeal-review--per-deal-scoring--discount-routing--redline }

Запустите `deal-desk` скилл на основе этого ввода:

**$АРГУМЕНТЫ**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`deal_scorer.py`** — Оценка сделки от 0 до 100 баллов по 5 параметрам: маржа (валовая прибыль после скидки), риск (условия оплаты + количество красных линий), стратегическая ценность (логотип / ссылка / расширение), коммерческое соответствие (в рамках политики), форма срока (многолетний или годовой). Отраслевая настройка с помощью `--profile`. Вердикт: ОДОБРИТЬ / РЕВЬЮ / ЭСКАЛАЦИЯ / ОТКЛОНЕНИЕ + **назван человек, утверждающий **.

2. **`discount_approval_router.py`** — Направьте скидку на соответствующий уровень утверждающего (значения по умолчанию: 0-15% AE, 15-25% менеджер, 25-35% директор, 35-50% вице-президент, 50%+ финансовый директор/CRO). Выводит цепочку одобрения с выделенными точками перехода сделки + расчетные дни цикла утверждения.

3. **`terms_redliner.py`** — Выявите более 10 шаблонов, убивающих основателей / продавцов: неуплаченное возмещение, отсутствие DPA, когда речь идет о данных ЕС, цены в режиме НБН, автоматическое продление без уведомления, возврат бессрочной лицензии, эксклюзивность без компенсации. Результат: ранжированный список "красных линий" с указанием степени серьезности + стандартный счетчик + названный юридический утверждающий.

## Выход { #output }

- Система показателей сделки с разбивкой по измерениям + вердикт
- Цепочка утверждения скидок (названные люди)
- Список исключений с указанием степени серьезности + язык счетчика
- Топ-3 следующих действия

## Жесткое правило { #hard-rule }

**На этом скилле никогда не написано "одобрено".** Он всегда выводит рекомендацию + имя утверждающего человека.

## Отличный от { #distinct-from }

- `cs-pricing-strategy` — это ** устанавливает модель ценообразования**. Это позволяет принимать решения **по каждой сделке**.
- `business-growth/contract-and-proposal-writer` — это **авторство**. Это ** гейт утверждения**.
- `commercial-policy` (родной брат) — который ** разрабатывает политику**. Это **применяется к каждой сделке**.
- `c-level-advisor/general-counsel-advisor` — это ** юридическая красная линия на более глубоком уровне**. Это ** коммерческая красная линия против политики**.
