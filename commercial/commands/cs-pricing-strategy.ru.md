# /cs:ценообразование-стратегия — Модель ценообразования + WTP + упаковка { #cspricing-strategy--pricing-model--wtp--packaging }

Запустите `pricing-strategist` скилл на основе этого ввода:

**$АРГУМЕНТЫ**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`pricing_model_picker.py`** — Оцените 5 моделей ценообразования (на основе места по подписке, на основе использования, на основе ценности, freemium, hybrid) с оценкой соответствия от 0 до 100 баллов каждая. Отраслевая настройка с помощью `--profile {saas,api,ai-tools,enterprise-software,marketplace}`. Детерминированная логика — схема потребления + значения драйверов сопоставляются с соответствием модели.

2. **`wtp_analyzer.py`** — Измеритель ценовой чувствительности Ван Вестендорпа. Принимает ответы на опрос (4 цены на одного респондента: слишком дешево, выгодная сделка, становится дороже, слишком дорого). Вычисляет пересечения OPP / IDP / PMC / PME. Выходные данные **Диапазон приемлемых цен** + ** Оптимальная ценовая точка** (с предупреждением о размере выборки N<30).

3. **`packaging_designer.py`** — 3-уровневая рекомендация по упаковке (хорошая / улучшенная /наилучший вариант) с распределением функций по уровням на основе важности + соответствия сегменту. Помечает анти-паттерны: "нет дифференциации", "Лучшая цена > 2x при значении < 1,5x".

## Выход { #output }

- Рекомендация по модели ценообразования (модель + ассортимент)
- Анализ WTP (4 ценовых пункта + RAP + OPP)
- Дизайн упаковки (3-уровневая карта объектов)

## Жесткое правило { #hard-rule }

**Этот скилл никогда не рекомендует конкретную цену.** В нем рекомендуются модель ** и ассортимент**. Человек выбирает номер.

## Отличный от { #distinct-from }

- `cs-deal-desk` — это одобрение скидки **за каждую сделку**.
- `c-level-advisor/cmo-advisor` — это ** позиционирование + бренд**.
- `c-level-advisor/cro-advisor` — это ** стратегическое движение доходов**.
