# /cs:размышление — Переоценка в середине разговора { #csreflect--mid-conversation-reassessment }

**Команда:** `/cs:reflect`

Тот `cs-reflect` персона приостанавливает выполнение и честно оценивает, к чему клонился разговор.

## Когда запускать { #when-to-run }

- Обсуждение деталей внедрения продвинулось более чем на 10 витков без стратегической проверки
- Повторяющиеся тупики или повороты в течение короткого промежутка времени
- Вы подозреваете, что обрамление отклонилось от первоначальной цели
- Вы хотите проверить предвзятость, прежде чем переходить к следующим шагам
- Проверка разумности предварительного решения при существенном изменении направления

## Когда не следует бегать { #when-not-to-run }

- Быстрый поиск или фактические вопросы
- Разговоры глубиной менее 5 оборотов (недостаточно для размышления)
- Промежуточная задача, когда вам нужно просто выполнить ее, а не переоценивать

## Что Вы получаете { #what-you-get }

Плавная прозаическая переоценка, охватывающая:

1. ** Макро-перспектива** — исходная цель в сравнении с текущим направлением; обнаружение дрейфа
2. **Анализ пробелов** — непроверенные предположения, отсутствующие стейкхолдеры, пропущенные ограничения, отвергнутые альтернативы
3. ** Рефлексивный запрос ** — правильная проблема по сравнению со смежной, более простой? Более простой путь слишком сложен? Более трудный и ценный путь, которого удалось избежать?
4. ** Проверка смещения** — подтверждение / заниженная стоимость / привязка / сложность / новизна
5. ** Контекстуальное соответствие** — служит ли направление целям + наилучшее использование времени

Завершая ** одной из трех рекомендаций**:

- **Продолжайте** — и почему (конкретные доказательства)
- **Поворот к {direction}** — а что бросать
- **Пауза для {question}** — и на какой вопрос ответить в первую очередь

## Фразы-триггеры (автоматический вызов без /cs:) { #trigger-phrases-auto-invoke-without-cs }

**Явный:**
- "размышлять"
- "сделай шаг назад" / "step back"
- "уменьшить масштаб"
- "мы что-то упускаем"
- "картина в целом"
- "чего нам не хватает"
- "давайте сделаем паузу"
- "проверьте это на вменяемость"
- "мы на верном пути"
- "не слишком ли мы много думаем об этом"
- "лес для деревьев"

**Неявный (фраза не требуется):**
- более 10 этапов детализации внедрения без стратегической проверки
- Пользователь проявляет признаки разочарования или зацикленности
- Повторяющиеся тупики или повороты в течение короткого промежутка времени

## Дисциплина { #discipline }

- ** Перечитайте ВЕСЬ разговор ** — от первоначальной цели вперед, а не только последние повороты
- ** Честный вывод ** — никаких искусственных проблем, когда путь надежен; конкретные рассуждения при проверке
- ** Плавная проза** — никаких заголовков, никаких маркированных списков
- ** Конкретные доказательства** — привязывайте каждое наблюдение к конкретным моментам разговора
- ** Обязательная рекомендация по закрытию ** — Продолжать / поворачивать / приостанавливать каждый раз
- **Низкое потребление** — максимум 1 дополнительный осветлитель (только при слишком разреженном контуре)
- ** Никаких упоминаний имен** — общее обращение от второго лица во всем

## Воркфлоу { #workflow }

```bash
# When triggered, the skill:
# 1. Halts current thread (no continuation of the in-progress task)
# 2. Re-reads full conversation from original goal
# 3. Runs 5-dimension analysis in head
# 4. Delivers flowing-prose reassessment

# Optional pre-flight: scan for bias patterns + depth signals
python ../skills/reflect/scripts/conversation_depth_analyzer.py --conversation /tmp/transcript.txt
python ../skills/reflect/scripts/bias_pattern_detector.py --conversation /tmp/transcript.txt

# Post-flight: validate output meets discipline
python ../skills/reflect/scripts/directional_recommendation_validator.py --output /tmp/output.txt
```

## Условия остановки { #stop-conditions }

- Размышление завершено + заключительная рекомендация выполнена → выполнено
- Слишком тонкий контекст → 1 уточняющий вопрос, затем запустите
- Пользователь говорит "прекратить размышлять" → немедленно вернуться к задаче

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Жестко закодированные имена пользователей или ссылки на конкретные домены
- Структурированный вывод отчета (заголовки, маркеры), когда требуется прозаический текст
- Выдуманные проблемы, когда на самом деле все в порядке
- Расплывчатое заверение ("выглядит хорошо!") вместо конкретных рассуждений
- Пересматривая только последние повороты вместо полного разговора
- Пропуск заключительной рекомендации по направлению
