# /cs:market-research — TAM/SAM/SOM + выборка опроса + сегментация { #csmarket-research--tamsamsom--survey-sampling--segmentation }

Запустите `market-research` скилл на основе этого ввода:

**$ARGUMENTS**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`market_sizer.py`** — Вычисляйте TAM /SAM / SOM как нисходящим (общая рыночная стоимость × доли), так и восходящим (клиенты × цена × принятие) методами параллельно. Сообщает о расхождении и помечает неудачную триангуляцию. Отраслевая настройка с помощью `--profile`. Никогда не возвращает ни одного числа.

2. **`sample_size_planner.py`** — Размер выборки опроса, основанный на достоверности, допустимой погрешности и ожидаемой пропорции, с поправкой на конечную совокупность и минимальные значения для каждого сегмента (опрос, проведенный в целом, не учитывается для каждого отчетного сегмента).

3. **`segmentation_scorer.py`** — Оценивайте сегменты-кандидаты в соответствии с критериями Котлера, которые поддаются измерению / существенны / доступны / дифференцируемы / применимы к действию. Применяет гейт существенности + доступности; отбрасывает демографические срезы, которые слишком малы или недоступны.

## Выход { #output }

- TAM/SAM/SOM в обоих направлениях + флаг триангуляции + предположения
- Обзор n (общий + этажи по сегментам)
- Оценки сегментов с вердиктами по цели /ПРОСМОТРУ /удалению
- Топ-3 следующих действия

## Жесткое правило { #hard-rule }

** Размер рынка всегда зависит от его метода (в обоих направлениях) и допущений — никогда не бывает ни одного числа без источника.**

## Первый запуск + оптимизация { #first-run--optimization }

- **Первый онбординг на борту:** `python3 skills/market-research/scripts/onboard.py` (профиль рынка, достоверность опроса, предел погрешности, метод определения размера) — сохраненная конфигурация предварительно настраивает каждый инструмент. `--show` перечисляет вопросы.
- **Оптимизация (регистрация):** только в том случае, если пользователь попросит согласовать размер/run цикл, переходящий к автоматическому поиску через `skills/market-research/scripts/ar_evaluator.py` (`tam_divergence`, чем ниже, тем лучше).

- `marketing-skill/marketing-strategy-pmm` — который устанавливает позиционирование/GTM. Это расширяет и сегментирует рынок.
- `commercial/pricing-strategist` — это определяет цену. Это расширяет рынок.
