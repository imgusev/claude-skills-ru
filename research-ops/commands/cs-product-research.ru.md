# /cs: продукт-исследование — дизайн исследования + насыщенность + обобщение информации { #csproduct-research--study-design--saturation--insight-synthesis }

Запустите `product-research` скилл на основе этого ввода:

**$АРГУМЕНТЫ**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`study_designer.py`** — Сопоставьте (цель исследования × стадия продукта) с соответствующим методом и сформируйте каркас плана (цель, критерии участников, структура руководства, критерии успеха). Перенаправляет прямой эфир A/B на `product-team/experiment-designer`.

2. **`saturation_planner.py`** — Руководство по выборке, основанное на методе, с явной меткой достоверности: Nielsen problem-discovery (5/сегмент), Guest и др. тематическая насыщенность (~12), оценочный охват. Никогда не претендует на показатель распространенности по результатам юзабилити-теста small-n.

3. **`insight_synthesizer.py`** — Группируйте закодированные наблюдения по тегам, подсчитывайте отдельных участников, ранжируйте по повторяемости между участниками и помечайте любого кандидата ниже порогового значения источника как АНЕКДОТ — никогда не повышайте его до уровня инсайта.

## Выход { #output }

- Рекомендуемый метод + каркас плана (в соответствии с целью)
- План выборки / насыщения с достоверностью + пределы
- Синтезированные кандидаты: ИНСАЙТ против АНЕКДОТА с доказательствами
- Топ-3 следующих действия

## Жесткое правило { #hard-rule }

** Метод должен соответствовать цели, а понимание требует повторения среди независимых участников. ** Отдельная цитата - это анекдот, а не вывод.

## Первый запуск + оптимизация { #first-run--optimization }

- **Первым поднялся на борт онбординга:** `python3 skills/product-research/scripts/onboard.py` (профиль продукта, источник информации - порог, метод насыщения, флаг высоких ставок) — сохраненная конфигурация предварительно настраивает каждый инструмент. `--show` перечисляет вопросы.
- **Оптимизировать (опция): ** только если пользователь попросит оптимизировать синтез / запустить цикл, переключитесь на автоматический поиск через `skills/product-research/scripts/ar_evaluator.py` (`validated_insights`, чем выше, тем лучше).

## Отличный от { #distinct-from }

- `product-team/ux-researcher-designer` — который создает персонажей / артефакты путешествия. Это дисциплина method + repository.
- `product-team/product-discovery` — который планирует спринты discovery. Это проектирует и обобщает результаты исследования.
- `product-team/experiment-designer` — который транслируется в прямом эфире A/B. При этом проводится качественное/оценочное исследование.
- `market-research` (родной брат) — который изучает рынок. Это исследование пользователей.
