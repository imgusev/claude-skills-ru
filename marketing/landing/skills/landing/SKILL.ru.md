# Лендинг — Генератор HTML-страниц премиум-класса { #landing--premium-html-landing-page-generator }

> **Отличается от `product-team/skills/landing-page-generator/`.** Этот скилл выводит Next.js Компоненты TSX оптимизированы для конверсии / генерации лидов. ЭТОТ скилл выводит единый автономный `.html` файл оптимизирован для превосходного визуального восприятия с помощью анимации GSAP. Выбирайте в зависимости от варианта использования.

Создайте отполированный, самодостаточный `.html` целевая страница из текстового промпта или брифа. Результатом является ОДИН HTML-файл: весь CSS встроен в `<style>`, все JS встроены в `<script>`, единственными внешними зависимостями являются Google Fonts + GSAP через CDN. Страница визуально отличительна, анимирована и отличается высоким качеством изготовления.

## Фаза 0: Прием пищи на гриле (4 форсирующих вопроса, по одному за раз) { #phase-0-grill-me-intake-4-forcing-questions-one-at-a-time }

Упорядоченный по зависимостям. Каждый вопрос содержит явное "почему я спрашиваю". Условие остановки: максимум 4.

### Q1 (root) — Продукт / услуга { #q1-root--product--service }

> **Что это за продукт или услуга? Дайте мне название + описание лифта в 1-2 предложениях — что он делает и для кого предназначен?**
>
> *Почему я спрашиваю:* Заголовок, подтекст и текстовая копия - все это вытекает из этого. "Приложение для повышения производительности" создает общий шаблон; "Асинхронный автономный инструмент для удаленных инженерных команд, которые ненавидят масштабирование" создает целевую страницу, которая преобразуется.

** Откажитесь от кашицы. ** Если пользователь называет только имя без высоты тона, нажмите один раз в ответ: "Что это делает? Для кого это?" Если после отката по-прежнему нет подачи, выполняйте с явным предупреждением об "общем позиционировании".

### Q2 (зависит от Q1) — Регистрация аудитории { #q2-depends-on-q1--audience-register }

> ** Кто эта аудитория? Выбери что-нибудь одно:**
>
> 1. **Технические покупатели** (инженеры, оперативники, охрана)
> 2. **Бизнес-покупатели** (PMS, руководители, руководители операционных подразделений)
> 3. **Потребители** (широкая общественность, любители)
> 4. **Внутренние** (сотрудники, партнеры — не для публичной продажи)
>
> *Почему я спрашиваю:* Аудитория диктует регистр копирования, уровень жаргона, выбор социальной защиты и составление CTA. Технические покупатели хотят конкретики; потребители хотят преимуществ; внутренние страницы могут не поддаваться убеждению.

Вынуждающий выбор.

### Q3 (всегда) — Переопределение бренда { #q3-always--brand-overrides }

> ** Фирменные цвета / шрифты для переопределения значений по умолчанию (темно-синий + бирюзовый + Интер)? Укажите в виде: основного шестигранника, акцентного шестигранника, дополнительного шестигранника bg. Или скажите "по умолчанию", если вы хотите получить отполированное значение по умолчанию.**
>
> *Почему я спрашиваю:* Значение по умолчанию намеренно красивое, но в соответствии с вашим брендом страница будет выглядеть как родная для вашего существующего сайта. Даже простое изменение основного цвета имеет большое значение.

Принимайте "по умолчанию" или частичные переопределения (например, только первичные). Если указан только первичный, выведите акцент алгоритмически (осветлить / затемнить).

### Q4 (зависит от Q1) — Тональный сигнал { #q4-depends-on-q1--tone }

> ** Тон — выберите один:**
>
> 1. **Профессионал** — уверенный в себе, сдержанный, дружелюбный к B2B
> 2. ** Игривый** — теплый, легкий, случайный юмор
> 3. **Авторитетный** — эксперт, передающий данные, укрепляющий доверие
> 4. **Минимальный ** — лаконичный, ориентированный на дизайн, низкая плотность копирования
>
> *Почему я спрашиваю:* Тон влияет на каждое предложение — заголовки, микрокопию, текст кнопки, заключительную копию. Подбор заранее предотвращает смещение тона по секциям.

Вынуждающий выбор. **Рекомендуемое значение по умолчанию:** профессиональный, если Q2 = технический/business; игривый, если Q2 = потребитель; минимальный, если продукт ориентирован на дизайн.

**Условие остановки: ** После Q4 зафиксируйте и сгенерируйте. Никаких дополнительных вопросов во время генерации.

## Извлечение контента (с использованием запасной стратегии) { #content-extraction-with-fallback-strategy }

Исходя из высоты подъема Q1, выведите:
- ** Заголовок героя ** — острая версия "что он делает" (8-12 слов)
- **Подтекст героя** — версия "для кого это + выигрыш" (1-2 предложения)
- ** 3-6 маркеров характеристик ** — составлено на основе подачи + аудитории (Q2) + тона (Q4)
- ** Текст CTA** — ориентирован на действие, соответствует тону
- ** Заключительная копия** — короткая, эмоциональная, соответствует тону

** Запасной вариант, когда вводимых данных мало:** придумайте привлекательный контент на основе семантики названия продукта + реестра аудитории. Помечайте выводимый контент комментарием в исходном коде HTML (`<!-- inferred: ... -->`). Не задерживайтесь в ожидании дополнительной информации.

### Переопределить шаблон { #override-pattern }

Когда Q3 предоставляет пользовательские значения бренда, скилл заменяет их на `:root` блокировать:

```
Brand override:
- primary: #FF6B35    →  --navy / hero bg
- accent:  #2EC4B6    →  --teal / CTA / highlights
- bg:      #011627    →  --navy-mid / section bg
- text:    #FDFFFC    →  --off-white
```

Если указан только основной цвет, выведите акцент алгоритмически (осветлите на 15% для акцента; затемните на 8% для темно-синего цвета; преобразуйте в rgba с 0,12 альфа для свечения). Использование `scripts/brand_palette_validator.py` для детерминированного вывода.

Видишь [`references/brand_system_design.md`](references/brand_system_design.md) для теории цвета + WCAG + алгоритмический канон получения палитры.

### Типография { #typography }

- ** Семейство шрифтов:** Inter (через Google Fonts)
- ** Весовая шкала: ** 400 (тело), 500 (брови), 600 (ссылки), 700 (субтитры), 800 (H1 + H2)
- **Размерная шкала:**
  - Герой H1: 68–82px

### Компоненты (необходимо указать CSS) { #components-must-specify-css }

- `.btn-primary` — Кнопка CTA с состоянием наведения (подъем + яркость)
- `.feature-card` — карточка с подъемом при наведении курсора мыши (перевод (-6 пикселей) + осветление границы)
- `.eyebrow` — метка категории в верхнем регистре с интервалом между буквами (0,2эм)

## Раздел 1: Герой { #section-1-hero }

- `min-height: 100vh`, ориентированный на гибкость контент
- Дополнительная метка для бровей над H1
- H1 (68-82 пикселя, вес 800 г)
- Подзаголовок (17-19 пикселей, 1-2 предложения)
- Кнопка CTA (.btn-основная)
- Индикатор прокрутки вниз (анимированный шеврон, отскок CSS)
- **Слои глубины** (параллакс мыши):
  - `.hero-shapes-back` — большие размытые круги, абсолютное расположение, низкая непрозрачность
  - `.hero-shapes-mid` — меньшие формы, более острые края, более высокая непрозрачность
  - Слой содержимого (H1 + субтитры) — плавно перемещается в том же направлении, что и мышь

## Раздел 2: Особенности { #section-2-features }

- 3 столбца по умолчанию (`repeat(3, 1fr)` сетка)
- Отзывчивый:
  - 2 столбца с точкой останова 900 пикселей
  - 1 столбец с точкой останова 580 пикселей
- Каждая карта:
  - Значок SVG (28 пикселей, обводка=var(--teal), без заливки)
  - Заголовок (22 пикселя, вес 700 г)
  - Описание (15–16 пикселей, --текст отключен)
- Состояние зависания:
  - `transform: translateY(-6px)`
  - `border-color: var(--teal)` (осветлить с помощью --card-border)
  - `transition: 0.3s ease`

## Раздел 3: Закрытие CTA { #section-3-closing-cta }

- Во всю ширину, `background: var(--navy-mid)`
- `padding: 120px 24px`, выравнивание по тексту: по центру
- Большой заключительный заголовок (52-62 пикселя, вес 800 г)
- Короткий подтекст (--текст отключен, 1-2 предложения)
- Кнопка CTA с окружающим радиально-градиентным свечением за ней:
  ```css

  ```

## Анимационные узоры { #animation-patterns }

Видишь [`references/gsap_animation_patterns.md`](references/gsap_animation_patterns.md) для канона. Требуется пять шаблонов:

### 1. Вступление героя (временная шкала GSAP) { #1-hero-entrance-gsap-timeline }

```js
// MUST use gsap.set() FIRST to prevent FOUC
gsap.set([".eyebrow", ".hero h1", ".hero .subtitle", ".btn-primary", ".scroll-down"], {
  opacity: 0,
  y: 30
});

const tl = gsap.timeline({ defaults: { ease: "power3.out" } });
tl.to(".eyebrow", { opacity: 1, y: 0, duration: 0.6 })
  .to(".hero h1", { opacity: 1, y: 0, duration: 0.8 }, "-=0.3")
  .to(".hero .subtitle", { opacity: 1, y: 0, duration: 0.6 }, "-=0.5")
  .to(".btn-primary", { opacity: 1, y: 0, duration: 0.5 }, "-=0.3")
  .to(".scroll-down", { opacity: 1, y: 0, duration: 0.4 }, "-=0.2");
```

### 2. Параллакс мыши { #2-mouse-parallax }

```js
const hero = document.querySelector(".hero");
hero.addEventListener("mousemove", (e) => {
  const x = (e.clientX / window.innerWidth - 0.5) * 2;
  const y = (e.clientY / window.innerHeight - 0.5) * 2;
  gsap.to(".hero-shapes-back", { x: x * 45, y: y * 22, duration: 0.8 });
  gsap.to(".hero-shapes-mid",  { x: x * 22, y: y * 11, duration: 0.8 });
  gsap.to(".hero .container",  { x: x * 8,  y: y * 5,  duration: 0.8 });
});
```

### 3. Игровые карты, Триггеры которых запускаются при прокрутке { #3-scroll-triggered-feature-cards }

```js
gsap.set(".feature-card", { opacity: 0, y: 55, rotateX: 18 });

ScrollTrigger.batch(".feature-card", {
  start: "top 80%",
  onEnter: batch => gsap.to(batch, {
    opacity: 1, y: 0, rotateX: 0,
    duration: 0.8,
    stagger: 0.11,
    ease: "power2.out"
  })
});
```

### 4. Плавающие декоративные фигуры (ключевые кадры CSS — НЕ GSAP) { #4-floating-decorative-shapes-css-keyframes--not-gsap }

CSS обрабатывает окружающее непрерывное движение (более плавное, дешевле, чем GSAP для неопределенной анимации):

```css
@keyframes floatA {
  0%, 100% { transform: translate(0, 0) rotate(0deg); }
  50%      { transform: translate(20px, -30px) rotate(8deg); }
}
@keyframes floatB { /* different duration + rotation */ }
@keyframes floatC { /* different duration + rotation */ }

.hero-shapes-back .shape-a { animation: floatA 12s ease-in-out infinite; }
```

### 5. Индикатор прокрутки (отскок CSS) { #5-scroll-indicator-css-bounce }

```css
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(8px); }
}
.scroll-down { animation: bounce 2s ease-in-out infinite; }
```

## Требуемые зависимости CDN { #required-cdn-dependencies }

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap" rel="stylesheet">
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/ScrollTrigger.min.js"></script>
```

НИКАКИХ других внешних CSS или JS-файлов. Весь пользовательский CSS в `<style>`, все пользовательские JS в `<script>` блоки внутри одного и того же HTML-файла.

Видишь [`references/single_file_html_discipline.md`](references/single_file_html_discipline.md) для встроенного обоснования.

## Правила компоновки { #layout-rules }

- **Максимальная ширина контейнера:** 1200 пикселей, по центру
- **Заполнение раздела:** `120px 24px` (по вертикали 120, по горизонтали 24, уменьшено на мобильном устройстве)
- **Адаптивные точки останова:**
  - 900 пикселей → сетка объектов 3-col → 2-col
  - 580 пикселей → все сетки → 1-col; H1 масштабируется до ~ 52 пикселей
- **Метаданные видового экрана:** `<meta name="viewport" content="width=device-width, initial-scale=1">`

## Спецификация выходного сигнала { #output-spec }

- **Путь:** `${OUTPUT_DIR}/<product-name-kebab>.html`
- **Значение по умолчанию `${OUTPUT_DIR}`:** `./landing-pages/`
- **Имя файла:** кебаб-заглавная буква в нижнем регистре от названия продукта ("Quill AI" → `quill-ai.html`). Используйте `scripts/kebab_slug_generator.py` для детерминированной генерации пуль + обнаружения дубликатов.
- ** Автономный:** весь CSS в `<style>`, все JS в `<script>`, только Google Fonts + GSAP CDN внешний.

## Проверка (после генерации) { #validation-post-generation }

Бежать `scripts/html_validator.py --file ${OUTPUT_DIR}/<slug>.html` из поколения в поколение. Проверки:

- Присутствуют все 3 обязательных раздела (`.hero`, `.features`, `.closing-cta`)
- Присутствуют deps CDN (Inter + GSAP + ScrollTrigger)
- `gsap.set()` начальные состояния предшествуют любому `gsap.timeline` или `gsap.to` (Предотвращение FOUC'а)
- Адаптивные точки останова с разрешением 900 пикселей + 580 пикселей
- Никакого внешнего `<link rel="stylesheet">` отличные от Google шрифты
- Никакого внешнего `<script src=>` отличный от GSAP CDN
- `<meta name="viewport">` настоящее время
- Все анимированные элементы имеют объявления начального состояния

## Обработка ошибок { #error-handling }

| Ситуация | Поведение |
|---|---|
| Ввод - это просто имя без контекста | Придумайте привлекательный контент на основе семантики имени + реестра аудитории; отметьте как `<!-- inferred -->` в исходном коде HTML |
| Входной файл большого размера или PDF | Прочитайте полностью перед созданием; не усекайте |
| Недостаточно фирменных цветов (предусмотрен только 1 шестигранник) | Использовать как первичный; выводить вторичный/accent алгоритмически (облегчить/darken через brand_palette_validator.py ) |
| Количество объектов не указано | Значение по умолчанию - 4 |
| Выходной каталог не существует | Создайте его |
| Существующий файл в пути вывода | Добавьте суффикс временной метки или спросите пользователя (kebab_slug_generator.py помечает дубликаты) |
| html_validator возвращает ошибку | Восстановите ТОЛЬКО поврежденные разделы за один целевой проход; не удаляйте файл |

## Анти-Паттерны для отклонения { #anti-patterns-to-reject }

- Жестко заданные абсолютные пути в выходном каталоге
- Единая палитра брендов без переопределяющей документации
- Очерчивание перед записью — запись за один проход
- Внешние файлы CSS или JS (должны быть встроенными; разрешены только шрифты Google + GSAP CDN)
- Пропускающий `gsap.set()` начальные состояния (вызывает FOUC)
- Более 6 объектов в сетке по умолчанию (становится недоступным для сканирования)
- Ссылки на контент, относящийся к конкретному бренду, в самом скилле
