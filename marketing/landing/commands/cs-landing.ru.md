# /cs:landing — Генератор целевых страниц премиум-класса в HTML-формате { #cslanding--premium-html-landing-page-generator }

**Команда:** `/cs:landing <product-or-brief>`

Тот `cs-landing` персона создает безупречную, самодостаточную `.html` целевая страница с анимацией GSAP, параллаксом мыши и 3D CSS-эффектами.

## Когда запускать { #when-to-run }

- Запускайте страницы, на которых страница представляет собой интерфейс (visual-премиум одностраничники)
- Витрины товаров с движущимся дизайном
- Сайты брендов, где коэффициент конверсии не является основным показателем — показ является

## Когда не запускать (использовать `landing-page-generator` вместо этого) { #when-not-to-run-use-landing-page-generator-instead }

Если вам нужен ** оптимизированный для конверсии лидогенератор ** с фреймворками копирования (PAS / AIDA / BAB), Next.js Компоненты TSX, несколько вариантов секций для A/B тестирования — используйте `product-team/skills/landing-page-generator/` вместо этого. Это другой скилл, оптимизирующий для достижения разных результатов.

| Потребность | Скилл |
|---|---|
| Визуальный премиум-пейджер с одним пейджером | **`/cs:landing`** (эта команда) |
| Оптимизированный для конверсии лидогенератор | `landing-page-generator` |

**Примечание:** эти фразы-триггеры могут соответствовать либо данному скиллу, либо `landing-page-generator`. Если установлены оба, Клод выбирает в зависимости от контекста беседы (премиум-визуальные подсказки → этот скилл; подсказки по конверсии / генерации лидов / A / B-тестированию → другое).

## Форсированный прием (3-4 вопроса, по одному за раз) { #forcing-intake-34-questions-one-at-a-time }

| Вопрос | Спрашивает | Значение по умолчанию, если принудительный выбор |
|---|---|---|
| Вопрос 1 | Продукт / услуга: название + 1-2 предложения высота подъема | отказывается от расплывчатых ответов ("приложение для повышения производительности" отбрасывается один раз) |
| Q2 | Реестр аудитории: техническая / деловая / потребительская / внутренняя | вынуждающий выбор |
| Вопрос 3 | Переопределения бренда: основной шестнадцатеричный код + акцентный шестнадцатеричный код + дополнительный шестнадцатеричный код bg ИЛИ "по умолчанию" | по умолчанию = темно-синий + бирюзовый |
| Q4 | Тон: профессиональный / игривый / авторитетный / минимальный | принудительный выбор (рекомендуется: профессиональный для B2B, игривый для потребителя, минимальный для дизайна-led) |

** Условие остановки:** Максимум 4 вопроса. Никаких последующих действий во время генерации.

## Что Вы получаете { #what-you-get }

Один-единственный `.html` файл по адресу `${OUTPUT_DIR}/<product-kebab>.html` (по умолчанию `./landing-pages/`) с:

- **Герой** — 100vh, анимированный вход в H1 через временную шкалу GSAP, индикатор прокрутки вниз, слои глубины параллакса с помощью мыши
- **Особенности** — 3- сетка столбцов (адаптивная 2-столбчатая с разрешением 900 пикселей, 1-столбчатая с разрешением 580 пикселей), значки в формате SVG, триггер прокрутки, открывающийся на карточке с `rotateX` лифт
- ** Закрывающий CTA ** — большой закрывающий заголовок + окружающее радиально-градиентное свечение за кнопкой

Весь CSS встроенный. Все JS встроены. Внешние: Google Fonts (Inter) + GSAP только через CDN.

## Дисциплина { #discipline }

- ** Один входной вопрос за ход. ** Никогда не связывайтесь.
- ** Откажитесь от неопределенного Q1 один раз.** Отожмите; доставьте с оговоркой, если пользователь не будет заострять внимание.
- ** Нет FOUC.** Каждый анимированный элемент получает `gsap.set()` исходное состояние.
- **Только встроенный.** Все CSS + JS в файле. Никакого внешнего `.css` / `.js` ссылки.
- ** Отзывчивый.** Точки останова на 900 пикселей + 580 пикселей.
- ** Никаких жестко заданных путей.** `${OUTPUT_DIR}` переменная.
- ** Запись за один проход.** Нет цикла "Набросок → черновик → полировка".

## Воркфлоу { #workflow }

```bash
# 1. Intake (Q1-Q4 one at a time)

# 2. If brand override provided, validate:
python ../skills/landing/scripts/brand_palette_validator.py \
  --primary "#FF6B35" --accent "#2EC4B6" --bg "#011627"

# 3. Generate output filename
python ../skills/landing/scripts/kebab_slug_generator.py \
  --product "<product name from Q1>" --output-dir ./landing-pages

# 4. Write the .html file in one pass (Hero + Features + Closing CTA + GSAP + mouse parallax + ScrollTrigger + CSS floats)

# 5. Validate structure
python ../skills/landing/scripts/html_validator.py \
  --file ./landing-pages/<slug>.html

# 6. Deliver:
#    CLI → file path
#    Web → HTML artifact
```

## Условия остановки { #stop-conditions }

- Даны ответы на все 4 вопроса + сгенерирован HTML-код + ПРОЙДЕН валидатором → готово
- Пользователь говорит "пропустить прием" → использовать значения по умолчанию для любого вопроса, на который нет ответа (бренд по умолчанию, профессиональный тон, аудитория, определяемая по подаче в лифте).
- Ошибка валидатора → восстановите поврежденные разделы за один целевой проход; не удаляйте файл

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Жестко заданные абсолютные пути в выходном каталоге
- Единая палитра брендов без переопределяющей документации
- Очерчивание перед записью — запись за один проход
- Внешние файлы CSS или JS (должны быть встроенными)
- Пропускающий `gsap.set()` начальные состояния (вызывает FOUC)
- Более 6 объектов в сетке по умолчанию (становится недоступным для сканирования)
- Ссылки на контент, относящийся к конкретному бренду, в самом скилле
- Объединяющие вопросы о приеме
