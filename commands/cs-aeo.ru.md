# /cs:aeo — Поисковая оптимизация ответов { #csaeo--answer-engine-optimization }

**Команда:** `/cs:aeo [action] [args]`

Тот `cs-aeo` команда - это **точка входа для воркфлоу AEO**: аудит → оптимизация → публикация → отслеживание ссылок.

## Отличный от `/cs:seo-audit` { #distinct-from-csseo-audit }

Они имеют общую основу (E-E-A-T), но оптимизированы для различных событий преобразования:

- **`/cs:seo-audit`** — оптимизирован для ранжирования + переходов по ссылкам в результатах поиска Google / Bing
- **`/cs:aeo`** (эта команда) — оптимизируется для цитирования LLMS в качестве авторитетного источника

Они могут работать с одним и тем же контентом. Агент cs-aeo обнаружит это и порекомендует запустить оба варианта для страниц с высоким коэффициентом использования.

## Когда запускать { #when-to-run }

- Аудит существующего контента на предмет готовности к поиску с помощью искусственного интеллекта (сигналы E-E-A-T + структура)
- Оптимизация страницы для цитирования в LLM перед публикацией
- Отслеживание того, какие LLM ссылаются на какие страницы с течением времени (журнал цитирования)
- Исследование того, стоят ли инвестиции в AEO для данного фрагмента контента
- Сравнение с показателями цитируемости конкурентов

## Когда НЕ следует бегать { #when-not-to-run }

- Чистый поиск по кликам без использования искусственного интеллекта-цель цитирования → использование `/cs:seo-audit`
- Контент, озвученный брендом, без фактических утверждений (для цитирования требуются факты)
- Новости, зависящие от времени (задержка в обучении LLM означает, что цитирование приходит месяцами позже)
- Темы, по которым магистранты уже имеют хорошую подготовку (например, элементарная математика)

## Действия { #actions }

### `audit` — Содержание оценки готовности УЭО { #audit--score-content-for-aeo-readiness }

```bash
/cs:aeo audit --input post.md --industry saas
/cs:aeo audit --url https://example.com/blog/post --industry healthcare
/cs:aeo audit --sample
```

Возвращает комбинацию 0-100 с разбивкой по измерениям (структура E-E-A-T +) и 5 лучших исправлений в порядке приоритета.

### `optimize` — Сгенерировать AEO-улучшенный вариант { #optimize--generate-aeo-improved-variant }

```bash
/cs:aeo optimize --input post.md --mode balanced --output post-aeo.md
/cs:aeo optimize --input post.md --mode aggressive --industry finance
```

Три режима:
- `conservative` — коснитесь <10% слов (только нижний колонтитул схемы + исправления)
- `balanced` — коснуться <30% (маркеры цитирования + реструктуризация заголовка + схема + нижний колонтитул)
- `aggressive` — полная реструктуризация + первое упоминание фактов + максимальная плотность цитирования

### `track` — Зарегистрируйте цитату, которую вы заметили в ответе LLM { #track--log-a-citation-you-observed-in-an-llm-response }

```bash
/cs:aeo track --url https://example.com/post --llm perplexity --query "what is AEO" --date 2026-05-17
```

Ведет локальную бухгалтерскую книгу по адресу `~/.aeo-data/citations.json`. Никакой телеметрии.

### `report` — Сводный отчет о цитировании для URL-адреса { #report--aggregate-citation-report-for-a-url }

```bash
/cs:aeo report --url https://example.com/post
```

Возвращает общее количество цитирований, охват LLM, скорость, топовые запросы, вердикт (РАННИЙ / ПОЯВЛЯЮЩИЙСЯ / СИЛЬНЫЙ).

### `export` — Создать реестр цитирований в формате CSV { #export--emit-citation-ledger-as-csv }

```bash
/cs:aeo export --output citations.csv
```

Для отчетности перед клиентами/стейкхолдерами.

## Минимальный прием (3 вопроса) { #minimal-intake-3-questions }

| Вопрос | Спрашивает | Когда |
|---|---|---|
| Вопрос 1 | Какое действие — аудит / оптимизация/ отслеживание / отчет? | Всегда |
| Q2 | Отрасль (saas / здравоохранение / финансы / юриспруденция / электронная коммерция / b2b / МЕДИА / образование) | Всегда (калибрует пороговые значения) |
| Вопрос 3 | Для `optimize`: режим (консервативный / сбалансированный/ агрессивный)? | Только тогда, когда действие=оптимизация |

Большинство вызовов завершают прием после Q2.

## Воркфлоу { #workflow }

```bash
# Phase 1: Audit
python3 marketing-skill/skills/aeo/scripts/aeo_audit.py --input <file> --industry <industry>
# → composite score 0-100 + top fixes

# Phase 2: Optimize (if audit < industry threshold)
python3 marketing-skill/skills/aeo/scripts/aeo_optimizer.py \
  --input <file> --mode <mode> --industry <industry> --output <file>-aeo.md
# → optimized variant + changelog

# Phase 3: Publish (manual step — review the optimized variant, then deploy)

# Phase 4: Track (over 4-12 weeks)
python3 marketing-skill/skills/aeo/scripts/citation_tracker.py \
  --action add --url <url> --llm <llm> --query <query> --date <YYYY-MM-DD>
# → ledger updated

# Phase 5: Report (monthly)
python3 marketing-skill/skills/aeo/scripts/citation_tracker.py \
  --action report --url <url>
# → per-URL citation report
```

## Пороговые значения для конкретной отрасли { #industry-specific-thresholds }

Аудитор проводит калибровку в зависимости от отрасли. В темах YMYL ("Ваши деньги или ваша жизнь") используются более строгие пороговые значения:

| Промышленность | Минимальный композит | Почему |
|---|---|---|
| Здравоохранение | 85 | Прямые последствия для здоровья |
| Финансы | 85 | Реальные финансовые решения |
| Юридический | 85 | Юридическая опасность в случае неправильного применения |
| Образование | 75 | Результаты обучения |
| SaaS, B2B, МЕДИА | 70 | Деловые решения, умеренные ставки |
| Электронная коммерция | 65 | Ревью к продукту, снижающий индивидуальный риск |

Контент для тем YMYL, набравший баллы ниже порогового значения, вряд ли будет цитироваться независимо от других сигналов — агент cs-aeo отметит это и откажется от агрессивной оптимизации до тех пор, пока основные параметры не улучшатся.

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Сгенерированный LLM контент AEO без ревью со стороны пользователя (поиск RAG лишает приоритетности общие выходные данные LLM)
- Сфабрикованные учетные данные в подписях авторов (перекрестная ссылка на LLMs через LinkedIn/Википедию)
- Спам по схеме (ложная разметка структурированных данных фильтруется)
- Отмывание полномочий (ссылка не дает полномочий)
- Оптимизация для каждого LLM-туннельное видение (73% корреляция цитирования между LLM — оптимизация для общих сигналов)
- Оптимизация AEO за счет SEO (и наоборот) — они дополняют, а не заменяют
