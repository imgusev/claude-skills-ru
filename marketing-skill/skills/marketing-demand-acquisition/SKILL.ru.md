## Основные ключевые показатели эффективности { #core-kpis }

**Уровень спроса:** Объем MQL/SQL, стоимость каждой возможности, пайплайн из маркетинговых источников в долларах, скорость MQL→SQL

**Платные МЕДИА:** CAC, ROAS, CPL, CPA, коэффициент эффективности канала

** SEO:** Органические сессии, процент небрендового трафика, рейтинг ключевых слов, оценка технического состояния

**Партнерские отношения:** Пайплайн из партнерских источников $, партнерский CAC, рентабельность совместного маркетинга

## Фреймворк для формирования спроса { #demand-generation-framework }

### Этапы воронки { #funnel-stages }

| Стадия | Тактика | Цель |
|-------|---------|--------|
| ТОФУ | Платные социальные сети, показ, синдикация контента, SEO | Узнаваемость бренда, трафик |
| МОФУ | Платный поиск, ретаргетинг, гейт-контент, поддержка электронной почты | MQLS, демонстрационные запросы |
| БОФУ | Поиск бренда, прямой охват, тематические исследования, судебные процессы | SQLs, пайплайн $ |

### Воркфлоу планирования кампании { #campaign-planning-workflow }

1. Определите цель, бюджет, продолжительность, аудиторию
2. Выберите каналы в зависимости от стадии воронки
3. Создайте кампанию в HubSpot с правильной структурой UTM
4. Настройка правил оценки потенциальных клиентов и назначения
5. Запуск с тестовым бюджетом, проверка отслеживания
6. **Проверка:** Параметры UTM отображаются в записях контактов HubSpot

### Структура UTM { #utm-structure }

```
utm_source={channel}       // linkedin, google, meta
utm_medium={type}          // cpc, display, email
utm_campaign={campaign-id} // {qN-yyyy}-linkedin-enterprise
utm_content={variant}      // ad-a, email-1
utm_term={keyword}         // [paid search only]
```

## Платные медиа-каналы { #paid-media-channels }

### Матрица выбора канала { #channel-selection-matrix }

| Канал | Лучше всего подходит для | Диапазон CAC | Серия A Приоритетная |
|---------|----------|-----------|-------------------|
| Реклама в LinkedIn | B2B, Предпринимательство, ПРО | $150-400 | Высокий |
| Поиск в Google | С высокими намерениями, БОФУ | $80-250 | Высокий |
| Дисплей Google | Перенацеливание | $50-150 | Средний |
| Мета-реклама | Малый и средний бизнес, визуальные продукты | $60-200 | Средний |

### Настройка рекламы в LinkedIn { #linkedin-ads-setup }

1. Создайте группу кампании для инициативы
2. Структура: Осведомленность → Рассмотрение → Конверсионные кампании
3. Цель: Директор+, 50-5000 сотрудников, соответствующие отрасли
4. Начните с 50 долларов в день за кампанию
5. Увеличивайте на 20% еженедельно, если CAC < целевой
6. ** Проверка:** Тег LinkedIn Insight запускается на всех страницах

### Настройка рекламы в Google { #google-ads-setup }

1. Расставьте приоритеты: Бренд → Конкурент → Решение → Ключевые слова категории
2. Структурируйте группы объявлений с помощью 5-10 ключевых слов с узкой тематикой
3. Создайте 3 адаптивных поисковых объявления для каждой группы объявлений (15 заголовков, 4 описания).
4. Вести список отрицательных ключевых слов (более 100)
5. Запустите ручную цену за клик, переключитесь на целевую цену за клик после более чем 50 конверсий
6. ** Проверка:** Запуск отслеживания конверсий, еженедельный ревью поисковых запросов

## Стратегия SEO { #seo-strategy }

### Чек-лист технической базы Foundation Foundation { #technical-foundation-checklist }

- [ ] XML-карта сайта, отправленная в Search Console
- [ ] Robots.txt настроен правильно
- [ ] Включен HTTPS
- [ ] Скорость страницы >90 для мобильных устройств
- [ ] Передача основных жизненно важных функций Сети
- [ ] Реализованы структурированные данные
- [ ] Канонические теги на всех страницах
- [ ] Теги Hreflang для международных
- ** Проверка: ** Запуск Screaming Frog crawl, ноль критических ошибок

### Стратегия по ключевым словам { #keyword-strategy }

| Уровень | Тип | Объем | Приоритет |
|------|------|--------|----------|
| 1 | БОФУ с высокими намерениями | 100-1к | Первый |
| 2 | MOFU, ориентированный на решение | 500-5k | Второй |
| 3 | ТОФУ, ориентированный на решение проблем | 1к-10к | Третий |

### Оптимизация на странице { #on-page-optimization }

1. URL: Укажите основное ключевое слово, 3-5 слов
2. Тег заголовка: Основное ключевое слово + бренд (60 символов)
3. Мета-описание: CTA + value prop (155 символов)
4. H1: Соответствие цели поиска (по одному на страницу)
5. Содержание: 2000-3000 слов по всеобъемлющим темам
6. Внутренние ссылки: 3-5 релевантных страниц
7. ** Проверка:** Поисковая консоль Google показывает, что страница проиндексирована, ошибок нет

### Приоритеты в построении связей { #link-building-priorities }

1. Цифровой PR (оригинальные исследования, отраслевые отчеты)
2. Гостевой постинг (только для сайтов DA 40+)
3. Партнерский совместный маркетинг (дополнительный SaaS)
4. Вовлечение сообщества (Reddit, Quora)

## Партнерские отношения { #partnerships }

### Уровни партнерства { #partnership-tiers }

| Уровень | Тип | Усилие | РЕНТАБЕЛЬНОСТЬ ИНВЕСТИЦИЙ |
|------|------|--------|-----|
| 1 | Стратегическая интеграция | Высокий | Очень высокий |
| 2 | Аффилированные партнеры | Средний | Средне-высокий |
| 3 | Рекомендации клиентов | Низкий | Средний |
| 4 | Объявления на маркетплейсах | Средний | Низкий-средний |

### Партнерский воркфлоу { #partnership-workflow }

1. Выявление партнеров с перекрывающимися ПМС, отсутствие конкуренции
2. Информационно-пропагандистская деятельность с конкретным предложением по интеграции/совместному маркетингу
3. Определите показатели успеха, модель дохода, срок
4. Создавайте кобрендовые активы и отслеживайте партнеров
5. Подключите команду партнеров по продажам к демонстрационному обучению
6. ** Проверка:** Функция отслеживания UTM партнера, правильная маршрутизация лидов

### Настройка партнерской программы { #affiliate-program-setup }

1. Выберите платформу (PartnerStack, Impact, Rewardful)
2. Настройка структуры комиссионных (20-30% повторяющихся)
3. Создать набор для поддержки партнеров (ресурсы, ссылки, контент)
4. Набирать сотрудников через исходящие, входящие мероприятия
5. ** Проверка:** Тестовая партнерская ссылка отслеживает конверсию

5. ** Проверка:** Запустите отчет за последние 90 дней, все каналы показывают данные

## Проактивные триггеры { #proactive-triggers }

- **Чрезмерная зависимость от одного канала** → Зависимость от одного канала - это бизнес-риск. Диверсифицируйте.
- **Нет подсчета лидов ** → Не все лиды равны. Путь к доходу - операции для подсчета очков.
- **CAC, превышающий LTV** → Генерация спроса убыточна. Оптимизируйте или сократите каналы.
- **Нет поддержки для неготовых потенциальных клиентов ** → 80% потенциальных клиентов не готовы к покупке. Воспитание преобразует их позже.

- **аналитика кампаний**: Для измерения эффективности формирования спроса.
