## Воркфлоу по исследованию ключевых слов { #keyword-research-workflow }

Находите и оценивайте ключевые слова, которые повышают видимость app store.

### Воркфлоу: Проведите исследование ключевых слов { #workflow-conduct-keyword-research }

1. Определите целевую аудиторию и основные функции приложения:
   - Основной вариант использования (какую проблему решает приложение)
   - Целевая демография пользователей
   - Конкурсная категория
2. Генерируйте исходные ключевые слова из:
   - Функции и преимущества приложения
   - Пользовательский язык (не терминология разработчика)
   - Предложения по автозаполнению в App store
3. Разверните список ключевых слов с помощью:
   - Модификаторы (бесплатные, лучшие, простые)
   - Действия (создавать, отслеживать, организовывать)
   - Аудитории (для студентов, для команд, для бизнеса)
4. Оценивайте каждое ключевое слово:
   - Объем поиска (предполагаемый ежемесячный объем поисковых запросов)
   - Конкуренция (количество и качество рейтинговых приложений)
   - Актуальность (согласование с функцией приложения)
5. Оценивайте ключевые слова и расставляйте приоритеты:
   - Основное: поле заголовка и ключевого слова (iOS)
   - Второстепенный: Подзаголовок и краткое описание
   - Третичный: только полное описание
6. Сопоставьте ключевые слова с местоположениями метаданных
7. Документируйте стратегию отслеживания ключевых слов
8. ** Проверка:** Ключевые слова оценены; сопоставлено размещение; не включены названия брендов конкурентов; в поле ключевого слова iOS нет множественного числа

### Критерии оценки ключевых слов { #keyword-evaluation-criteria }

| Фактор | Вес | Высокие балльные показатели |
|--------|--------|----------------------|
| Актуальность | 35% | Описывает основную функцию приложения |
| Объем | 25% | более 10 000 поисковых запросов в месяц |
| Конкуренция | 25% | Топ-10 приложений имеют средний рейтинг <4,5 |
| Преобразование | 15% | Транзакционное намерение ("лучшее приложение X") |

### Приоритет размещения ключевых слов { #keyword-placement-priority }

| Местоположение | Вес поиска |
|----------|---------------|
| Название приложения | Самый высокий |
| Субтитры (iOS) | Высокий |
| Поле ключевого слова (iOS) | Высокий |
| Краткое описание (Android) | Высокий |
| Полное описание | Средний |

## Оптимизация метаданных в воркфлоу { #metadata-optimization-workflow }

Оптимизируйте элементы списка app Store для ранжирования в поиске и конверсии.

### Воркфлоу: Оптимизация метаданных приложения { #workflow-optimize-app-metadata }

1. Аудит текущих метаданных в соответствии с ограничениями платформы:
   - Количество символов заголовка и наличие ключевых слов
   - Использование субтитров/краткого описания
   - Эффективность поля ключевых слов (iOS)
   - Плотность ключевых слов описания
2. Оптимизируйте заголовок по следующей формуле:
   ```
   [Brand Name] - [Primary Keyword] [Secondary Keyword]
   ```
3. Написать субтитры (iOS) или краткое описание (Android):
   - Сосредоточьтесь на основной выгоде
   - Включить вторичное ключевое слово
   - Используйте глаголы действия
4. Оптимизировать поле ключевого слова (только для iOS):
   - Удалить дубликаты из заголовка
   - Удалить множественное число (Apple индексирует обе формы)
   - Никаких пробелов после запятых
   - Расставляйте приоритеты по баллам
5. Переписать полное описание:
   - Дополните абзац ценностным предложением
   - Выделите маркеры с ключевыми словами
   - Раздел социального доказательства
   - Призыв к действию
6. Проверьте количество символов для каждого поля
7. Рассчитайте плотность ключевых слов (цель - 2-3% первичных)
8. ** Проверка:** Все поля в пределах допустимого количества символов; основное ключевое слово в заголовке; без заполнения ключевыми словами (>5%); сохранен естественный язык

### Ограничения по персонажам платформы { #platform-character-limits }

| Поле | Apple App Store | Магазин Google Play |
|-------|-----------------|-------------------|
| Название | 30 символов | 50 символов |
| Подзаголовок | 30 символов | Н/Д |
| Краткое описание | Н/Д | 80 символов |
| Ключевые слова | 100 символов | Н/Д |
| Рекламный текст | 170 символов | Н/Д |
| Полное описание | 4000 символов | 4000 символов |
| Что нового | 4000 символов | 500 символов |

### Структура описания { #description-structure }

```
PARAGRAPH 1: Hook (50-100 words)
├── Address user pain point
├── State main value proposition
└── Include primary keyword

PARAGRAPH 2-3: Features (100-150 words)
├── Top 5 features with benefits
├── Bullet points for scanability
└── Secondary keywords naturally integrated

PARAGRAPH 4: Social Proof (50-75 words)
├── Download count or rating
├── Press mentions or awards
└── Summary of user testimonials

PARAGRAPH 5: Call to Action (25-50 words)
├── Clear next step
└── Reassurance (free trial, no signup)
```

## Воркфлоу анализа конкурентов { #competitor-analysis-workflow }

Проанализируйте ведущих конкурентов, чтобы выявить пробелы в ключевых словах и возможности позиционирования.

### Воркфлоу: Анализ стратегии ASO конкурентов { #workflow-analyze-competitor-aso-strategy }

1. Определите 10 лучших конкурентов:
   - Прямые конкуренты (та же основная функция)
   - Косвенные конкуренты (перекрывающаяся аудитория)
   - Лидеры категории (лучшие загрузки)
2. Извлеките ключевые слова конкурентов из:
   - Названия приложений и субтитры
   - Первые 100 слов описания
   - Видимые шаблоны метаданных
3. Создайте матрицу ключевых слов конкурентов:
   - Определите, на какие ключевые слова нацелен каждый конкурент
   - Рассчитайте процент охвата по каждому ключевому слову
4. Выявлять пробелы в ключевых словах:
   - Ключевые слова с охватом конкурентов менее 40%
   - Условия большого объема, которые упускают конкуренты
   - Возможности "длинного хвоста"
5. Анализ визуальных ресурсов конкурентов:
   - Шаблоны оформления значков
   - Сообщения со скриншотами и стиль
   - Наличие и качество видео
6. Сравните рейтинги и ревью-шаблоны:
   - Средний рейтинг по конкурентам
   - Общие темы для восхваления
   - Распространенные темы жалоб
7. Возможности позиционирования документов
8. ** Проверка:** Проанализировано более 10 конкурентов; заполнена матрица ключевых слов; выявлены пробелы с оценкой объема; задокументирован визуальный аудит.

### Матрица анализа конкурентов { #competitor-analysis-matrix }

| Область анализа | Точки данных |
|---------------|-------------|
| Ключевые слова | Ключевые слова заголовка, частота описания |
| Метаданные | Использование символов, плотность ключевых слов |
| Визуальные эффекты | Стиль значка, количество скриншотов/стиль оформления |
| Рейтинги | Средняя оценка, общее количество, скорость |
| Ревью | Лучшая похвала, лучшие жалобы |

### Шаблон для анализа пробелов { #gap-analysis-template }

| Тип возможности | Пример | Действие |
|------------------|---------|--------|
| Пробел в ключевых словах | "отслеживание привычек" (охват 40%) | Добавить в поле ключевое слово |
| Пробел в характеристиках | Конкуренту не хватает виджета | Выделите на скриншотах |
| Визуальный разрыв | Нет видео в топ-5 | Создать предварительный просмотр приложения |
| Разрыв в обмене сообщениями | Ни в одном из них не упоминается "бесплатно" | Проверьте свободное позиционирование |

## Воркфлоу для запуска приложения { #app-launch-workflow }

Выполните структурированный запуск для обеспечения максимальной начальной видимости.

### Воркфлоу: Запуск приложения в магазинах { #workflow-launch-app-to-stores }

1. Полная предстартовая подготовка (за 4 недели до запуска):
   - Доработать ключевые слова и метаданные
   - Подготовьте все визуальные ресурсы
   - Настройка аналитики (Firebase, Mixpanel)
   - Создайте пресс-подборку и список средств массовой информации
2. Отправить на ревью (за 2 недели до этого):
   - Выполните все требования магазина
   - Проверьте соответствие руководящим принципам
   - Подготовить сообщения о запуске
3. Настройка систем после запуска:
   - Настройка мониторинга ревью
   - Подготовьте шаблоны ответов
   - Настройка времени промптов рейтинга
4. Выполнить день запуска:
   - Убедитесь, что приложение доступно в обоих магазинах
   - Объявлять по всем каналам
   - Начать цикл ответа на ревью
5. Отслеживайте первоначальную производительность (дни 1-7):
   - Скорость загрузки трека ежечасно
   - Отслеживайте ревью и отвечайте в течение 24 часов
   - Документируйте любые проблемы для быстрого устранения
6. Провести 7-дневную ретроспективу:
   - Сравните показатели с прогнозами
   - Определите преимущества быстрой оптимизации
   - Запланируйте первое обновление метаданных
7. Запланируйте первое обновление (через 2 недели после запуска)
8. ** Проверка:** Приложение доступно в магазинах; отслеживание аналитики; ревью ответов в течение 24 часов; скорость загрузки задокументирована; первое обновление запланировано

### Предстартовый чек-лист { #pre-launch-checklist }

| Категория | Предметы |
|----------|-------|
| Метаданные | Название, подзаголовок, описание, ключевые слова |
| Визуальные ресурсы | Иконка, скриншоты (всех размеров), видео |
| Соответствие требованиям | Возрастной рейтинг, политика конфиденциальности, права на контент |
| Технический | Двоичный файл приложения, подписывающий сертификаты |
| Аналитика | Интеграция SDK, отслеживание событий |
| Маркетинг | Пресс-подборка, социальный контент, готовая электронная почта |

### Соображения о сроках запуска { #launch-timing-considerations }

| Фактор | Рекомендация |
|--------|----------------|
| День недели | Вторник-среда (избегайте выходных) |
| Время суток | Утро в часовом поясе целевого рынка |
| Сезонный | Согласовать с соответствующей категорией сезонов |
| Конкуренция | Избегайте дат запуска основных конкурентов |

## A/B-тестирование воркфлоу { #ab-testing-workflow }

Протестируйте метаданные и визуальные элементы, чтобы повысить коэффициент конверсии.

### Воркфлоу: Запустите A/B-тест { #workflow-run-ab-test }

1. Выберите тестовый элемент (расставьте приоритеты по воздействию):
   - Значок (наибольший эффект)
   - Снимок экрана 1 (ударопрочный)
   - Название (высокая отдача)
   - Краткое описание (среднее воздействие)
2. Сформулируйте гипотезу:
   ```
   If we [change], then [metric] will [improve/increase] by [amount]
   because [rationale].
   ```
3. Создавайте варианты:
   - Управление: Текущая версия
   - Обработка: Однократное изменение переменной
4. Рассчитать необходимый размер выборки:
   - Базовый коэффициент пересчета
   - Минимальный обнаруживаемый эффект (обычно 5%)
   - Статистическая значимость (95%)
5. Тест на запуск:
   - Apple: Используйте оптимизацию страницы продукта
   - Android: Используйте эксперименты со списком магазинов
6. Запустите тест в течение минимальной продолжительности:
   - Не менее 7 дней
   - До достижения статистической значимости
7. Анализ результатов:
   - Сравните коэффициенты конверсии
   - Проверка статистической значимости
   - Документируйте полученные знания
8. **Валидация:** Протестирована единственная переменная; размер выборки достаточен; достигнута значимость (95%); результаты задокументированы; победитель определен

### Определение приоритетов A/B-тестов { #ab-test-prioritization }

| Элемент | Влияние конверсии | Сложность теста |
|---------|-------------------|-----------------|
| Значок приложения | возможен подъем на 10-25% | Средний (требуется дизайн) |
| Скриншот 1 | возможен подъем на 15-35% | Средний |
| Название | возможен подъем на 5-15% | Низкий |
| Краткое описание | возможен подъем на 5-10% | Низкий |
| Видео | возможен подъем на 10-20% | Высокий |

### Краткая справка о размере выборки { #sample-size-quick-reference }

| Базовый CVR | Необходимые показы (для каждого варианта) |
|--------------|----------------------------------|
| 1% | 31,000 |
| 2% | 15,500 |
| 5% | 6,200 |
| 10% | 3,100 |

### Шаблон тестовой документации { #test-documentation-template }

```
TEST ID: ASO-2025-001
ELEMENT: App Icon
HYPOTHESIS: A bolder color icon will increase conversion by 10%
START DATE: [Date]
END DATE: [Date]

RESULTS:
├── Control CVR: 4.2%
├── Treatment CVR: 4.8%
├── Lift: +14.3%
├── Significance: 97%
└── Decision: Implement treatment

LEARNINGS:
- Bold colors outperform muted tones in this category
- Apply to screenshot backgrounds for next test
```

### Оптимизация заголовка { #title-optimization }

** Приложение для повышения производительности:**

| Версия | Название | Анализ |
|---------|-------|----------|
| До того, как | "Мои задачи" | Без ключевых слов, только бренд (8 символов) |
| После | "MyTasks - Список дел и планировщик" | Первичные + вторичные ключевые слова (29 символов) |

** Фитнес-приложение:**

| Версия | Название | Анализ |
|---------|-------|----------|
| До того, как | "FitTrack Pro" | Общий модификатор (12 символов) |
| После | "FitTrack: Журнал тренировок и тренажерный зал" | Ключевые слова категории (27 символов) |

### Оптимизация субтитров (iOS) { #subtitle-optimization-ios }

| Версия | Подзаголовок | Анализ |
|---------|----------|----------|
| До того, как | "Доводи дело до конца" | Расплывчато, без ключевых слов |
| После | "Менеджер ежедневных задач и планировщик" | Два ключевых слова, очевидная выгода |

### Оптимизация полей ключевых слов (iOS) { #keyword-field-optimization-ios }

**До (неэффективно - 89 символов, 8 ключевых слов):**
```
task manager, todo list, productivity app, daily planner, reminder app
```

**После (оптимизировано - 97 символов, 14 ключевых слов):**
```
task,todo,checklist,reminder,organize,daily,planner,schedule,deadline,goals,habit,widget,sync,team
```

**Улучшения:**
- Удалены пробелы после запятых (+8 символов)
- Удалены дубликаты (диспетчер задач → задача)
- Удалено множественное число (напоминания → напоминание)
- Удаленные слова в названии
- Добавлены более релевантные ключевые слова

### Описание Открытия { #description-opening }

**До того, как:**
```
MyTasks is a comprehensive task management solution designed
to help busy professionals organize their daily activities
and boost productivity.
```

**После:**
```
Forget missed deadlines. MyTasks keeps every task, reminder,
and project in one place—so you focus on doing, not remembering.
Trusted by 500,000+ professionals.
```

**Улучшения:**
- Выводы с болевой точкой пользователя
- Конкретная выгода (не общее "повышение производительности")
- Социальное доказательство включало
- Ключевые слова натуральный, не фаршированный

### Эволюция подписи к скриншоту { #screenshot-caption-evolution }

| Версия | Подпись | Проблема |
|---------|---------|-------|
| До того, как | "Функция списка задач" | Функционально ориентированный, пассивный |
| Лучше | "Создавать списки задач" | Глагол действия, но все же отличительный признак |
| Лучший | "Никогда не пропускай крайний срок" | Ориентированный на выгоду, эмоциональный |

## Проактивные триггеры { #proactive-triggers }

- ** В названии нет оптимизации по ключевым словам ** → Название приложения является фактором ранжирования №1. Включите ключевое слово top.
- ** Скриншоты не показывают значения ** → Скриншоты должны рассказывать историю, а не показывать пользовательский интерфейс.
- ** Стратегия без рейтингов ** → Рейтинг ниже 4,0 звезд снижает конверсию. Внедрите промпты для оценки в приложении.
- ** Описание с наполнением ключевыми словами ** → Естественный язык с ключевыми словами превосходит наполнение ключевыми словами.

## Общение { #communication }

Вся продукция проходит проверку качества:
- Самопроверка: указание источника, аудит предположений, оценка достоверности
- Формат вывода: Итоговая строка → Что (с уверенностью) → Почему → Как действовать
- Только результаты. Каждая находка помечена тегами: "проверено", "средний", "предполагается".
