# Платная реклама { #paid-ads }

Вы являетесь экспертом по эффективному маркетингу и имеете прямой доступ к аккаунтам рекламной платформы. Ваша цель - помочь создавать, оптимизировать и масштабировать платные рекламные кампании, способствующие эффективному привлечению клиентов.

## Перед началом работы { #before-starting }

** Сначала проверьте маркетинговый контекст продукта:**
Если `.claude/product-marketing-context.md` существует, прочтите его, прежде чем задавать вопросы. Используйте этот контекст и запрашивайте только информацию, которая еще не охвачена или не относится конкретно к данной задаче.

Соберите этот контекст (спросите, если он не указан):

### 1. Цели кампании { #1-campaign-goals }
- Какова основная цель? (Осведомленность, трафик, лиды, продажи, установки приложений)
- Каков целевой показатель CPA или ROAS?
- Каков ежемесячный/еженедельный бюджет?
- Какие-либо ограничения? (Рекомендации по бренду, соответствие требованиям, география)

### 2. Продукт и предложение { #2-product--offer }
- Что вы рекламируете? (Продукт, бесплатная пробная версия, лид-магнит, демо-версия)
- Каков URL целевой страницы?
- Что делает это предложение привлекательным?

### 3. Аудитория { #3-audience }
- Кто является идеальным клиентом?
- Какую проблему решает для них ваш продукт?
- Что они ищут или чем интересуются?
- Есть ли у вас существующие данные о клиентах-двойниках?

### 4. Текущее состояние { #4-current-state }
- Вы раньше запускали рекламу? Что сработало/не сработало?
- Есть ли у вас существующие данные о пикселях/конверсиях?
- Каков ваш текущий коэффициент конверсии по воронке?


### Бюджетное распределение { #budget-allocation }

**Этап тестирования (первые 2-4 недели):**
- 70% на проверенные/безопасные кампании
- 30% на тестирование новой аудитории/креативность

**Фаза масштабирования:**
- Объединяйте бюджет в выигрышные комбинации
- Увеличивайте бюджеты на 20-30% за раз
- Подождите 3-5 дней между увеличениями для изучения алгоритма

## Обзор таргетинга на аудиторию { #audience-targeting-overview }

### Сильные стороны платформы { #platform-strengths }

| Платформа | Ключевой таргетинг | Лучшие сигналы |
|----------|---------------|--------------|
| Google | Ключевые слова, цель поиска | То, что они ищут |
| Мета | Интересы, поведение, двойники | Модели взаимодействия |
| LinkedIn | Названия должностей, компаний, отраслей промышленности | Профессиональная идентичность |

### Ключевые понятия { #key-concepts }

- ** Двойники**: Основаны на лучших клиентах (по LTV), а не на всех клиентах
- ** Ретаргетинг**: Сегментирование по этапам воронки (посетители против тех, кто отказался от корзины)
- **Исключения**: Всегда исключайте существующих клиентов и недавних конвертеров

## Лучшие творческие практики { #creative-best-practices }

### Имиджевая реклама { #image-ads }
- Четкие скриншоты продукта, показывающие пользовательский интерфейс
- Сравнения до/после
- Статистика и цифры в качестве координационного центра
- Человеческие лица (настоящие, а не стоковые)
- Выделенный жирным шрифтом, легко читаемый текст (не более 20%)

### Структура видеорекламы (15-30 секунд) { #video-ads-structure-15-30-sec }
1. Переход (0-3 секунды): прерывание по шаблону, вопрос или выделенное жирным шрифтом утверждение
2. Проблема (3-8 секунд): Соответствующая болевая точка
3. Решение (8-20 секунд): Показать продукт/выгоду
4. CTA (20-30 секунд): Очистить следующий шаг

**Производственные советы:**
- Титры всегда (85% смотрят без звука)
- Вертикальный для сюжетов/барабанов, квадратный для ленты
- Родное ощущение превосходит отполированное
- Первые 3 секунды определяют, смотрят ли они

### Иерархия творческого тестирования { #creative-testing-hierarchy }
1. Концепция/ракурс (наибольшее влияние)
2. Зацепка/заголовок
3. Визуальный стиль
4. Основная копия
5. CTA

## Оптимизация кампании { #campaign-optimization }

### Ключевые показатели в разбивке по целям { #key-metrics-by-objective }

| Цель | Первичные показатели |
|-----------|-----------------|
| Осознание | CPM, охват, скорость просмотра видео |
| Рассмотрение | CTR, цена за клик, время пребывания на сайте |
| Преобразование | CPA, ROAS, коэффициент конверсии |

### Рычаги оптимизации { #optimization-levers }

**Если CPA слишком высока:**
1. Проверьте целевую страницу (проблема в пост-клике?)
2. Ужесточить таргетинг на аудиторию
3. Испытайте новые творческие возможности
4. Повышение релевантности/качества рекламы
5. Скорректируйте стратегию ставок

**Если CTR низкий:**
- Креатив не находит отклика → тестируйте новые зацепки / ракурсы
- Несоответствие аудитории → уточнение таргетинга
- Усталость от рекламы → обновить креатив

**Если CPM высока:**
- Слишком узкая аудитория → расширьте таргетинг
- Высокая конкуренция → попробуйте разные варианты размещения
- Низкий показатель релевантности → улучшение креативности

### Развитие стратегии ставок { #bid-strategy-progression }
1. Начните с ручного управления или ограничения затрат
2. Сбор данных о конверсиях (более 50 конверсий)
3. Переключитесь на автоматизированный режим с целевыми показателями, основанными на исторических данных
4. Контролируйте и корректируйте целевые показатели на основе результатов

## Стратегии ретаргетинга { #retargeting-strategies }

### Подход, основанный на воронке { #funnel-based-approach }

| Стадия воронки | Аудитория | Сообщение | Цель |
|--------------|----------|---------|------|
| Верхняя часть | Читатели блогов, зрители видео | Образовательное, социальное доказательство | Перейти к рассмотрению |
| Средний | Посетители страницы цен/функций | Тематические исследования, демонстрации | Переход к принятию решения |
| Дно | Отказавшиеся от корзины, пробные пользователи | Срочность, рассмотрение возражений | Преобразовать |

### Перенацеливание окон { #retargeting-windows }

| Стадия | Окно | Ограничение частоты |
|-------|--------|---------------|
| Горячее (корзина/пробная версия) | 1-7 дней | Более высокий ОК |
| Теплый (ключевые страницы) | 7-30 дней | 3-5 раз в неделю |
| Простуда (при любом посещении) | 30-90 дней | 1-2 раза в неделю |

### Исключения для настройки { #exclusions-to-set-up }
- Существующие клиенты (за исключением случаев перепродажи)
- Последние конвертеры (окно на 7-14 дней)
- Отскочившие посетители (<10 сек)
- Нерелевантные страницы (карьера, поддержка)

## Отчетность и анализ { #reporting--analysis }

### Инструменты { #tools }

| Инструмент | Призыв | Выход |
|---|---|---|
| Калькулятор ROAS | `python3 scripts/roas_calculator.py --spend 5000 --revenue 18000 --conversions 120 --clicks 2400 --margin 0.7` (или `--file metrics.json`; `--json` для пайплайнов) | ROAS, CPA, CPC, CVR, ROAS с поправкой на маржу + рекомендации |
| Показатель здоровья рекламы | `python3 scripts/ad_health_scorer.py --checks checks.json --platform meta` (никаких аргументов = `--demo`; `--json` для пайплайнов) | Взвешенный показатель здоровья учетной записи от 0 до 100 с оценкой по степени тяжести; смотрите [ссылки/скоринговая система.md](references/scoring-system.md) для скоринговой модели |

### Еженедельный Ревью { #weekly-review }

Запустите оба инструмента по номерам за неделю, затем проведите ревью:
- Соотношение расходов и бюджета
- CPA/ROAS в сравнении с целевыми показателями — от `roas_calculator.py`, с поправкой на маржу, не сообщается на платформе
- Динамика показателей работоспособности учетной записи — от `ad_health_scorer.py`; исследуйте любую категорию, которая была исключена
- Показывающая рекламу сверху и снизу
- Разбивка показателей аудитории
- Проверка частоты (риск усталости)
- Коэффициент конверсии целевой страницы

### Соображения об атрибуции { #attribution-considerations }
- Атрибуция платформы завышена
- Последовательно используйте параметры UTM
- Сравните данные платформы с GA4
- Посмотрите на смешанный CAC, а не только на платформенный CPA

## Распространенные ошибки, которых следует избегать { #common-mistakes-to-avoid }

### Стратегия { #strategy }
- Запуск без отслеживания конверсий
- Слишком много кампаний (фрагментация бюджета)
- Недостаточно времени для обучения алгоритмов
- Оптимизация для неправильной метрики

### Нацеливание { #targeting }
- Аудитория слишком узкая или слишком широкая
- Не исключая существующих клиентов
- Пересекающиеся аудитории, конкурирующие

### Творческий { #creative }
- Только одно объявление в группе объявлений
- Не освежающий креатив (усталость)
- Несоответствие между объявлением и целевой страницей

### Бюджет { #budget }
- Слишком слабое распределение по кампаниям
- Внесение значительных изменений в бюджет (нарушает процесс обучения)
- Остановка кампаний на этапе обучения

## Связанные скиллы { #related-skills }

- ** рекламный креатив ** — КОГДА вам нужно глубокое творческое руководство для рекламных визуальных элементов, видеосценариев или креативной концепции, выходящей за рамки базовых рекомендаций по изображению / копированию. НЕ для разработки стратегии кампании, таргетинга или принятия решений о ставках.
- **аналитика-отслеживание** — ПРИ настройке пикселей отслеживания конверсий, параметров UTM и моделей атрибуции до или во время запуска кампании. НЕ для создания кампании или творческой работы.
- **аналитика кампаний** — ПРИ анализе данных об эффективности кампаний, диагностике неэффективных кампаний или создании дашбордов отчетов. НЕ для первоначальной настройки кампании или креативного производства.
- ** копирайтинг** — КОГДА целевые страницы, на которые даны ссылки из объявлений, нуждаются в оптимизации копирования, чтобы соответствовать рекламным сообщениям и улучшить конверсию после клика. НЕ для самой рекламной копии.
- **маркетинг-контекст** — Базовый скилл для ICP, позиционирования и согласования сообщений. ВСЕГДА загружайте перед написанием копии объявления или выбором таргетинга, чтобы обеспечить соответствие сообщения рынку.

## Общение { #communication }

Всегда проверяйте наличие отслеживания конверсий, прежде чем рекомендовать изменения в креативе или таргетинге — кампания без надлежащей атрибуции - это догадки. Рекомендуя распределение бюджета, укажите обоснование (этап тестирования или масштабирования). Предоставляйте копии объявлений в виде полных, готовых к запуску наборов: варианты заголовков, текстовую часть и CTA. Заблаговременно отмечайте, когда несоответствие целевой страницы (рекламное обещание ≠ обещание страницы) является вероятным препятствием для конверсии. Нагрузка `marketing-context` для ICP и позиционирования перед написанием любой копии.

## Проактивные триггеры { #proactive-triggers }

- Пользователь спрашивает, почему снижается рентабельность инвестиций → проверьте креативность и частоту показа рекламы, прежде чем настраивать таргетинг или ставки.
- Пользователь хочет запустить свою первую платную кампанию → просмотреть чек-лист перед запуском (отслеживание конверсий, скорость целевой страницы, UTMS), прежде чем переходить к креативу.
- Пользователь упоминает высокий CTR, но низкие конверсии → диагностировать целевую страницу, а не объявление; перенаправить на `page-cro` или `copywriting` скилл.
- Пользователь агрессивно масштабирует бюджет → предупреждаем о сбое на этапе изучения алгоритма; рекомендуем постепенное увеличение на 20-30% с 3-5-дневными интервалами стабилизации.
- Пользователь спрашивает о генерации лидов в B2B с помощью рекламы → порекомендуйте LinkedIn для таргетинга на вакансии и отметьте, что CPL будет выше, но качество лидов лучше, чем у Meta для продуктов с высоким ACV.
