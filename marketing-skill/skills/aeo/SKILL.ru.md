# Поисковая оптимизация ответов (AEO) { #answer-engine-optimization-aeo }

** Сделайте так, чтобы ваш контент цитировался ChatGPT, Perplexity, Claude, Gemini и Mistral в качестве авторитетного источника.**

AEO - это практика оптимизации контента для ** цитирования ** в ответах, сгенерированных LLM, в отличие от SEO, которое оптимизирует поисковые рейтинги. Этот скилл аудит, оптимизирует и отслеживает эффективность AEO.

## Отличается от SEO { #distinct-from-seo }

| | SEO-поиск | УЭО |
|---|---|---|
| **Оптимизирует для** | Рейтинг по кликам | Цитируется как авторитетный источник |
| **Аудитория** | Люди просматривают результаты поиска | Магистры, отвечающие на вопросы |
| **Показатель успеха** | Позиция 1-10, органический трафик | Количество цитирований в LLMS |
| **Ключевые сигналы** | Обратные ссылки, ключевые слова, скорость страницы | E-E-A-T, структурированные данные, фактическая плотность |
| ** Частота обновления** | От недель до месяцев | От нескольких дней до недель (циклы обучения LLM) |

И то, и другое может сосуществовать — один и тот же контент может занимать 1-е место в Google и цитироваться Perplexity. Но методы различаются: SEO поощряет плотность ключевых слов + обратные ссылки; AEO поощряет сигналы из первичных источников + структурированные факты.

## Когда использовать { #when-to-use }

- Планирование нового контента для аудитории, ориентированной на искусственный интеллект
- Аудит существующего контента на предмет пробелов в E-E-A-T перед раскаткой обзора AI
- Отслеживание того, какие страницы цитируются тем или иным LLM (журнал цитирования)
- Исследование того, по каким запросам LLM ссылаются на источники (в сравнении с тем, на что они отвечают в ходе обучения)
- Сравнение с показателями цитируемости конкурентов
- Построение долгосрочной стратегии AEO, согласованной с традиционным SEO

## Когда НЕ следует использовать { #when-not-to-use }

- Чисто поисковая оптимизация по кликам без намеренного использования LLM-цитирования `marketing-skill/skills/seo-audit` вместо этого
- Контент, озвученный брендом, без фактических утверждений - для цитирования требуются факты
- Контент по теме, где у LLM уже есть сильный обучающий сигнал (например, элементарная математика) — прирост цитируемости минимален
- Контент, чувствительный ко времени (последние новости) - задержка в обучении LLM означает, что цитаты приходят месяцами позже

## Основные возможности { #core-capabilities }

### 1. Аудит контента + оценка E-E-A-T { #1-content-audit--e-e-a-t-scoring }

Аудитор (`aeo_audit.py`) оценивает контент по 4 измерениям:

- ** Опыт **: Свидетельства от первого лица, датированные примеры, тематические исследования, заявления "Мы запустили X в 2026 году".
- **Экспертные знания**: Биография автора, полномочия, ссылки на ревью-источники, техническая глубина
- **Авторитетность**: Внешние обратные ссылки с авторитетных доменов, schema.org разметка, структурированные данные
- ** Надежность**: HTTPS, контактная информация, прозрачные исправления, фактическая плотность (количество проверяемых утверждений на 1000 слов)

Сводный балл от 0 до 100 с разбивкой по измерениям. Результат: отчет Markdown с конкретными рекомендациями по исправлению.

### 2. Оптимизация контента { #2-content-optimization }

Оптимизатор (`aeo_optimizer.py`) генерирует улучшенные варианты AEO:

- **Переписывание структуры** — Иерархия H2/H3 оптимизирована для синтаксического анализа LLM
- ** Повышение плотности цитирования** — добавляет `[1]`-ссылки на стиль с источниками
- **Внедрение схемы** — генерирует JSON-LD для часто задаваемых вопросов, инструкций, схем статей
- **Fact-first lede** — переносит проверяемые утверждения в первые 200 слов

Три режима: `conservative` (коснитесь <10% слов), `balanced` (касание <30%), `aggressive` (переписать для максимального УЭО).

### 3. Отслеживание цитируемости { #3-citation-tracking }

Следопыт (`citation_tracker.py`) ведет локальный реестр цитат:

- Ввод вручную: вставьте цитату, найденную в выводах ChatGPT/Perplexity/Claude/Gemini
- Отслеживайте, какой URL, какой LLM, какой запрос, какую дату
- Вычислите количество цитирований на страницу, скорость цитирования, охват LLM
- Экспорт в CSV для создания отчетов

Магазины в `~/.aeo-data/citations.json` (локальный, телеметрии нет).

## Воркфлоу { #workflow }

```
0. Pre-flight: bot access
   Check robots.txt against the crawler matrix in references/bot_access_and_monitoring.md
   → a blocked GPTBot/PerplexityBot/ClaudeBot/Google-Extended is the first fix, always

1. Audit existing content
   $ python3 scripts/aeo_audit.py --url https://example.com/blog/post
   → markdown report with composite score + 4-dimension breakdown

2. Apply optimization recommendations
   $ python3 scripts/aeo_optimizer.py --input post.md --mode balanced --output post-aeo.md
   → optimized variant with citations + schema + structural fixes

3. Publish + monitor
   $ python3 scripts/citation_tracker.py --action add --url https://example.com/blog/post \
       --llm perplexity --query "what is AEO" --date 2026-05-17
   → adds entry to local citations.json ledger

4. Report
   $ python3 scripts/citation_tracker.py --action report --url https://example.com/blog/post
   → per-page citation stats: count, LLMs, queries, velocity
```

## Конфигурация { #configuration }

Этот скилл соответствует отраслевым требованиям с помощью per-run `--industry` флаг. Поддерживаемый: `saas`, `healthcare`, `finance`, `legal`, `ecommerce`, `b2b`, `media`, `education`.

Промышленность влияет:
- **Требования к сигналам органов власти** — здравоохранение/finance нужны более строгие ссылки на источники
- **Строгость проверки фактов** — юридический/healthcare помечать непроверяемые утверждения как критические
- ** Стиль цитирования ** — академический или профессиональный - соглашения между журналами и блогами

Пример:
```bash
python3 scripts/aeo_audit.py --url <url> --industry healthcare
# → stricter E-E-A-T thresholds; flags any health claim without primary citation
```

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- ** Ввод ключевых слов для искусственного интеллекта ** — LLM уже извлекают тему из семантики; плотность ключевых слов не повышает вероятность цитирования
- ** Чистый контент, сгенерированный искусственным интеллектом, без ревью со стороны человека ** - общий вывод LLM теряет приоритет из—за алгоритмов поиска RAG, которые ищут отличительный сигнал
- **Фермы цитирования / колеса ссылок ** — современный LLM RAG наказывает связанные сети с низким уровнем полномочий
- **Спам по схеме** — ложный или не поддающийся проверке schema.org заявки фильтруются; отмечайте только реальные, поддающиеся проверке заявки
- ** Оптимизация для одного LLM за счет других ** — распределение цитирований сильно коррелирует между основными LLM, поскольку они используют общие источники обучающих данных; оптимизация для общих сигналов (E-E-A-T), а не для взломов для каждого LLM.
- ** Полное игнорирование SEO ** — Ссылки на AEO часто берутся из источников, которые уже имеют хороший органический рейтинг; AEO и SEO дополняют друг друга, а не заменяют

## Зависимости { #dependencies }

- **только для stdlib** для всех 3 скриптов — нет `pip install` требуемый
- **Необязательно**: `requests` + `beautifulsoup4` если `--url` используемый режим (в противном случае передайте Markdown через `--input` для аудита на основе файлов)
- **Необязательно**: любой ключ API LLM для `query_research` режим (в настоящее время только для scaffold - полное исследование запросов на основе LLM является дорожной картой)

## Хранение { #storage }

Все данные сначала являются локальными:
- `~/.aeo-data/citations.json` — реестр цитирований
- `~/.aeo-data/patterns.json` — библиотека шаблонов успеха
- `~/.aeo-data/audits/<hash>.md` — сохраненные отчеты по аудиту

Никакой телеметрии. Нет облачной синхронизации. Экспорт в CSV в любое время с помощью `citation_tracker.py --action export`.
