> ** Этот скилл был разделен на два специальных скилла. ** Используйте тот, который соответствует вашим намерениям:

| Ты этого хочешь... | Используйте это вместо этого |
|----------------|-----------------|
| ** Напишите ** сообщение в блоге, статью или руководство | [контент-продакшн](../content-production/) |
| ** Планируйте** какой контент создавать, тематические группы, календарь | [контент-стратегия](../content-strategy/) |
| **Анализ голоса бренда** | [контент-продакшн](../content-production/) (включает в себя `brand_voice_analyzer.py`) |

| **Создание контента в социальных сетях** | [социальный контент](../social-content/) |

## Почему произошли такие перемены { #why-the-change }

Оригинал `content-creator` старался делать все: планирование, написание текстов, SEO, социальные сети, озвучивание бренда. Это делало его мастером на все руки. Специальные скиллы позволяют выполнять каждую работу лучше:

- ** производство контента** — полный пайплайн: исследование → краткое описание → черновик → оптимизация → публикация. Включает в себя все инструменты Python от оригинального создателя контента.
- **контент-стратегия** — Стратегическое планирование: тематические кластеры, исследование ключевых слов, календари контента, фреймворки расстановки приоритетов.

## Проактивные триггеры { #proactive-triggers }

- ** Пользователь запрашивает "создатель контента"** → Перейти к созданию контента (наиболее вероятным намерением является написание).
- **Пользователь спрашивает "контент-план" или "что я должен написать"** → Перейти к контент-стратегии.

## Общение { #communication }

Это скилл перенаправления. Направьте пользователя к нужному специалисту — не пытайтесь обработать запрос здесь.

## Связанные скиллы { #related-skills }

- **контент-продакшн**: пайплайн полного выполнения контента (преемник).
- **контент-стратегия**: планирование контента и выбор темы (преемник).
- ** гуманизатор контента **: Постобработка контента с помощью искусственного интеллекта для придания ему аутентичности.
- **маркетинговый контекст**: Базовый контекст, который читают оба преемника.
