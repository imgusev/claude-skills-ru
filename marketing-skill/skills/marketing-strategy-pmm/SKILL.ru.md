## Определение ICP Воркфлоу { #icp-definition-workflow }

Определите идеальный профиль клиента для таргетинга:

1. Проанализируйте существующих клиентов (топ-20% по LTV)
2. Определите общие характеристики фирмы (размер, отрасль, выручка)
3. Картография (инструменты, зрелость, интеграция)
4. Документируйте психографические данные (уровень боли, мотивация, толерантность к риску).
5. Определите 3-5 характеристик покупателя (экономическая, техническая, пользовательская)
6. Проверка на соответствие данным о цикле продаж и оттоке
7. Оценивайте перспективы A/B/C/D на основе соответствия ICP
8. ** Проверка:** Клиенты A-fit имеют самый низкий отток и самое быстрое закрытие

|-----------|--------------|-----------|

| Доход | $5 МЛН-$500 млн | Доступный бюджет |

## Разработка позиционирования { #positioning-development }

Разработайте позиционирование с использованием методологии Эйприл Данфорд:

1. Перечислите конкурентные альтернативы (прямые, смежные, статус-кво)
2. Выделите уникальные атрибуты (функции, которые есть только у вас)
3. Сопоставьте атрибуты с потребительской ценностью (почему это важно)
4. Определите наиболее подходящих клиентов (кого это волнует больше всего)
5. Выберите категорию рынка (общий, нишевый, новая категория)
6. Слой с соответствующими тенденциями (обоснование сроков)
7. Тест с более чем 10 интервью с клиентами
8. ** Проверка:** более 7 клиентов описывают ценность без запроса

### Шаблон заявления о позиционировании { #positioning-statement-template }

```
FOR [target customer]
WHO [statement of need]
THE [product] IS A [category]
THAT [key benefit]
UNLIKE [competitive alternative]
OUR PRODUCT [primary differentiation]
```

### Формула ценностного предложения { #value-proposition-formula }

Шаблон: `[Product] helps [Target Customer] [Achieve Goal] by [Unique Approach]`

Пример: "Acme помогает SaaS-командам среднего звена в 2 раза быстрее реализовывать проекты за счет автоматизации воркфлоу проектов с помощью искусственного интеллекта".

### Иерархия обмена сообщениями { #messaging-hierarchy }

| Уровень | Содержание | Пример |
|-------|---------|---------|
| Заголовок | 5-7 слов | "Отправляйте быстрее благодаря автоматизации с помощью искусственного интеллекта" |
| Подзаголовок | 1 предложение | "Автоматизируйте воркфлоу, чтобы команды могли сосредоточиться на том, что важно" |
| Преимущества | 3-4 пули | Скорость, качество, сотрудничество, стоимость |
| Особенности | Подтверждающие доказательства | Автоматизация искусственного интеллекта → экономия 10 часов в неделю |
| Доказательство | Социальное доказательство | Логотипы клиентов, статистика, тематические исследования |

## Конкурентная разведка { #competitive-intelligence }

Создание конкурентоспособной базы знаний:

1. Определите уровень 1 (прямой), уровень 2 (смежный), уровень 3 (статус-кво)
2. Подпишитесь на продукты конкурентов (практическая оценка)
3. Отслеживайте веб-сайты конкурентов, цены, обмен сообщениями
4. Проанализируйте записи звонков по продажам на предмет упоминаний конкурентов
5. Прочитайте ревью о G2/Capterra (плюсы и минусы)
6. Отслеживание объявлений о вакансиях конкурентов (сигналы дорожной карты)
7. Ежемесячно обновляйте боевые карты
8. ** Подтверждение:** Отдел продаж использует боевые карты более чем в 80% конкурентных сделок

### Структура конкурентного уровня { #competitive-tier-structure }

| Уровень | Определение | Примеры |
|------|------------|----------|
| 1 | Прямой конкурент, той же категории | [Участник A, B] |
| 2 | Смежное решение, перекрывающийся вариант использования | [Альтернативное решение C, D] |
| 3 | Статус-кво (что они делают сегодня) | Электронные таблицы, руководство пользователя, собственные разработки |

### Шаблон боевой карты { #battlecard-template }

```
- [Scenario where you win]

```

### Анализ выигрышей/проигрышей { #winloss-analysis }

Отслеживать ежемесячно:
- Процент побед по конкурентам
- Основные причины выигрыша (соответствие продукта, простота использования, цена)
- Основные причины потерь (отсутствующая функция, цена, взаимосвязь)
- Элементы действий для продукта, продаж, маркетинга

## Планирование запуска продукта { #product-launch-planning }

Планируйте запуски по уровням:

| Уровень | Сфера применения | Время подготовки | Бюджет |
|------|-------|-----------|--------|
| 1 | Новый продукт, основная особенность | 6-8 недель | $50-100 тыс. |
| 2 | Важная особенность, интеграция | 3-4 недели | $10-25 тыс. |
| 3 | Небольшое улучшение | 1 неделя | <5 тысяч долларов |

### Уровень 1 Запуск воркфлоу { #tier-1-launch-workflow }

Выполнить запуск крупного продукта:

1. Начальная встреча по продукту, маркетингу, продажам, CS
2. Определите цели (пайплайн $, MQLS, освещение в прессе)
3. Разрабатывайте позиционирование и обмен сообщениями
4. Создать инструмент для продаж (колода, демо, боевая карта)
5. Создавайте ресурсы кампании (целевую страницу, электронные письма, рекламу)
6. Обучать команды по продажам и CS
7. Провести день запуска (пресса, электронная почта, реклама, исходящие сообщения)
8. Мониторинг и оптимизация в течение 30 дней
9. ** Проверка:** Пайплайн на пути к достижению цели ко 2-й неделе

### Чек-лист на день запуска Day Day { #launch-day-checklist }

- [ ] Распространен пресс-релиз
- [ ] Отправлено объявление по электронной почте
- [ ] Посты в социальных сетях в прямом эфире
- [ ] Платная реклама с полным бюджетом
- [ ] Запущен блиц-опрос по исходящим продажам
- [ ] Уведомление в приложении активно
- [ ] Показатели отслеживаются каждые 2 часа

### Показатели запуска { #launch-metrics }

| Метрика | Ведущий (ежедневно) | Задержка (еженедельно) |
|--------|-----------------|------------------|
| Дорожное движение | Посетители целевой страницы | - |
| Помолвка | Демо-запросы, регистрации | Внедрение функций % |
| Пайплайн | Сгенерированный MQLS | SQLs, пайплайн $ |
| Доход | - | Сделки закрыты, выручка |

## Стимулирование продаж { #sales-enablement }

Снабдите отдел продаж средствами PMM:

1. Создайте колоду продаж (15-20 слайдов, сначала визуальные)
2. Создание одностраничников (продукт, конкуренция, тематическое исследование)
3. Разработка демонстрационного скрипта (30-45 мин с открытием)
4. Написание шаблонов электронных писем (разъяснительная работа, последующая деятельность, закрытие)
5. Создать калькулятор рентабельности инвестиций (затраты на ввод, экономия на выходе)
6. Проводите ежемесячные призывы к активизации
7. Проводить ежеквартальные тренинги (позиционирование, конкурентоспособность)
8. ** Проверка:** Продажи используют активы более чем в 80% случаев

### Структура торговой площадки { #sales-deck-structure }

| Слайд | Содержание |
|-------|---------|
| 1-2 | Название, повестка дня |
| 3-4 | Введение в компанию, постановка проблемы |
| 5-7 | Решение, основные преимущества, демонстрация |
| 8-10 | Дифференциация, тематическое исследование, ценообразование |
| 11-12 | Внедрение, поддержка, следующие шаги |

### Демонстрационный поток { #demo-flow }

```
1. Intro (2 min): Who we are, agenda
2. Discovery (5 min): Their needs, pain points
3. Demo (20 min): Product focused on their use case
4. Q&A (10 min): Objection handling
5. Next steps (3 min): Trial, POC, proposal
```

### Хэндофф по продажам и маркетингу { #sales-marketing-handoff }

| Хэндофф | Частота | Содержание |
|---------|-----------|---------|
| Еженедельная синхронизация | 30 мин | Выигрыш/проигрыш, конкуренция, новые активы |
| Ежемесячное включение | 60 мин | Обновления продуктов, обучение |
| Ежеквартальный ревью | Полдня | Результаты, стратегия, планирование |

## Международная экспансия { #international-expansion }

Систематически выходить на новые рынки:

1. Проверка рыночного спроса (входящие лиды, анализ TAM)
2. Локализовать веб-сайт, цены, юридические
3. Установить охват продаж (аренда или агентство)
4. Адаптируйте обмен сообщениями к культурным особенностям
5. Создавайте местные партнерские отношения и рекомендации
6. Запуск локализованных кампаний
7. Отслеживайте CAC и конверсию по рынкам
8. ** Проверка:** более 3 платежеспособных клиентов с рынка за первые 90 дней

### Рыночный приоритет (серия А) { #market-priority-series-a }

| МЫ | Месяцы 1-6 | 50% | $1 МЛН |
| Великобритания | Месяцы 4-9 | 20% | 500 тысяч долларов |
| ДАЧ | Месяцы 7-12 | 15% | 300 тысяч долларов |
| Франция | Месяцев 10-15 | 10% | 200 тысяч долларов |

## Проактивные триггеры { #proactive-triggers }

- **Отсутствие документированного позиционирования ** → Без четкого позиционирования весь маркетинг - это догадки.
- ** Сообщения по разным каналам отличаются ** → Противоречивая история сбивает покупателей с толку.
- ** ICP не определен ** → Продавать всем означает не продавать никому.
- **Изменение позиции конкурента** → Обнаружен сдвиг на рынке. Ревью свое позиционирование.

## Общение { #communication }

Вся продукция проходит проверку качества:
- Самопроверка: указание источника, аудит предположений, оценка достоверности
- Формат вывода: Итоговая строка → Что (с уверенностью) → Почему → Как действовать
- Только результаты. Каждая находка помечена тегами: "проверено", "средний", "предполагается".

## Связанные скиллы { #related-skills }

- **маркетинговый контекст**: Для определения основополагающего позиционирования. PMM основывается на этом.

- **competitive-intel** (C-Suite): для стратегической конкурентной разведки.
- **cmo-консультант** (C-Suite): Для принятия решений о маркетинговом бюджете и модели роста.
