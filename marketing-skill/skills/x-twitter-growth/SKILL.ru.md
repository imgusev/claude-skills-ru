## Шаг 1 — Аудит профиля { #step-1--profile-audit }

Прежде чем приступать к какой-либо работе по росту, проведите аудит текущего присутствия X. Бежать `scripts/profile_auditor.py` с помощью ручки или вручную оцените:

### Биографический чек-лист Bio Bio { #bio-checklist }
- [ ] Четкое ценностное предложение в первой строке (кому вы помогаете + как)
- [ ] Конкретная ниша — не "предприниматель | мыслитель | строитель"
- [ ] Элемент социального доказательства (подписчики, заголовок, метрика, бренд)
- [ ] CTA или ссылка (новостная рассылка, продукт, сайт)
- [ ] Нет хэштегов в биографии (сигналы любителя)

### Закрепленный твит { #pinned-tweet }
- [ ] Существует, и ему менее 30 дней
- [ ] Демонстрирует лучшую работу или самый сильный крючок
- [ ] Имеет четкий CTA (подписываться, follow, read)

### Недавняя активность (последние 30 сообщений) { #recent-activity-last-30-posts }
- [ ] Частота публикации: минимум 1 раз в день, в идеале 3-5 раз в день
- [ ] Сочетание форматов: твиты, темы, ответы, цитаты
- [ ] Соотношение ответов: >30% активности должны составлять ответы
- [ ] Тенденция вовлеченности: улучшающаяся, неизменная или снижающаяся

Бежать: `python3 scripts/profile_auditor.py --handle @username`

## Шаг 2 — Конкурентная разведка { #step-2--competitive-intelligence }

Изучите конкурентов и успешные аккаунты в вашей нише с помощью веб-поиска.

### Процесс { #process }
1. Поиск `site:x.com "topic" min_faves:100` с помощью Brave можно найти высокоэффективный контент
2. Определите 5-10 аккаунтов в вашей нише с сильной вовлеченностью
3. Для каждого проанализируйте: частоту публикаций, типы контента, схемы подключения, уровень вовлеченности
4. Бежать: `python3 scripts/competitor_analyzer.py --handles @acc1 @acc2 @acc3`

### Что извлекать { #what-to-extract }
- ** Шаблоны крючков ** — С чего начинаются топовые посты? Вопрос? Смелое заявление? Статистика?
- ** Темы контента ** — Какие 3-5 тем привлекают наибольшее внимание?
- ** Сочетание форматов ** — Соотношение твитов и тем, ответов и цитат
- ** Время публикации ** — Когда выходят их лучшие посты?
- ** Триггеры вовлеченности ** — Что заставляет людей отвечать, ставить лайки или ретвитить?

## Шаг 3 — Создание контента { #step-3--content-creation }

### Типы твитов (упорядоченные по влиянию на рост) { #tweet-types-ordered-by-growth-impact }

#### 1. Потоки (самый высокий охват, самая высокая конверсия подписчиков) { #1-threads-highest-reach-highest-follow-conversion }
```
Structure:
- Tweet 1: Hook — must stop the scroll in <7 words
- Tweet 2: Context or promise ("Here's what I learned:")
- Tweets 3-N: One idea per tweet, each standalone-worthy
- Final tweet: Summary + explicit CTA ("Follow @handle for more")
- Reply to tweet 1: Restate hook + "Follow for more [topic]"

Rules:
- 5-12 tweets optimal (under 5 feels thin, over 12 loses people)
- Each tweet should make sense if read alone
- Use line breaks for readability
- No tweet should be a wall of text (3-4 lines max)
- Number the tweets or use "↓" in tweet 1
```

#### 2. Атомарные твиты (широта охвата, количество показов) { #2-atomic-tweets-breadth-impression-farming }
```
Formats that work:
- Observation: "[Thing] is underrated. Here's why:"
- Listicle: "10 tools I use daily:\n\n1. X — for Y"
- Contrarian: "Unpopular opinion: [statement]"
- Lesson: "I [did X] for [time]. Biggest lesson:"
- Framework: "[Concept] explained in 30 seconds:"

Rules:
- Under 200 characters gets more engagement
- One idea per tweet
- No links in tweet body (kills reach — put link in reply)
- Question tweets drive replies (algorithm loves replies)
```

#### 3. Цитируйте твиты (повышение авторитета) { #3-quote-tweets-authority-building }
```
Formula: Original tweet + your unique take
- Add data the original missed
- Provide counterpoint or nuance
- Share personal experience that validates/contradicts
- Never just say "This" or "So true"
```

#### 4. Ответы (рост сети, самый быстрый путь к видимости) { #4-replies-network-growth-fastest-path-to-visibility }
```
Strategy:
- Reply to accounts 2-10x your size
- Add genuine value, not "great post!"
- Be first to reply on accounts with large audiences
- Your reply IS your content — make it tweet-worthy
- Controversial/insightful replies get quote-tweeted (free reach)
```

Бежать: `python3 scripts/tweet_composer.py --type thread --topic "your topic" --audience "your audience"`

## Шаг 4 — Механика алгоритма { #step-4--algorithm-mechanics }

### Какие награды X (2025-2026) { #what-x-rewards-2025-2026 }
| Сигнал | Вес | Действие |
|--------|--------|--------|
| Полученные ответы | Очень высокий | Пишите контент, достойный ответа (вопросы, дебаты) |
| Время, потраченное на чтение | Высокий | Темы, более длинные твиты с разрывами строк |
| Посещения профиля из твита | Высокий | Пробелы в любопытстве, дразнящий опыт |
| Закладки | Высокий | Тактический контент, достойный сохранения (списки, фреймворки) |
| Ретвиты/Цитаты | Средний | Доступные для обмена идеи, смелые подходы |
| Нравится | Низкий-средний | Простое согласование, приемлемый контент |
| Переходы по ссылкам | Низкий (оштрафован) | Никогда не размещайте ссылки в теле твита — используйте ответ |

### То, что убивает, достигает { #what-kills-reach }
- Ссылки в теле твита (вместо этого вставьте в первый ответ)
- Редактирование твитов в течение 30 минут после публикации
- Публикация и немедленный переход в автономный режим (без раннего участия)
- Более 2-х хэштегов
- Отмечать людей, которые не отвечают взаимностью
- Темы с непоследовательным качеством (один слабый твит забивает всю тему)

### Оптимальная частота постинга { #optimal-posting-cadence }
| Размер счета | Твиты в день | Темы/неделя | Ответы/день |
|-------------|------------|--------------|-------------|
| < 1 тыс. подписчиков | 2-3 | 1-2 | 10-20 |
| 1К-10К | 3-5 | 2-3 | 5-15 |
| 10К-50К | 3-7 | 2-4 | 5-10 |
| 50 ТЫСЯЧ+ | 2-5 | 1-3 | 5-10 |

## Шаг 5 — Плейбук для роста { #step-5--growth-playbook }

### Неделя 1-2: Основа { #week-1-2-foundation }
1. Оптимизируйте биографию и закрепленный твит (шаг 1)
2. Определите 20 аккаунтов в вашей нише, с которыми вы будете взаимодействовать ежедневно
3. Отвечайте 10-20 раз в день на более крупные аккаунты (только с подлинной стоимостью)
4. Публикуйте 2-3 атомарных твита в день, тестируя различные форматы
5. Опубликовать 1 поток

### Неделя 3-4: Распознавание образов { #week-3-4-pattern-recognition }
1. Ревью, какие форматы привлекли наибольшее внимание
2. Удвоьте выбор из 2 лучших форматов контента
3. Увеличьте количество постов до 3-5 в день
4. Публикуйте 2-3 темы в неделю
5. Начните цитировать-ежедневно публикуйте в Твиттере релевантный контент

### Месяц 2+: Масштабирование { #month-2-scale }
1. Разработайте 3-5 повторяющихся серий контента (например, "Пятничный фреймворк").
2. Перекрестное опыление: перепрофилируйте темы в качестве постов LinkedIn, контента для новостной рассылки
3. Выстраивайте отношения с ответами с 5-10 аккаунтами вашего размера (взаимное взаимодействие)
4. Поэкспериментируйте с пространствами / звуком, если это имеет отношение к нише
5. Бежать: `python3 scripts/growth_tracker.py --handle @username --period 30d`

## Распространенные подводные камни { #common-pitfalls }

1. ** Размещать ссылки напрямую ** — Всегда размещайте ссылки в первом ответе, никогда в теле твита
2. ** Поток твита 1 слаб ** — Если хук не прекращает прокрутку, все остальное не имеет значения
3. ** Непоследовательная публикация ** — Алгоритм вознаграждает ежедневную согласованность за случайные публикации
4. ** Только трансляция ** — Ответы и вовлеченность увеличиваются более чем на 50%, а не только публикация
5. ** Общая биография ** — "Помогать людям что-то делать" никому ничего не говорит
6. ** Копирование форматов без адаптации ** — То, что работает для технического Твиттера, не работает для маркетингового Твиттера
