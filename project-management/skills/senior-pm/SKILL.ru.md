# Старший эксперт по управлению проектами { #senior-project-management-expert }

## Обзор { #overview }

Стратегическое управление проектами в области корпоративного программного обеспечения, SaaS и инициатив по цифровой трансформации. Предоставляет возможности управления портфелем, инструменты количественного анализа и фреймворки отчетности на уровне руководителей для сложных портфелей из нескольких проектов.

### Основные области специализации { #core-expertise-areas }

**Управление портфелем ценных бумаг и стратегическое согласование**
- Оптимизация портфеля мультипроектов с использованием передовых моделей расстановки приоритетов (WSJF, RICE, ICE, Москва)
- Разработка стратегической дорожной карты в соответствии с бизнес-целями и рыночными условиями
- Планирование ресурсного потенциала и оптимизация распределения по всему портфелю
- Мониторинг работоспособности портфолио с помощью многомерных фреймворков оценки

**Количественное управление рисками**
- Анализ ожидаемой денежной стоимости (EMV) для количественной оценки финансового риска
- Моделирование методом Монте-Карло для моделирования рисков по расписанию и доверительных интервалов
- Внедрение фреймворка склонности к риску с пороговыми значениями на уровне предприятия
- Корреляционный анализ портфельных рисков и стратегии диверсификации

**Коммуникация с руководством и управление**
- Подготовленные Правлением отчеты руководителей со статусом RAG и стратегическими рекомендациями
- Согласование интересов стейкхолдеров с помощью сложных матриц RACI и путей эскалации
- Отслеживание финансовых показателей с учетом скорректированной на риск рентабельности инвестиций и расчетами NPV
- Стратегии управления изменениями для крупномасштабных цифровых преобразований

## Методология и фреймворки { #methodology--frameworks }

### Трехуровневый подход к анализу { #three-tier-analysis-approach }

**Уровень 1: Оценка состояния портфолио**
Использует `project_health_dashboard.py` для обеспечения всесторонней многомерной оценки:

```bash
python3 scripts/project_health_dashboard.py assets/sample_project_data.json
```

**Показатели здоровья (взвешенная оценка):**
- ** Выполнение графика** (вес 25%): Соблюдение графика, достижение основных этапов, анализ критического пути
- **Управление бюджетом** (вес 25%): Разница в расходах, точность прогноза, показатели экономической эффективности
- **Комплект поставки ** (вес 20%): Скорость выполнения функций, удовлетворение требований, контроль изменений
- **Показатели качества** (вес 20%): охват кода, плотность дефектов, техническая задолженность, состояние безопасности.
- **Подверженность риску** (вес 10%): Оценка риска, эффективность снижения, тенденции воздействия

**Расчет состояния тряпки:**
- 🟢 Зеленый: Суммарный балл >80, все измерения >60
- 🟡 Янтарный: Суммарный балл 60-80 или любой размер 40-60
- 🔴 Красный: Суммарный балл <60 или любое измерение <40

**Уровень 2: Матрица рисков и стратегия их снижения**
Рычаги `risk_matrix_analyzer.py` для количественной оценки рисков:

```bash
python3 scripts/risk_matrix_analyzer.py assets/sample_project_data.json
```

**Процесс количественной оценки рисков:**
1. **Оценка вероятности** (шкала от 1 до 5): Исторические данные, экспертное заключение, исходные данные по методу Монте-Карло
2. **Анализ воздействия** (шкала от 1 до 5): Финансовые, временные, качественные и стратегические векторы воздействия
3. ** Взвешивание категорий**: Технические (1,2раза), ресурсные (1,1 раза), финансовые (1,4 раза), График (1,0 раза)
4. **Расчет EMV**:

```python
# EMV and risk-adjusted budget calculation
def calculate_emv(risks):
    category_weights = {"Technical": 1.2, "Resource": 1.1, "Financial": 1.4, "Schedule": 1.0}
    total_emv = 0
    for risk in risks:
        score = risk["probability"] * risk["impact"] * category_weights[risk["category"]]
        emv = risk["probability"] * risk["financial_impact"]
        total_emv += emv
        risk["score"] = score
    return total_emv

def risk_adjusted_budget(base_budget, portfolio_risk_score, risk_tolerance_factor):
    risk_premium = portfolio_risk_score * risk_tolerance_factor
    return base_budget * (1 + risk_premium)
```

**Стратегии реагирования на риски (по пороговому значению баллов):**
- **Избегать** (>18): Устранять путем изменения сферы применения/подхода
- **Смягчение последствий** (12-18): Снижение вероятности или воздействия путем активного вмешательства
- **Передача** (8-12): Страхование, контракты, партнерства
- **Принять** (<8): Мониторинг с планированием на случай непредвиденных обстоятельств

**Уровень 3: Оптимизация ресурсного потенциала**
Нанимает `resource_capacity_planner.py` для анализа ресурсов портфеля:

```bash
python3 scripts/resource_capacity_planner.py assets/sample_project_data.json
```

** Фреймворк для анализа потенциала:**
- ** Оптимизация использования**: Целевой показатель 70-85% для обеспечения устойчивой производительности
- ** Соответствие скиллам**: Распределение ресурсов на основе алгоритма для максимальной эффективности
- **Выявление узких мест**: Критические ограничения ресурсов по всему портфелю
- **Сценарное планирование**: анализ "что, если" для стратегий перераспределения ресурсов

### Усовершенствованные модели расстановки приоритетов { #advanced-prioritization-models }

Применяйте каждую модель в конкретном контексте, где она обеспечивает наибольший сигнал:

**Взвешенное самое короткое задание в первую очередь (WSJF)** — Гибкие портфолио с ограниченными ресурсами и поддающейся количественной оценке стоимостью задержки
```python
def wsjf(user_value, time_criticality, risk_reduction, job_size):
    return (user_value + time_criticality + risk_reduction) / job_size
```

**RICE** — Инициативы, ориентированные на клиента, в которых показатели охвата поддаются количественной оценке
```python
def rice(reach, impact, confidence_pct, effort_person_months):
    return (reach * impact * (confidence_pct / 100)) / effort_person_months
```

**ICE** — Быстрая расстановка приоритетов во время мозгового штурма или когда время анализа ограничено
```python
def ice(impact, confidence, ease):
    return (impact + confidence + ease) / 3
```

**Выбор модели — используйте эту логику принятия решений:**
```
if resource_constrained and agile_methodology and cost_of_delay_quantifiable:
    → WSJF
elif customer_facing and reach_metrics_available:
    → RICE
elif quick_prioritization_needed or ideation_phase:
    → ICE
elif multiple_stakeholder_groups_with_differing_priorities:
    → MoSCoW
elif complex_tradeoffs_across_incommensurable_criteria:
    → Multi-Criteria Decision Analysis (MCDA)
```

### Фреймворк для управления рисками { #risk-management-framework }

Ссылка: `references/risk-management-framework.md`

**Шаг 1: Классификация рисков по категориям**
- Технические: Архитектура, интеграция, производительность
- Ресурсы: Доступность, скиллы, удержание
- График: Зависимости, критический путь, внешние факторы
- Финансовые: Перерасход бюджета, валюта, экономические факторы
- Бизнес: изменения на рынке, конкурентное давление, стратегические сдвиги

**Шаг 2: Трехточечная оценка исходных данных по методу Монте-Карло**
```python
def three_point_estimate(optimistic, most_likely, pessimistic):
    expected = (optimistic + 4 * most_likely + pessimistic) / 6
    std_dev = (pessimistic - optimistic) / 6
    return expected, std_dev
```

**Шаг 3: Корреляция рисков портфеля**
```python
import math

def portfolio_risk(individual_risks, correlations):
    # individual_risks: list of risk EMV values
    # correlations: list of (i, j, corr_coefficient) tuples
    sum_sq = sum(r**2 for r in individual_risks)
    sum_corr = sum(2 * c * individual_risks[i] * individual_risks[j]
                   for i, j, c in correlations)
    return math.sqrt(sum_sq + sum_corr)
```

** Фреймворк склонности к риску:**
- **Консервативный**: Оценка риска 0-8, резервы на случай непредвиденных обстоятельств составляют 25-30%.
- **Умеренный**: Оценка риска 8-15 баллов, 15-20% резервов на случай непредвиденных обстоятельств
- **Агрессивный**: Оценка риска 15+, 10-15% резервов на случай непредвиденных обстоятельств

## Воркфлоу по внедрению { #implementation-workflows }

### Ревью состояния портфолио (еженедельно) { #portfolio-health-review-weekly }

1. **Сбор и проверка данных**
   ```bash
   python3 scripts/project_health_dashboard.py current_portfolio.json
   ```
   ⚠️ Если какой-либо суммарный балл проекта <60 или отсутствует критическое поле данных, остановитесь и устраните проблемы с целостностью данных, прежде чем продолжить.

2. **Обновление оценки рисков**
   ```bash
   python3 scripts/risk_matrix_analyzer.py current_portfolio.json
   ```
   ⚠️ Если какой-либо показатель риска превышает 18 (порог избегания), остановитесь и инициируйте эскалацию до спонсора проекта, прежде чем продолжить.

3. **Анализ потенциала**
   ```bash
   python3 scripts/resource_capacity_planner.py current_portfolio.json
   ```
   ⚠️ Если загрузка какой-либо команды >90% или <60%, отметьте для немедленного обсуждения перераспределения перед шагом 4.

4. **Составление резюме**
   - Обобщение результатов в формате исполнительного отчета
   - Выделите важнейшие вопросы и рекомендации
   - Подготовка сообщений для стейкхолдеров

### Ежемесячный стратегический ревью { #monthly-strategic-review }

1. **Ревью по определению приоритетов портфеля**
   - Применяйте модели WSJF/RICE/ICE для оценки текущих приоритетов
   - Оценка стратегического соответствия бизнес-целям
   - Определите возможности оптимизации

2. **Анализ портфеля рисков**
   - Обновите уровни склонности к риску и толерантности к нему
   - Ревью корреляции и концентрации рисков портфеля
   - Скорректировать инвестиции в снижение рисков

3. **Планирование оптимизации ресурсов**
   - Проанализируйте ограничения производственных мощностей в предстоящем квартале
   - Планируйте стратегии перераспределения ресурсов и найма персонала
   - Выявлять пробелы в скиллах и потребности в обучении

4. **Сессия согласования интересов стейкхолдеров**
   - Представьте портфолио медицинских и стратегических рекомендаций
   - Соберите отзывы о расстановке приоритетов и распределении ресурсов
   - Согласовать приоритеты и инвестиции на предстоящий квартал

### Ежеквартальная оптимизация портфеля { #quarterly-portfolio-optimization }

1. **Оценка стратегической согласованности**
   - Оценить вклад портфеля в достижение бизнес-целей
   - Оценка изменений на рынке и конкурентных позиций
   - Обновите стратегические приоритеты и критерии успеха

2. **Ревью финансовых показателей**
   - Проанализируйте рентабельность инвестиций с поправкой на риск по всему портфелю
   - Ревью исполнения бюджета и точности прогнозов
   - Оптимизируйте распределение инвестиций для получения максимальной отдачи

3. **Анализ пробелов в возможностях**
   - Определите новые требования к технологиям и скиллам
   - Планируйте инвестиции в наращивание потенциала
   - Оценить марку по сравнению с решения о покупке в сравнении с решениями о партнерстве

4. **Перебалансировка портфеля**
   - Примените модель трех горизонтов для обеспечения инновационного баланса
   - Оптимизируйте соотношение риска и доходности, используя эффективные границы
   - Планируйте новые инициативы и окончательные решения

- Корректировка уровня склонности к риску и толерантности

## Показатели успеха и ключевые показатели эффективности { #success-metrics--kpis }

Ссылка: `references/portfolio-kpis.md` для получения полных определений и рекомендаций по измерениям.

### Эффективность портфеля { #portfolio-performance }
- Своевременная доставка: >80% в пределах 10% от запланированного срока
- Отклонение бюджета: <5% в среднем по портфелю
- Оценка качества: >85 сводный рейтинг
- Охват по снижению рисков: >90% рисков при активных планах
- Использование ресурсов: в среднем 75-85%

### Стратегическая ценность { #strategic-value }
- Достижение рентабельности инвестиций: >90% проектов соответствуют прогнозам в течение 12 месяцев
- Стратегическое соответствие: >95% инвестиций соответствуют бизнес-приоритетам
- Баланс инноваций: 70% операционных / 20% роста / 10% трансформационных
- Удовлетворенность стейкхолдеров: >8,5/10 в среднем для руководителей
- Время до получения значения: в среднем <6 месяцев после завершения

### Управление рисками { #risk-management }
- Подверженность риску: Поддерживайте аппетит в пределах утвержденных пределов
- Время разрешения: <30 дней (среднее), <7 дней (высокое)
- Экономическая эффективность снижения рисков: <20% от общего EMV портфельного риска
- Точность прогнозирования риска: точность оценки вероятности >70%

## Фреймворк непрерывного совершенствования { #continuous-improvement-framework }

### Интеграция обучения с портфолио { #portfolio-learning-integration }
- Обобщать уроки, извлеченные из завершенных проектов
- Обновлять оценки вероятности риска на основе исторических данных
- Повысить точность оценки с помощью ретроспектива-анализа
- Обмениваться передовым опытом между проектными командами

### Эволюция методологии { #methodology-evolution }
- Регулярный ревью эффективности модели расстановки приоритетов
- Обновление фреймворков управления рисками на основе лучших отраслевых практик
- Интегрируйте новые инструменты и технологии для повышения эффективности анализа
- Сравнение со стандартами эффективности отраслевого портфеля

### Интеграция обратной связи с стейкхолдерами { #stakeholder-feedback-integration }
- Ежеквартальные опросы удовлетворенности стейкхолдеров

- Отзывы команды об эффективности процесса
- Оценка влияния портфельных решений на клиента
