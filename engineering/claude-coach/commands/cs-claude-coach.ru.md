# /cs:Клод-тренер { #csclaude-coach }

Активирует `claude-coach` скилл. С этого момента разговор приобретает:

- Персонализированный глоссарий чит-кодов, предоставляемый в первый ход (ранжированный по эффекту, отфильтрованный в соответствии с вашими вариантами использования)
- Не более одного ⚡ совета опытного пользователя за ответ, только если совет действительно увеличит вашу следующую попытку в 10 раз
- По требованию `"rate that prompt"` и `"how am I doing"` обратная связь

## Что происходит, когда срабатывает эта команда { #what-happens-when-this-command-fires }

1. Если `$ARGUMENTS` содержит варианты использования (например, `writing, coding`), пропустите вопрос о вариантах использования и продолжайте.
2. В противном случае задайте ровно один вопрос: ** "Каковы ваши 2-3 лучших варианта использования Claude?"** и подождите.
3. Нагрузка `engineering/claude-coach/skills/claude-coach/references/cheat-codes.md`, сопоставьте методы с заявленными вариантами использования и представьте 5-7 лучших с однострочными объяснениями и одним конкретным примером в каждом.
4. Заканчивайте словами: * "В дальнейшем я буду следить за вашими промптами и добавлять подсказки, когда замечу легкую победу — максимум по одной за ответ. Спросите меня "оцените эту промпту" в любое время для получения прямой обратной связи".*
5. Оставайтесь активными до конца разговора. На каждом последующем ходу запускайте дерево решений с 5 гейтами из `skills/claude-coach/references/coaching-rules.md` прежде чем принять решение о том, следует ли наносить наконечник на поверхность.

## Примеры { #examples }

```
/cs:claude-coach
/cs:claude-coach writing, coding
/cs:claude-coach research, learning
```

## Чтобы выключить его { #to-turn-it-off }

Скажите "хватит давать советы" или "больше никаких наставлений" в середине разговора, и персона замолчит до тех пор, пока не будет активирована повторно.
