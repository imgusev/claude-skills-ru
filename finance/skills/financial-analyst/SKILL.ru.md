# Скилл финансового аналитика { #financial-analyst-skill }

## Обзор { #overview }

Готовый к производству инструментарий финансового анализа, обеспечивающий анализ коэффициентов, оценку DCF, анализ отклонений бюджета и построение скользящего прогноза. Предназначен для финансового моделирования, прогнозирования и составления бюджета, управленческой отчетности, анализа эффективности бизнеса и инвестиционного анализа.

## 5-Фазный воркфлоу { #5-phase-workflow }

### Этап 1: Определение сферы охвата { #phase-1-scoping }
- Определите цели анализа и требования к стейкхолдерам
- Определите источники данных и периоды времени
- Установите пороговые значения существенности и целевые показатели точности
- Выберите подходящие аналитические фреймворки

### Этап 2: Анализ данных и моделирование { #phase-2-data-analysis--modeling }
- Сбор и проверка финансовых данных (отчет о прибылях и убытках, балансовый отчет, движение денежных средств)
- ** Проверьте полноту входных данных** перед выполнением расчетов коэффициентов (проверьте, нет ли пропущенных полей, нулей или неправдоподобных значений)
- Рассчитайте финансовые коэффициенты по 5 категориям (прибыльность, ликвидность, кредитное плечо, эффективность, оценка).
- Построение моделей DCF с вычислениями значений WACC и терминала; ** перекрестная проверка выходных данных DCF на соответствие допустимым пределам** (например, подразумеваемые кратные значения по сравнению с сопоставимыми)
- Постройте анализ отклонений бюджета с благоприятными/unfavorable классификация
- Разрабатывайте прогнозы на основе факторов с помощью сценарного моделирования

### Фаза 3: Генерация инсайта { #phase-3-insight-generation }
- Интерпретируйте тенденции соотношения и сравнивайте их с отраслевыми стандартами
- Выявлять существенные отклонения и коренные причины
- Оцените диапазоны оценки с помощью анализа чувствительности
- Оценка прогнозных сценариев (базовый/bull/bear) для поддержки принятия решений

### Этап 4: Отчетность { #phase-4-reporting }
- Составляйте резюме с ключевыми выводами
- Составляйте подробные отчеты об отклонениях в разбивке по отделам и категориям
- Предоставлять отчеты об оценке DCF с таблицами чувствительности
- Представлять текущие прогнозы с анализом тенденций

### Этап 5: Последующая деятельность { #phase-5-follow-up }
- Отслеживание точности прогноза (цель: +/-5% выручки, +/-3% расходов)
- Контролировать своевременность предоставления отчетов (цель: 100% в срок)
- Обновляйте модели актуальными данными по мере их поступления
- Уточнение допущений на основе анализа отклонений

## Инструменты { #tools }

### 1. Калькулятор коэффициентов (`scripts/ratio_calculator.py`) { #1-ratio-calculator-scriptsratio_calculatorpy }

Рассчитывайте и интерпретируйте финансовые коэффициенты на основе данных финансовой отчетности.

**Соотношение категорий:**
- **Рентабельность:** Рентабельность инвестиций в основной капитал, ROA, Валовая маржа, Операционная маржа, Чистая маржа
- **Ликвидность:** Коэффициент текущей ликвидности, коэффициент быстрой ликвидности, коэффициент наличности
- **Кредитное плечо:** Соотношение долга к собственному капиталу, покрытие процентов, DSCR
- **Эффективность:** Оборачиваемость активов, оборачиваемость запасов, оборачиваемость дебиторской задолженности, DSO
- **Оценка:** P/E, P/B, P/S, EV/EBITDA, коэффициент привязки

```bash
python scripts/ratio_calculator.py assets/sample_financial_data.json
python scripts/ratio_calculator.py assets/sample_financial_data.json --format json
python scripts/ratio_calculator.py assets/sample_financial_data.json --category profitability
```

### 2. Оценка DCF (`scripts/dcf_valuation.py`) { #2-dcf-valuation-scriptsdcf_valuationpy }

Оценка предприятия с дисконтированным денежным потоком и собственного капитала с анализом чувствительности.

**Особенности:**
- Расчет WACC с помощью CAPM
- Прогнозы выручки и свободного денежного потока (5-летний дефолт)
- Конечная ценность за счет постоянного роста и выхода несколькими способами
- Определение стоимости предприятия и собственного капитала
- Двусторонний анализ чувствительности (ставка дисконтирования в зависимости от темпов роста)

```bash
python scripts/dcf_valuation.py assets/sample_financial_data.json
python scripts/dcf_valuation.py assets/sample_financial_data.json --format json
python scripts/dcf_valuation.py assets/sample_financial_data.json --projection-years 7
```

### 3. Анализатор отклонений бюджета (`scripts/budget_variance_analyzer.py`) { #3-budget-variance-analyzer-scriptsbudget_variance_analyzerpy }

Проанализируйте фактические показатели по сравнению с бюджетом и показателями предыдущего года с помощью фильтрации существенности.

**Особенности:**
- Расчет отклонения в долларах и процентах
- Фильтрация по порогу существенности (по умолчанию: 10% или 50 тысяч долларов)
- Благоприятный/unfavorable классификация по доходу/expense логика
- Разбивка по отделам и категориям
- Составление исполнительного резюме

```bash
python scripts/budget_variance_analyzer.py assets/sample_financial_data.json
python scripts/budget_variance_analyzer.py assets/sample_financial_data.json --format json
python scripts/budget_variance_analyzer.py assets/sample_financial_data.json --threshold-pct 5 --threshold-amt 25000
```

### 4. Составитель прогнозов (`scripts/forecast_builder.py`) { #4-forecast-builder-scriptsforecast_builderpy }

Прогнозирование выручки на основе драйверов с прогнозированием скользящего денежного потока и сценарным моделированием.

**Особенности:**
- Модель прогнозирования доходов на основе драйверов
- прогноз текущего денежного потока на 13 недель
- Сценарное моделирование (базовое/bull/bear случаи)
- Анализ тренда с использованием простой линейной регрессии (стандартная библиотека)

```bash
python scripts/forecast_builder.py assets/sample_financial_data.json
python scripts/forecast_builder.py assets/sample_financial_data.json --format json
python scripts/forecast_builder.py assets/sample_financial_data.json --scenarios base,bull,bear
```

## Формат входных данных { #input-data-format }

Все скрипты принимают входные файлы JSON в любой из двух форм:

1. **Flat** — ожидаемые клавиши инструмента на верхнем уровне (например,, `income_statement` / `balance_sheet` для калькулятора коэффициентов, `historical` / `assumptions` для постоянного тока, `line_items` для отклонения, `historical_periods` / `drivers` / `assumptions` / `cash_flow_inputs` для прогнозирования).
2. **Вложенный (в комплекте)** — входные данные для всех четырех инструментов в одном файле, вложенные под ключами для каждого инструмента: `ratio_analysis`, `dcf_valuation`, `budget_variance`, `forecast`. Смотри `assets/sample_financial_data.json` для полной схемы в комплекте; каждая команда быстрого запуска, приведенная выше, выполняется непосредственно против нее.

Каждый скрипт автоматически определяет форму (плоские клавиши выигрывают, если они присутствуют) и завершает работу с ненулевым значением с явной ошибкой, если ни одна из форм не дает пригодных для использования данных.
