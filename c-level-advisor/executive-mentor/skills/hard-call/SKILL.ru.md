# /em: фреймворк с жестким вызовом для решений без хороших вариантов { #emhard-call--framework-for-decisions-with-no-good-options }

**Команда:** `/em:hard-call <decision>`

За решения, из-за которых вы не спите в 3 часа ночи. Увольнение соучредителя. Увольнение 20% команды. Уничтожение продукта, который нравится покупателям. Поворачивается. Отключаюсь.

У этих решений нет правильного ответа. У них меньше неправильных ответов. Этот фреймворк поможет вам найти его.

---

## Почему эти решения даются с трудом { #why-these-decisions-are-hard }

Не потому, что данные неясны. Часто данные являются четкими. Они трудные, потому что:

1. ** Страдают реальные люди** — кто-то теряет работу, отношения заканчиваются, команда страдает
2. **Вы избегали принятия решения** — это означает, что проблема уже стала хуже, чем была
3. ** Необратимость** — в отличие от большинства бизнес-решений, вы не можете легко отменить это
4. ** У вас есть скин в игре ** — ваше суждение о правильном колле затуманено вашими чувствами по этому поводу

Чем дольше вы избегаете жесткого вызова, тем хуже обычно становится ситуация. Компания, которая 6 месяцев назад нуждалась в сокращении на 10%, теперь нуждается в сокращении на 25%. Разговор с соучредителем, который должен был состояться на 4-м месяце, происходит на 14-м.

** Самые трудные решения - это запоздалые решения.**

## Фреймворк { #the-framework }

### Шаг 1: Тест на обратимость { #step-1-the-reversibility-test }

Сначала самый важный вопрос: ** можете ли вы отменить это?**

- ** Обратимый ** — попробуйте, изучите, отрегулируйте (уволите поставщика, отключите функцию, измените стратегию)
- **Частично обратимый** — болезненный для отмены, но возможный (реструктуризация, смена ролей соучредителей)
- **Необратимый** — не может быть отменен (увольнение сотрудника, закрытие продукта с привязкой к клиенту, закрытие юридического лица)

Для необратимых решений планка определенности выше. Вы должны проявить больше должной осмотрительности, прежде чем действовать. Не потому, что вы можете ошибаться, а потому, что вы не можете вернуть свои слова обратно.

** Если вы относитесь к обратимому решению так, как будто оно необратимо, вы избегаете его.**

### Шаг 2: Фреймворк 10/10/10 { #step-2-the-101010-framework }

Задайте по три вопроса о каждом варианте:

- **через 10 минут**: Что вы почувствуете сразу после принятия этого решения?
- **через 10 месяцев**: Каким будет эффект? Будет ли проблема решена?
- **через 10 лет**: Когда вы оглянетесь назад, было ли это правильным решением?

10-минутное ощущение обычно является наименее надежным ориентиром. Обзор на 10 лет обычно проясняет, каков на самом деле правильный выбор.

** Самые трудные решения кажутся очевидными через 10 лет. Вопрос в том, сможете ли вы вытерпеть 10-минутную боль.**

### Шаг 3: Тест Энди Гроува { #step-3-the-andy-grove-test }

Тест Энди Гроува на принятие стратегических решений: "Если бы завтра нас заменили и пришел новый генеральный директор, что бы они сделали?"

Свежий взгляд, никаких эмоциональных вложений в текущий путь, никаких заниженных затрат. Каков очевидный правильный выбор со стороны?

Если ответ ясен постороннему, возникает вопрос: почему вы до сих пор этого не сделали?

### Шаг 4: Составление карты воздействия на стейкхолдеров { #step-4-stakeholder-impact-mapping }

Для каждого варианта укажите, кто пострадал и как:

| Стейкхолдер | Вариант А Воздействие | Воздействие варианта В | Их реакция |
|-------------|----------------|----------------|----------------|
| Пострадавшие сотрудники | | | |
| Оставшаяся команда | | | |
| Клиенты | | | |
| Инвесторы | | | |
| Ты | | | |

Речь идет не о том, чтобы найти вариант, который никому не повредит, — его просто нет. Речь идет о том, чтобы понять полную картину, прежде чем принимать решение.

### Шаг 5: Тест перед объявлением { #step-5-the-pre-announcement-test }

Прежде чем принимать решение: напишите объявление. Электронное письмо команде, сообщение клиенту, разговор, который у вас будет.

**Если вы не можете написать это объявление, значит, вы не готовы принять решение.**

Написание этого заставляет вас взглянуть в лицо реальности того, что вы делаете. Это также показывает, верны ли ваши рассуждения при проверке. "Мы вносим это изменение, потому что..." — звучит ли это предложение правдиво?

### Шаг 6: План коммуникации { #step-6-the-communication-plan }

Трудные решения почти всегда становятся еще труднее, если коммуникация плохая. Важно не только само решение — огромное значение имеет то, как оно принимается.

Для каждого сложного вызова планируйте:
- ** Кто должен знать первым** (непосредственно пострадавший человек, прежде чем кто-либо другой)
- ** Как вы им скажете ** (по возможности лично, никогда по электронной почте для личного воздействия)
- **Что вы скажете** (честный, прямой, сострадательный — смотрите `../executive-mentor/references/hard_things.md`)
- ** Что они могут спросить** (будьте готовы к каждому вопросу)
- **Что будет дальше** (дайте им четкую картину того, что произойдет после)

## Фреймворки, ориентированные на принятие конкретных решений { #decision-specific-frameworks }

### Увольнение соучредителя { #firing-a-co-founder }
Видишь `../executive-mentor/references/hard_things.md — Co-Founder Conflicts` для полного фреймворка.

Ключевые вопросы, на которые нужно ответить в первую очередь:
- Это проблема производительности или проблема ценностей / культуры? (Разные разговоры)
- Были ли вы откровенны — не намекали, а прямо говорили — о проблеме?
- Как выглядит таблица ограничений и каковы юридические последствия?
- Есть ли роль, которая подходит им лучше, или это полный уход?
- Кому нужно знать (совету директоров, команде, инвесторам) и в каком порядке?

** Правило: ** Если вы думали об этом более 3 месяцев, вы уже знаете ответ. Вопрос в том, когда, а не в том, будет ли это сделано.

### Увольнения { #layoffs }
Ключевые вопросы:
- Является ли это одноразовым сбросом или началом более длительного спада? (Один сброс можно восстановить. Серийные увольнения убивают культуру.)
- Вы режете достаточно глубоко? (Недостаточное количество увольнений хуже, чем их отсутствие — два раунда разрушают доверие.)
- Кому принадлежит это объявление и является ли оно прямым и честным?
- Что такое выходное пособие и справедливо ли оно?
- Как вы предотвращаете уход лучших людей после этого?

** Правило: ** Режь один раз, режь глубоко, режь достойно. Неопределенность хуже ясности.

### Поворотный { #pivoting }
Ключевые вопросы:
- Является ли это истинным разворотом (новое направление) или оптимизацией (то же направление, другая тактика)?
- Что вы сохраняете и от чего отказываетесь?
- Есть ли у вас доказательства того, что новое направление работает, или вы бежите от неудачи?
- Как вы сообщаете нынешним клиентам, которые купили старое видение?
- Как это влияет на доверие правления?

** Правило: ** Поворотные точки должны притягиваться при появлении новых возможностей, а не подталкиваться неудачей текущего пути.

### Уничтожение продуктовой линейки { #killing-a-product-line }
Ключевые вопросы:
- Что происходит с клиентами, которые в настоящее время используют его?
- Каков путь миграции?
- Что делают люди, которые его построили?
- Правильно ли "убить это" или лучше "продать это" или "раскрутить это"?
- Каково повествование — внутреннее и внешнее?

## Тест на избегание этого { #the-avoiding-it-test }

Ты знаешь, что избегал трудного вызова, если:
- Ты думал об этом каждую неделю больше месяца
- Вы надеетесь, что ситуация "разрешится сама собой"
- Вы ждете больше данных, которых, по вашему мнению, никогда не будет достаточно
- Вы много раз прокручивали этот разговор в своей голове, но не в реальной жизни
- Другие люди вокруг вас заметили эту проблему

**Стоимость задержки почти всегда выше, чем стоимость принятия решения.**

С каждым месяцем ожидания проблема усугубляется. Соучредитель, у которого ничего не получается, становится более укоренившимся. Линейка продуктов, которая должна умереть, потребляет больше ресурсов. Человек, которого нужно отпустить, влияет на окружающих его людей.

Сделай звонок. Сделайте это четко. Сделайте это с достоинством.
