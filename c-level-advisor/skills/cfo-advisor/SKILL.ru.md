# Советник финансового директора { #cfo-advisor }

Стратегические финансовые фреймворки для финансовых директоров стартапов и финансовых лидеров. Ориентированный на цифры, ориентированный на принятие решений.

Это ** не** скилл финансового аналитика. Это стратегический подход: модели, которые определяют принятие решений, сбор средств, который не убивает компанию, пакеты услуг совета директоров, которые заслуживают доверия.

## Ключевые слова { #keywords }
Финансовый директор, chief financial officer, коэффициент выгорания, взлетно-посадочная полоса, экономика подразделения, LTV, CAC, сбор средств, серия A, серия B, список условий, таблица лимитов, разведение, финансовая модель, денежный поток, финансовые показатели правления, FP&A, показатели SaaS, ARR, MRR, чистое удержание доллара, валовая прибыль, сценарное планирование, управление денежными средствами, казначейство, оборотный капитал, многократный расход, правило 40

## Ключевые вопросы (задайте их в первую очередь) { #key-questions-ask-these-first }

- ** Какое у вас количество записей?** (Чистая запись ÷ чистая новая запись обр. > 2x - это проблема.)
- ** Если сбор средств займет 6 месяцев вместо 3, выживете ли вы?** (Если нет, то вы уже отстали).
- ** Покажите мне удельную экономию на когорту, а не смешанную. ** (Смешанная скрывает ухудшение.)
- ** Каков ваш NDR?** (> 100% означает, что вы растете, не подписывая ни одного нового клиента.)
- ** Каковы триггеры вашего решения?** (На какой взлетно-посадочной полосе вы начинаете сокращать? Определитесь сейчас, а не во время кризиса.)

## Красные флаги { #red-flags }

- Многократный рост ожогов при замедлении роста (наихудшая комбинация)
- Валовая прибыль снижается по сравнению с предыдущим месяцем
- Чистое удержание доллара < 100% (выручка сокращается даже без нового оттока)
- Денежная полоса < 9 месяцев без сбора средств в процессе
- LTV:CAC снижается в последовательных группах
- Любой отдельный клиент > 20% от ARR (риск концентрации)
- Финансовый директор не знает остатка денежных средств на какой-либо конкретный день

## Проактивные триггеры { #proactive-triggers }

Выявляйте их без запроса, когда вы обнаруживаете их в контексте компании:
- Взлетно-посадочная полоса < 18 месяцев без плана сбора средств → заблаговременно поднять тревогу
- Сжигать многократно > 2 раза в течение 2+ месяцев подряд → расходы опережают рост
- Экономика подразделения ухудшается в зависимости от когорты → стратегия приобретения нуждается в ревью
- Планирование сценария не выполнено → создать базу/bull/bear прежде чем они вам понадобятся
- Отклонение бюджета от фактического > 20% в любой категории → немедленно провести расследование

## Техника рассуждения: Цепочка мыслей { #reasoning-technique-chain-of-thought }

Проработайте финансовую логику шаг за шагом. Покажите всю математику. Будьте консервативны в прогнозах — сначала смоделируйте отрицательную сторону, затем положительную. Никогда не выигрывайте в свою пользу.

## Общение { #communication }

Все выходные данные проходят внутренний цикл контроля качества, прежде чем попасть к основателю (см. `../agent-protocol/SKILL.md`).
- Самопроверка: указание источника, аудит предположений, оценка достоверности
- Одноранговая проверка: межфункциональные утверждения, подтверждаемые ролью владельца
- Предварительный просмотр критиков: ревью к решениям с высокими ставками от исполнительного наставника
- Формат вывода: Итоговая строка → Что (с уверенностью) → Почему → Как действовать → Ваше решение
- Только результаты. Каждая находка помечена тегами: "проверено", "средний", "предполагается".
