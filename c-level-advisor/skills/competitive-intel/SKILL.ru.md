# Конкурентная разведка { #competitive-intelligence }

Систематическое отслеживание конкурентов. Не одержимость — разум, который управляет реальными решениями.

## Ключевые слова { #keywords }
конкурентная разведка, анализ конкурентов, карта сражений, анализ выигрышей/проигрышей, конкурентное позиционирование, отслеживание конкуренции, рыночная разведка, исследование конкурентов, SWOT, конкурентная карта, анализ пробелов в характеристиках, конкурентная стратегия

## Быстрый старт { #quick-start }

Запросите на естественном языке необходимый вам результат:

> "Составьте карту нашего конкурентного ландшафта" — прямые, косвенные и будущие конкуренты
> "Создайте боевую карту для [конкурент]" — готовая к продаже боевая карта
> "Провести анализ выигрыша/проигрыша" — последние выигрыши и проигрыши по причинам
> "Что ты сделал [конкурент] делал недавно?" — отслеживание обновлений конкурентов
> "Создайте карту конкурентного позиционирования" — карта позиционирования 2х2

## Фреймворк: 5-уровневая интеллектуальная система { #framework-5-layer-intelligence-system }

### Уровень 1: Идентификация конкурентов { #layer-1-competitor-identification }

**Прямые конкуренты: ** Тот же ICP, та же проблема, сопоставимое решение, аналогичная цена.
**Косвенные конкуренты: ** Тот же бюджет, другое решение (включая "ничего не делать" и "строить собственными силами").
** Будущие конкуренты: ** Хорошо финансируемые стартапы в смежных областях; крупные компании с заявленной дорожной картой пересекаются.

**Матрица угроз 2х2:**

| | Тот же самый ICP | Другой ICP |
|---|---|---|
| **Та же проблема** | Прямая угроза | Соседний (часы) |
| **Другая проблема** | Риск перемещения | Игнорируй пока |

Обновляйте это ежеквартально. Кто переместил квадранты?

### Уровень 2: Отслеживание размеров { #layer-2-tracking-dimensions }

Отслеживайте эти 8 параметров для каждого участника:

| Измерение | Источники | Ритм |
|-----------|---------|---------|
| **Перемещение продукта** | Список изменений, ревью G2/Capterra, Twitter/LinkedIn | Ежемесячно |
| **Изменения в ценах** | Страница с ценами, звонок в отдел продаж intel, отзывы клиентов | Триггер |
| **Финансирование** | Crunchbase, TechCrunch, LinkedIn | Триггер |
| **Сигналы о приеме на работу** | Действительно, объявления о вакансиях в LinkedIn | Ежемесячно |
| **Партнерские отношения** | Пресс-релизы, совместный маркетинг | Триггер |
| **Клиент выигрывает** | Тематические исследования, сайты ревью, LinkedIn | Ежемесячно |
| **Потери клиентов** | Интервью о победах и поражениях, сбитые с толку отчеты | Продолжающийся |
| **Смена обмена сообщениями** | Домашняя страница, реклама (библиотека объявлений Facebook/Google) | Ежеквартально |

### Уровень 3: Фреймворки для анализа { #layer-3-analysis-frameworks }

**SWOT-анализ для каждого конкурента:**
- Сильные стороны: В чем они преуспевают? Где они побеждают?
- Слабые стороны: где они проигрывают? На что жалуются клиенты?
- Возможности: Что они могли бы сделать такого, что угрожало бы вам?
- Угрозы: Каков их экзистенциальный риск?

**Карта конкурентного позиционирования (2 оси):**
Выбирайте оси, которые важны для ваших покупателей:
- Общие: Цена в сравнении с глубиной функциональных возможностей; Готовность к работе на предприятии в сравнении с готовностью для малого и среднего бизнеса; Простота внедрения в сравнении с конфигурируемостью
- Выбирайте оси, которые четко демонстрируют ВАШУ индивидуальность

**Анализ пробелов в характеристиках:**
| Особенность | Ты | Конкурент А | Конкурент В | Статус разрыва |
|---------|-----|-------------|-------------|------------|
| [Особенность] | ✅ | ✅ | ❌ | Ваше преимущество |
| [Особенность] | ❌ | ✅ | ✅ | Разрыв — дорожная карта? |
| [Особенность] | ✅ | ❌ | ❌ | Ров |
| [Особенность] | ❌ | ❌ | ✅ | Только участник В |

### Уровень 4: Выходные форматы { #layer-4-output-formats }

**Для отдела продаж (CRO):** Боевые карточки — по одной странице на каждого участника, предназначенные для предварительной подготовки к звонку.
Видишь `templates/battlecard-template.md`

** Для отдела маркетинга (CMO):** Обновление позиционирования — смена сообщений, новые отличительные признаки, заявления о прекращении или начале подачи.

** Для продукта (CPO): ** Краткое описание недостатков в функциях — что запрашивают клиенты, чего у нас нет, что поставляют конкуренты, чему следует изменить приоритеты.

** Для генерального директора/Совета директоров:** Ежемесячное конкурсное резюме — 1 страница: кто перешел, что это значит, рекомендуемые ответы.

### Уровень 5: Частота интеллекта { #layer-5-intelligence-cadence }

**Ежемесячно (по расписанию):**
- Ревью всех конкурентов уровня 1 (прямые угрозы, топ-3)
- Обновите боевые карты с помощью новой информации
- Опубликовать резюме на 1 странице для руководства

**Триггер (основанный на событиях):**
- Конкурент привлекает финансирование → оцените последствия в течение 48 часов
- Конкурент запускает основную функцию → продукт + ответ от продаж в течение 1 недели
- Конкурент переманивает ключевого клиента → собеседование о выигрыше/проигрыше в течение 2 недель
- Конкурент меняет цены → проанализируйте и ответьте в течение 1 недели

**Ежеквартально:**
- Полный ревью конкурентного ландшафта
- Обновить карту позиционирования
- Обновить оценку конкурентных угроз ICP
- Добавление/удаление компаний из списка отслеживания

## Анализ выигрышей/проигрышей { #winloss-analysis }

Это самые качественные конкурентные данные, которые у вас есть. Большинство компаний делают это слишком редко.

**Когда проводить собеседование:**
- Каждая проигранная сделка составляет более $50 тыс.
- Каждый отток >6 месяцев пребывания в должности
- Каждая победа в соревновании (узнайте почему — это может быть не то, что вы думаете)

**Кто его проводит:**
- НЕ тот человек, который заключил сделку (слишком близко, потенциальный клиент не будет откровенным)
- Успех клиента, команды разработчиков или внешнего исследователя

**Структура вопроса:**
1. "Ознакомьте меня с процессом вашей оценки"
2. "Кого еще ты рассматривала?"
3. "Каковы были 3 главных критерия при принятии вашего решения?"
4. "Откуда это взялось [наш продукт] не дотягивает?"
5. "Что было решающим фактором?"
6. "Что изменило бы ваше решение?"

**Сводные результаты ежемесячно:**
- Причины выигрыша (ранжирование по частоте)
- Причины потерь (ранжирование по частоте)
- Показатели выигрыша конкурентов (по конкурентам, по сегментам)
- Закономерности с течением времени

## Баланс: Разум без одержимости { #the-balance-intelligence-without-obsession }

** Признаки того, что вы переоцениваете конкурентов:**
- Решения по дорожной карте в первую очередь определяются тем, что "они только что отправили X".
- Моральный дух команды падает, когда конкуренты собирают средства
- Вы отправляете функции, в которые не верите, в соответствии с их чек-листом.
- Обсуждения цен всегда начинаются с "ну, они берут X".

** Признаки того, что вы недостаточно отслеживаете:**
- Ваши AES застают врасплох при звонках
- Потенциальные клиенты знают о конкурентах больше, чем ваша команда
- Вы пропустили запуск крупного продукта, пока клиенты не сообщили вам об этом
- Ваше позиционирование не изменилось более чем за 12 месяцев, несмотря на изменения на рынке

** Правильная осанка:**
- Знать конкурентов достаточно хорошо, чтобы победить их
- Не позволяйте им определять ваши планы
- Ваша дорожная карта основана на проблемах клиентов, а также на конкурентных пробелах

## Тревожные сигналы в конкурентной разведке { #red-flags-in-competitive-intelligence }

| Сигнал | Что это значит |
|--------|---------------|
| Процент побед конкурентов >50% в вашем основном сегменте | Фундаментальная проблема позиционирования, а не проблема продаж |
| То же возражение от 5+ сделок: "у конкурента есть X". | Реальный разрыв в характеристиках, а не только в оптике |
| Конкурент нанял 10 инженеров в вашей области | Поступающие крупные инвестиции в продукт |
| Конкурент собрал более 20 миллионов долларов и нацелен на ваш ICP | 12-месячная взлетно-посадочная полоса для них, чтобы они могли усердно соревноваться |
| Потенциальные клиенты оценивают вас, чтобы оправдать решение конкурента | Вы - "флажок" — фиксируете восприятие или сегмент |
