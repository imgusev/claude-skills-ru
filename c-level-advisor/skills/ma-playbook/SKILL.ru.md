# Плейбук для слияний и поглощений { #ma-playbook }

Фреймворки для обеих сторон слияний и поглощений: приобретающие компании и те, которые приобретаются.

## Ключевые слова { #keywords }
M&A, слияния и поглощения, due diligence, приобретение, наем на работу, интеграция, структура сделки, оценка, LOI, срочный отчет, доход

## Быстрый старт { #quick-start }

**Приобретение:** Начните со стратегического обоснования → отбора целей → должной осмотрительности → оценки → переговоров → интеграции.

** Приобретается:** Начните с оценки готовности → подготовка помещения для обработки данных → выбор консультанта → переговоры → переход.

## Когда Вы приобретаете { #when-youre-acquiring }

### Стратегическое обоснование (ответьте прежде всего) { #strategic-rationale-answer-before-anything-else }
- ** Покупка против сборки: ** Можете ли вы построить это быстрее / дешевле? Если да, то не приобретайте.
- ** Приобретение по сравнению с продуктом и рынком: ** Что вы на самом деле покупаете? Талант? Технология? Клиенты?
- ** Сложность интеграции: ** Насколько сложно внедрить это в вашу компанию?

### Чек-лист должной осмотрительности (Due Diligence) { #due-diligence-checklist }
| Домен | Ключевые вопросы | Красные флаги |
|--------|--------------|-----------|
| Финансовый | Качество выручки, концентрация клиентов, скорость выгорания | >30% выручки от 1 клиента |
| Технический | Качество кода, технический долг, соответствие архитектуры | Монолит без каких-либо испытаний |
| Юридический | Владение интеллектуальной собственностью, незавершенные судебные разбирательства, контракты | Ключевые IP-адреса, принадлежащие частным лицам |
| Люди | Риск ключевого сотрудника, соответствие культуре, риск удержания | У основателей нет ограничений по доходам |
| Рынок | Положение на рынке, конкурентные угрозы | Сокращающаяся доля рынка |
| Клиенты | Уровень оттока, NPS, условия контракта | Высокий отток, короткие контракты |

### Подходы к оценке { #valuation-approaches }

Приведенные ниже диапазоны являются ** иллюстративными, а не текущими рыночными данными** — всегда сверяйтесь с текущими рыночными показателями, прежде чем использовать их в модели или переговорах.

- **Кратность выручки:** Зависит от отрасли (иллюстративный диапазон: от 2 до 15 раз в год для SaaS, варьируется в зависимости от темпов роста, NRR и условий тарификации)
- **Сопоставимые сделки:** За что продавались аналогичные компании — наиболее оправданный якорь
- **DCF:** Только для прибыльных компаний (большинство стартапов: используют мультипликаторы)
- **Приобретение на работу:** Примерный диапазон: от 1 до 3 миллионов долларов на одного инженера на горячих рынках талантов

** Источники для проверки (ознакомьтесь с последней редакцией):** Индекс SaaS Capital Index (кратные показатели доходов от частного SaaS, обновляются ежемесячно), ежегодные/ежеквартальные отчеты Software Equity Group (SEG) о слияниях и поглощениях SaaS (кратные показатели транзакций) и отчеты Aventis Advisors об оценке SaaS. Перепроверьте как минимум два из них, прежде чем привязывать цену.

## Когда тебя приобретают { #when-youre-being-acquired }

### Сигналы готовности { #readiness-signals }
- Исходящий интерес со стороны стратегических покупателей
- Консолидация рынка происходит вокруг вас
- Сбор средств становится сложнее, чем управление
- Основатель готов к переходу

### Подготовка (за 6-12 месяцев до начала) { #preparation-6-12-months-before }
1. Привести в порядок финансовые показатели (по возможности провести аудит)
2. Документируйте все права интеллектуальной собственности и контракты
3. Снизить концентрацию клиентов
4. Запереть ключевых сотрудников
5. Создайте хранилище данных
6. Нанять консультанта по слияниям и поглощениям

### Пункты для переговоров { #negotiation-points }
| Термин | Что посмотреть | Ваш рычаг воздействия |
|------|--------------|---------------|
| Оценка | Ловушки для заработка (недостижимые цели) | Множество конкурирующих предложений |
| Заработок | Определения контрольных точек, период измерения | Соотношение "Большие деньги" и "большие доходы" |
| Изолятор | Продолжительность, условия | Ваша заменимость |
| Репутация и гарантии | Объем ответственности | Условное депонирование против предельного размера компенсации |
| Удержание сотрудников | Кто получает предложения, на каких условиях | Зависимости от ключевых лиц |

## Красные флаги (с обеих сторон) { #red-flags-both-sides }

- Нет четкого стратегического обоснования, кроме "это выгодная сделка".
- Столкновение культур, заметное во время проведения due diligence и проигнорированное
- Ключевые сотрудники, не запертые перед закрытием
- Плана интеграции не существует или это "мы что-нибудь придумаем".
- Оценка основана на прогнозах, а не на фактических данных

## Цикл проверки (перед любым LOI или подписью) { #verification-loop-before-any-loi-or-signature }

Этот скилл формирует сделку; два родственных скилла подтверждают это. Передайте — не дублируйте:

1. **Юридические термины** → `general-counsel-advisor`: просмотрите таблицу LOI/term через `../general-counsel-advisor/scripts/term_sheet_analyzer.py` (оценка по 12 измерениям от 0 до 100 баллов) и окончательные документы через `../general-counsel-advisor/scripts/contract_risk_scanner.py` (12 шаблонов "убийцы основателей": ловушки для заработка, неконтролируемое возмещение, неопределенный IP и т.д.). Любое 🔴 заключение передается стороннему адвокату перед подписанием.
2. **Проверка данных** → `chief-data-officer-advisor`: запустить `../chief-data-officer-advisor/scripts/ai_training_data_audit.py` (обучение - права на данные, основа статьи 6 GDPR) и `../chief-data-officer-advisor/scripts/data_asset_valuator.py` (стоимость данных-активов, множитель слияний и поглощений с учетом штрафных санкций за изъятие) в отношении объекта данных. Происхождение с недокументированным согласием - это возможность снизить цену или отказаться от товара.
3. ** Математика оценки ** → `cfo-advisor` инструменты для количественной модели; этот плейбук остается качественным.

Верните полученные результаты в таблицу пунктов согласования, приведенную выше, циклом перед следующим счетчиком.

## Интеграция с ролями C-Suite { #integration-with-c-suite-roles }

| Роль | Вклад в слияния и поглощения |
|------|-------------------|
| ГЕНЕРАЛЬНЫЙ директор | Стратегическое обоснование, руководство переговорами |
| Финансовый директор | Оценка, структура сделки, финансирование |
| GC | Ревью LOI/term sheet, проверка рисков по контракту, нормативные триггеры |
| CDO | Проверка данных: обучение - права на данные, оценка данных-активов |
| Технический директор | Техническая экспертиза, архитектура интеграции |
| ХРО | Должная осмотрительность сотрудников, планирование удержания персонала |
| ВОРКУЮЩИЙ | Выполнение интеграции, слияние процессов |
| Генеральный директор | Влияние дорожной карты продукта, совпадение интересов клиентов |
