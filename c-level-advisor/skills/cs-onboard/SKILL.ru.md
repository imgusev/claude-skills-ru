# Онбординг в C-Suite { #c-suite-onboarding }

Структурированное интервью с основателем, которое создает контекстный файл компании, необходимый каждому консультанту C-suite. Один 45-минутный разговор. Постоянный контекст для всех ролей.

## Команды { #commands }

- `/cs:setup` — Полное интервью по онбордингу (~45 мин, 7 измерений)
- `/cs:update` — Ежеквартальное обновление (~15 мин, "что изменилось?")

## Ключевые слова { #keywords }
cs:настройка, cs:обновление, контекст компании, интервью с основателем, онбординг, профиль компании, настройка c-suite, настройка советника

---

## Принципы ведения беседы { #conversation-principles }

Это будет беседа, а не допрос. Задавайте по одному вопросу за раз. Следите за потоками. Подумайте еще раз: "Итак, реальная проблема звучит как X — это верно?" Следите за тем, что они пропускают — вот где живет настоящая история. Никогда не читайте список вопросов.

Начните с: * "Расскажите мне о компании своими словами — что вы создаете и почему это важно?"*

## 7 Аспектов интервью { #7-interview-dimensions }

### 1. Фирменный стиль компании { #1-company-identity }
Фиксируйте: что они делают, для кого это, истинное основополагающее "почему", суть в одном предложении, не подлежащие обсуждению ценности.
Ключевой вопрос: * "Какую ценность вы бы уволили из-за нарушения?"*
Красный флаг: ценности, которые звучат как маркетинговая копия.

### 2. Стадия и масштаб { #2-stage--scale }
Фиксация: численность персонала (FT против подрядчиков), диапазон доходов, взлетно-посадочная полоса, стадия (до PMF / масштабирования / оптимизации), что произошло за последние 90 дней.
Ключевой вопрос: * "Если бы вам пришлось обозначать свой этап — вы бы все еще находили PMF, масштабировали то, что работает, или оптимизировали?"*

### 3. Профиль основателя { #3-founder-profile }
Захват: самоидентифицированная сверхдержава, признанные слепые зоны, архетип (продукт/sales/technical/operator), что на самом деле не дает им спать по ночам.
Ключевой вопрос: * "Что, по мнению вашего соучредителя, вам следует прекратить делать?"*
Красный флаг: Никаких слепых зон или слабостей, выдаваемых за силу.

### 4. Команда и культура { #4-team--culture }
Захват: команда в трех словах, последний реальный конфликт и его разрешение, какие ценности являются реальными, а какие - желательными, самый сильный и самый слабый лидер.
Ключевой вопрос: * "Какая из заявленных вами ценностей наиболее реальна? Что это за плакат на стене?"*
Красный флаг: "У нас нет конфликта".

### 5. Рынок и конкуренция { #5-market--competition }
Захват: кто выигрывает и почему (честная версия), реальное несправедливое преимущество, единственный конкурентный ход, который может навредить им.
Ключевой вопрос: * "В чем заключается ваше реальное несправедливое преимущество, а не версия для инвесторов?"*
Красный флаг: "У нас нет реальной конкуренции".

### 6. Текущие проблемы { #6-current-challenges }
Захват: стек приоритетов -ранжирование по продукту/growth/people/money/operations, решение, которого они избегали, ответ "один дополнительный день".
Ключевой вопрос: * "Какое решение вы откладывали неделями?"*
Примечание: Ответ "дополнительный день" раскрывает истинные приоритеты.

### 7. Цели и амбиции { #7-goals--ambition }
Фиксация: цель на 12 месяцев (конкретная), цель на 36 месяцев (направленная), ориентация на выход и построение навсегда, определение личного успеха.
Ключевой вопрос: * "Как выглядит успех лично для вас — отдельно от компании?"*

## Результат: company-context.md { #output-company-contextmd }

После собеседования сформируйте `~/.claude/company-context.md` используя `templates/company-context-template.md`.

Заполните каждый раздел. Писать `[not captured]` для неизвестных — никогда не оставляйте поле пустым. Добавьте временную метку, отметьте как `fresh`.

Скажите основателю: * "Я уловил все в контексте вашей компании. Каждый консультант будет использовать это, чтобы дать конкретный, релевантный совет. Бежать /cs:update через 90 дней, чтобы поддерживать его в актуальном состоянии".*

## /cs:update — Ежеквартальное обновление { #csupdate--quarterly-refresh }

**Триггер: ** Каждые 90 дней или после серьезных изменений. Продолжительность: ~15 минут.

Начните с: * "Это было [X раз] с тех пор, как мы изучили контекст вашей компании. Что изменилось?"*

Пройдитесь по каждому измерению с одним вопросом: "Что изменилось?" вопрос:
1. Идентичность: та же миссия или измененная?
2. Масштаб: команда, выручка, взлетно-посадочная полоса сейчас?
3. Основатель: роль или что вас напрягает?
4. Команда: какие-либо изменения в руководстве?
5. Рынок: есть какие-нибудь конкурентные сюрпризы?
6. Проблемы: проблема №1 сейчас по сравнению с проблемой 90 дней назад?
7. Цели: все еще на пути к достижению 12-месячной цели?

Обновите контекстный файл, обновите временную метку, сбросьте значение `fresh`.

## Расположение контекстного файла { #context-file-location }
