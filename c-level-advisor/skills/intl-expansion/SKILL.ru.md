# Международная экспансия { #international-expansion }

Фреймворки для выхода на новые рынки: отбор, выход на рынок, локализация и исполнение.

## Ключевые слова { #keywords }
международная экспансия, выход на рынок, локализация, выход на рынок, GTM, региональная стратегия, международные рынки, выбор рынка, трансграничная, глобальная экспансия

## Быстрый старт { #quick-start }

** Последовательность принятия решений:** Выбор рынка → Режим выхода → Оценка регулирующих органов → План локализации → Стратегия GTM → Структура команды → Запуск.

## Фреймворк для выбора рынка { #market-selection-framework }

### Оценочная матрица { #scoring-matrix }
| Фактор | Вес | Как оценить |
|--------|--------|---------------|
| Размер рынка (адресуемый) | 25% | ТАМ в целевом сегменте, готовность платить |
| Интенсивность конкуренции | 20% | Сила действующих компаний, разрывы на рынке |
| Сложность регулирования | 20% | Барьеры для входа, стоимость соблюдения требований, сроки |
| Культурная дистанция | 15% | Язык, деловая практика, покупательское поведение |
| Существующая тяга | 10% | Входящий спрос, существующие клиенты, партнерские отношения |
| Сложность эксплуатации | 10% | Часовые пояса, инфраструктура, платежные системы |

### Режимы ввода { #entry-modes }
| Режим | Инвестиции | Контроль | Риск | Лучше всего подходит для |
|------|-----------|---------|------|----------|
| **Экспорт** (продажа удаленно) | Низкий | Низкий | Низкий | Требование к тестированию |
| **Партнерство** (реселлер/дистрибьютор) | Средний | Средний | Средний | Рынки с жесткими местными требованиями |
| **Местная команда** (нанимается на рынке) | Высокий | Высокий | Высокий | Стратегические рынки с доказанным спросом |
| **Юридическое лицо** (полная дочерняя компания) | Очень высокий | Полный | Высокий | Основные рынки, нормативные требования |
| **Приобретение** | Самый высокий | Полный | Самый высокий | Быстрый выход на рынок с существующей базой |

** Путь по умолчанию:** Экспорт → Партнерство → Местная команда → Организация (выпускается в зависимости от дохода).

## Чек-лист по локализации Localization Localization { #localization-checklist }

### Продукт { #product }
- [ ] Язык (пользовательский интерфейс, документация, вспомогательный контент)
- [ ] Валюта и цены (местные цены, а не только конвертация)
- [ ] Способы оплаты (сильно варьируются в зависимости от рынка)
- [ ] Форматы даты/времени/чисел
- [ ] Юридические требования (хранение данных, конфиденциальность)
- [ ] Культурная адаптация (не просто перевод)

### Выход на рынок { #go-to-market }
- [ ] Адаптация обмена сообщениями (что находит отклик на местном уровне)
- [ ] Стратегия канала (каналы различаются в зависимости от рынка)
- [ ] Местные тематические исследования и социальное доказательство
- [ ] Местные партнерства и интеграции
- [ ] Присутствие на мероприятии/конференции
- [ ] Местное SEO и контент

### Операции { #operations }
- [ ] Юридическое лицо (при необходимости)
- [ ] Соблюдение налогового законодательства
- [ ] Трудовое законодательство (при приеме на работу на местном уровне)
- [ ] Служба поддержки клиентов (часы работы, язык)
- [ ] Банковское дело и платежи

## Ключевые вопросы { #key-questions }

- "Есть ли тяга со стороны рынка, или мы давим?"
- "Какова стоимость входа по сравнению с возможностью получения дохода в течение 3 лет?"
- "Можем ли мы обслуживать этот рынок из штаб-квартиры, или нам нужны люди на местах?"
- "Каковы нормативные сроки? Можем ли мы начать до того, как будет оформлена вся документация?"
- "Кто выигрывает на этом рынке и что потребуется, чтобы вытеснить их?"

## Распространенные ошибки { #common-mistakes }

| Ошибка | Почему это происходит | Предотвращение |
|---------|---------------|------------|
| Выход на слишком много рынков одновременно | FOMO, давление на борт | Максимум 1-2 новых рынка в год |
| Скопируйте и вставьте GTM с домашнего рынка | Предполагая, что покупатели одни и те же | Исследуйте местное покупательское поведение |
| Недооценка нормативных затрат | "Мы что-нибудь придумаем" | Нормативная оценка ПЕРЕД совершением |
| Прием на работу слишком рано | Оптимизм | Докажите востребованность, прежде чем нанимать местную команду |
| Неправильная цена (просто конвертация) | Лень | Исследуйте готовность платить на местном уровне |
