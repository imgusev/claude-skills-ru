# Диагностика работоспособности организации { #org-health-diagnostic }

Восемь измерений. Светофор. Реальные ориентиры. Выявляет проблемы, о существовании которых вы и не подозреваете.

## Ключевые слова { #keywords }
здоровье организации, организационное здоровье, диагностика здоровья, дашборд здоровья, проверка здоровья, здоровье компании, функциональное здоровье, здоровье команды, здоровье стартапа, система показателей здоровья, оценка состояния здоровья, дашборд рисков

```bash
python scripts/health_scorer.py        # Guided CLI — enter metrics, get scored dashboard

```

Или опишите свои показатели на естественном языке:

## 8 измерений { #the-8-dimensions }

### 1. 💰 Финансовое благополучие (финансовый директор) { #1--financial-health-cfo }
**Что он измеряет:** Можем ли мы финансировать операции и инвестировать в рост?

Ключевые показатели:
- **Взлетно—посадочная полоса** - месяцы текущего использования (зеленый: >12, желтый: 6-12, красный: <6)
- **Записать несколько раз** — чистый сброс / чистый новый сброс (зеленый: <1,5x, желтый: 1,5-2,5x, красный: >2,5x)
- **Валовая прибыль** — Целевой показатель SaaS: >65% (зеленый: >70%, желтый: 55-70%, красный: <55%)
- **Темпы роста за месяц** — в зависимости от контекста по этапам (см. контрольные показатели)
- **Концентрация выручки** — доля крупнейших клиентов в общем объеме продаж (зеленый: <15%, желтый: 15-25%, красный: >25%)

### 2. 📈 Уровень доходов (CRO) { #2--revenue-health-cro }
** Что он измеряет:** Остаются ли клиенты, растут ли их число и рекомендуют ли они нас?

Ключевые показатели:
- **NRR (удержание чистой выручки)** — Зеленый: >110%, желтый: 100-110%, Красный: <100%
- **Коэффициент оттока логотипов (в годовом исчислении)** — Зеленый: <5%, желтый: 5-10%, красный: >10%
- **Охват пайплайна (следующий квартал)** — Зеленый: >3x, желтый: 2-3x, красный: <2x
- **Срок окупаемости CAC** — Зеленый: <12 месяцев, желтый: 12-18, красный: >18 месяцев
- **Средний тренд ACV** — направленный: растущий, неизменный, снижающийся

### 3. 🚀 Здоровье продукта (CPO) { #3--product-health-cpo }
**Что он измеряет:** Любят ли клиенты продукт и пользуются ли им?

Ключевые показатели:
- **NPS** — Зеленый: >40, желтый: 20-40, красный: <20
- **Соотношение DAU/MAU** — показатель вовлеченности (зеленый: >40%, желтый: 20-40%, красный: <20%)
- **Внедрение основной функции ** — % пользователей, использующих функцию primary value (зеленый: >60%)
- **Время на оценку** - дни от регистрации до первого основного действия (чем меньше, тем лучше)
- **Удовлетворенность клиентов (CSAT)** — Зеленый: >4,2/5, желтый: 3,5-4,2, Красный: <3,5

### 4. ⚙️ Инженерное здравоохранение (технический директор) { #4--engineering-health-cto }
** Что он измеряет:** Можем ли мы надежно осуществлять доставку и поддерживать скорость?

Ключевые показатели:
- **Частота развертывания** — Зеленый: ежедневно, желтый: еженедельно, красный: ежемесячно или реже
- **Частота отказов изменений** — % развертываний, вызывающих инциденты (зеленый: <5%, красный: >15%)
- **Среднее время восстановления (MTTR)** — Зеленый: <1 часа, желтый: 1-4 часа, красный: >4 часов
- **Коэффициент технического долга** — % от мощности спринта по долгу (зеленый: <20%, желтый: 20-35%, красный: >35%)
- **Частота инцидентов** — P0/P1 в месяц (зеленый: <2, желтый: 2-5, Красный: >5)

### 5. 👥 Здоровье людей (CHRO) { #5--people-health-chro }
** Что он измеряет:** Является ли команда стабильной, вовлеченной и растущей?

Ключевые показатели:
- ** Прискорбный выбытие (в годовом исчислении)** — Зеленый: <10%, желтый: 10-20%, красный: >20%
- ** Показатель вовлеченности** — (eNPS или аналогичный; Зеленый: >30, желтый: 0-30, красный: <0)
- **Время заполнения (в среднем дней)** — Зеленый: <45, желтый: 45-90, красный: >90
- **Соотношение между менеджером и IC** — Зеленый: 1:5-1:8, желтый: 1:3-1:5 или 1:8-1:12, красный: снаружи
- **Уровень внутреннего продвижения по службе** — не менее 25-30% руководящих должностей, заполненных внутри компании

### 6. 🔄 Операционное здоровье (COO) { #6--operational-health-coo }
**Что он измеряет:** Дисциплинированно ли мы реализуем нашу стратегию?

Ключевые показатели:
- **Коэффициент выполнения OKR** — % ключевых результатов, достигающих цели (зеленый: >70%, желтый: 50-70%, красный: <50%)
- **Время цикла принятия решения** — дни от необходимого решения до его принятия (зеленый: <48 часов, желтый: 48 часов-1 вт)
- **Эффективность совещаний** — % совещаний с четким результатом (качественным)
- **Зрелость процесса** — шкала уровней 1-5 (смотрите консультанта главного операционного директора)
- **Завершение межфункциональной инициативы** — % по срокам, по объему

### 7. 🔒 Безопасность и гигиена труда (CISO) { #7--security-health-ciso }
**Что он измеряет:** Защищаем ли мы клиентов и соблюдаем ли требования законодательства?

Ключевые показатели:
- **Инциденты в сфере безопасности (за последние 90 дней)** — Зеленый: 0, желтый: 1-2 незначительных, красный: 1+ серьезный
- **Статус соответствия** — текущие/выполняемые сертификаты по сравнению с просроченными
- **SLA по устранению уязвимостей** — % критических CVE, исправленных в рамках SLA (зеленый: 100%)
- **Завершение обучения по безопасности** — % от текущей команды (зеленый: >95%)
- ** Недавно проведенный тест пера** — Зеленый: <12 месяцев, желтый: 12-24, Красный: >24 месяцев

### 8. 📣 Состояние рынка (CMO) { #8--market-health-cmo }
**Что он измеряет:** Выигрываем ли мы на рынке и эффективно ли растем?

Ключевые показатели:
- **Тренд CAC** — улучшение, отсутствие изменений или ухудшение кв/кв
- ** Сочетание органического и платного свинца ** — больше органического = полезнее для здоровья (менее хрупкое)
- **Процент побед** — % закрытых квалифицированных возможностей-выигранных (зеленый: >25%, желтый: 15-25%, красный: <15%)
- ** Конкурентный коэффициент выигрыша** — конкретно по сравнению с основными конкурентами
- **NPS бренда** — узнаваемость + баллы предпочтений в ICP

## Подсчет очков и светофоры { #scoring--traffic-lights }

Каждое измерение оценивается от 1 до 10 баллов с помощью светофора:
- 🟢 **Зеленый (7-10):** Здоровый — поддерживайте и оптимизируйте
- 🟡 ** Желтый (4-6):** Следите — тренд имеет значение; улучшается или снижается?
- 🔴 ** Красный (1-3):** Требуется действие — обратиться в течение 30 дней

**Общий показатель состояния здоровья:**
Средневзвешенное значение по стадиям развития компании (см. `references/health-benchmarks.md` для весов).

## Взаимодействия измерений (Почему одна проблема порождает другую) { #dimension-interactions-why-one-problem-creates-another }

| Если это измерение красное... | Посмотрите на эти измерения далее |
|-----------------------------|----------------------------|
| Финансовое благополучие | Люди (заморозить наем) → Инженерия (заморозить инфраструктуру) → Продукт (сократить сферу применения) |
| Состояние доходов | Финансы (кассовый разрыв) → Люди (риск истощения) → Рынок (потеря позиций) |
| Здоровье людей | Разработка (скорость падает) → Продукт (качество падает) → Выручка (отток растет) |
| Инженерное здоровье | Продукт (список характеристик) → Выручка (сделки по продукту приостанавливаются) |
| Здоровье продукта | Доход (NRR падает, отток растет) → Рынок (CAC растет; количество рефералов сокращается) |
| Работоспособность | Все измерения со временем ухудшаются (сбои выполнения каскадируются повсюду) |

## Изящная деградация { #graceful-degradation }

Вам не нужны все показатели для запуска диагностики. Инструмент обрабатывает частичные данные:
- Отсутствующий показатель → исключен из оценки, помечен как "[необходимые данные]"
- Оценка по-прежнему действительна для доступных измерений
- Отчет указывает, какие пробелы необходимо заполнить для следующего цикла
