# /cs:cmo-review — Директор по маркетингу форсирует вопросы { #cscmo-review--cmo-forcing-questions }

**Команда:** `/cs:cmo-review <plan>`

Стратег, ориентированный в первую очередь на повествование, проверяет позиционирование, прежде чем обсуждать тактику.

## Когда запускать { #when-to-run }

- Перед запуском любой новой кампании
- Перед изменением позиционирования, слогана или категории
- Прежде чем выделять > 10% маркетингового бюджета на новый канал
- Перед важным PR-событием (объявление о финансировании, запуск продукта)
- Когда вклад пайплайна уменьшается

## Шесть вопросов CMO { #the-six-cmo-questions }

### 1. ICP (один реальный человек) { #1-icp-one-real-person }
** Назовите одного реального человека в вашем ПМС. Компания, должность, то, что они делают ежедневно, то, что они ненавидят.**
- Персона ≠ ПМС. ДЦП - это реально.
- Если вы не можете назвать ни одного из них, значит, ВЧД недостаточно острое.

### 2. JTBD { #2-jtbd }
**Для выполнения какой работы клиент нанимает этот продукт и какую альтернативу он использует сегодня?**
- Одно предложение, которое клиент произнес бы вслух.
- "Мы используем электронные таблицы" - это приемлемая альтернатива. Как и "мы этого не делаем".

### 3. Заявление о позиционировании { #3-positioning-statement }
**Одно предложение: Для [ICP], который нуждается [работа], мы [категория], которая [отличительный признак] непохожий [альтернатива].**
- Это заголовок. Все обрушивается каскадом.
- Если это не укладывается в одно предложение, значит, это еще не позиционирование.

### 4. Канал распространения { #4-distribution-channel }
** Где клиент впервые слышит ваше имя — и является ли оно входящим или исходящим на данном этапе?**
- Назовите канал, намерение и путь к первому контакту.
- PLG, ориентированный на продажи, контент-ориентированный, партнерский — выберите основной.

### 5. Окупаемость CAC { #5-cac-payback }
** Для каждого канала: каков CAC, какова окупаемость в месяцах и улучшается ли она?**
- Если окупаемость канала составляет более 18 месяцев, то это не канал — это хобби.

### 6. Защищенность бренда { #6-defensibility-of-brand }
** Если завтра хорошо финансируемый конкурент скопирует ваше сообщение, что останется вашим?**
- Позиция в категории, соответствие основателя рынку, любовь клиентов, контроль за распространением - назовите только одно.

## Воркфлоу { #workflow }

1. **Запуск моделей:**
   ```bash
   python ../../../skills/cmo-advisor/scripts/marketing_budget_modeler.py
   python ../../../skills/cmo-advisor/scripts/growth_model_simulator.py
   ```
2. **Ответьте на шесть вопросов** в письменном виде.
3. **Вынести вердикт:**
   - 🟢 ЗЕЛЕНЫЙ — сюжет четкий, звук смешивания каналов
   - 🟡 ЖЕЛТЫЙ — повышение резкости позиционирования перед масштабированием
   - 🔴 КРАСНЫЙ — положение нарушено; не тратьте
