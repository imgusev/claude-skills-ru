# Агенты, работающие под прикрытием персон { #persona-based-agents }

Предварительно сконфигурированные персонажи-агенты с заданными скиллами, воркфлоу и индивидуальными особенностями.

## Что такое персона? { #whats-a-persona }

** Персона** - это определение агента, которое выходит за рамки "использовать эти скиллы". Каждая персона включает в себя:

- **🧠 Идентичность и память ** — кто этот агент, как он мыслит, чему научился
- ** Core Основная миссия** — для чего они оптимизируются, в порядке приоритетности
- **🚨 Критические правила** — жесткие ограничения, которые они никогда не нарушают
- ** Capabilities Возможности** — экспертиза предметной области, организованная по областям
- **🔄 Воркфлоу** — пошаговые процессы для выполнения общих задач
- **💭 Стиль общения** — как они разговаривают, с конкретными примерами
- **🎯 Показатели успеха** — измеримые результаты, которые определяют "хорошо"
- ** Advanced Расширенные возможности ** — более глубокие знания загружаются по запросу
- **🔄 Обучение и память ** — что они запоминают и какие паттерны распознают

## Как использовать { #how-to-use }

### Код Клода { #claude-code }
```bash
cp agents/personas/startup-cto.md ~/.claude/agents/
# Then: "Activate startup-cto mode"
```

### Курсор { #cursor }
```bash
./scripts/convert.sh --tool cursor
# Personas convert to .cursor/rules/*.mdc
```

### Любой поддерживаемый инструмент { #any-supported-tool }
```bash
./scripts/install.sh --tool <your-tool>
```

## Персонажи против агентов по выполнению задач { #personas-vs-task-agents }

| | Агенты задач (`agents/`) | Персонажи (`agents/personas/`) |
|---|---|---|
| **Сосредоточенность** | Выполнение задачи | Воплощение роли |
| **Сфера применения** | Единый домен | Междоменный кураторский набор |
| **Голос** | Нейтральный/professional | Личностный подход с предысторией |
| **Воркфлоу** | Одноступенчатый | Многоступенчатый процесс с точками принятия решений |
| **Вариант использования** | "Выполните это задание" | "Думай как этот человек" |

И то, и другое сосуществует. Используйте агентов задач для целенаправленной работы, персонажей для постоянного сотрудничества.

## Создавая свой собственный { #creating-your-own }

Видишь [TEMPLATE.md](template.md) для спецификации формата. Ключевые элементы:

```yaml
---
name: Agent Name
description: What this agent does and when to activate it.
color: blue          # Agent color theme
emoji: 🎯           # Single emoji identifier
vibe: One sentence personality capture.
tools: Read, Write, Bash, Grep, Glob
---
```

Следуйте структуре раздела (Идентичность → Миссия → Правила → Возможности → Воркфлоу → Коммуникация → Показатели → Продвинутый уровень → Обучение) для соответствия существующим персонажам.
