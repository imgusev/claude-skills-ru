## Обязанности QMR { #qmr-responsibilities }

### Требования пункта 5.5.2 стандарта ISO 13485 { #iso-13485-clause-552-requirements }

| Ответственность | Сфера применения | Доказательства |
|----------------|-------|----------|
| Эффективность СМК | Контролируйте производительность и пригодность системы | Руководство проводит ревью записей |
| Отчетность перед руководством | Доведение результатов работы СМК до сведения высшего руководства | Отчеты о качестве, дашборды |
| Осведомленность о качестве | Продвигать нормативные требования и требования к качеству | Записи о тренировках, сообщения |
| Связь с внешними сторонами | Взаимодействие с регулирующими органами, нотифицированными органами | Отчеты о встречах, переписка |

| Домен | Ответственный за | Отчитывается перед | Частота |
|--------|-----------------|------------|-----------|

| Цели в области качества | Достижение цели и актуальность | Исполнительная команда | Ежеквартально |
| Эффективность СМК | Показатели эффективности системы | Управление | Ежемесячно |
| Соответствие нормативным требованиям | Статус соответствия требованиям в разных юрисдикциях | ГЕНЕРАЛЬНЫЙ директор | Ежеквартально |
| Программа аудита | Завершение графика аудита, закрытие результатов | Управление | За каждый аудит |
| Надзор CAPA | Эффективность и своевременность CAPA | Исполнительная команда | Ежемесячно |

## Руководство Ревью воркфлоу { #management-review-workflow }

Проводить ревью руководства в соответствии с требованиями пункта 5.6 стандарта ISO 13485.

### Воркфлоу: Подготовка и проведение ревью руководства { #workflow-prepare-and-execute-management-review }

1. Ревью по управлению графиком (минимум ежегодно, обычно ежеквартально или раз в полгода)
2. Уведомите всех необходимых участников минимум за 2 недели до начала
3. Сбор необходимых исходных данных от владельцев процессов:
   - Результаты аудита (внутреннего и внешнего)
   - Отзывы клиентов (жалобы, удовлетворенность, возвраты)
   - Производительность процесса и соответствие продукции
   - Статус и эффективность CAPA
   - Предыдущие пункты ревью к действиям
   - Изменения, влияющие на СМК (нормативные, организационные)
   - Рекомендации по улучшению
4. Составьте сводный отчет по входным данным с анализом тенденций
5. Подготовьте презентационные материалы с подтверждающими данными
6. Распространите повестку дня и пакет материалов за 1 неделю до этого
7. Провести совещание по ревью в соответствии с повесткой дня
8. **Валидация:** Ревью всех необходимых исходных данных; решения документально подтверждены владельцами и сроками выполнения

### Требуемые участники { #required-attendees }

| Роль | Требование | Ответственность за ввод данных |
|------|-------------|---------------------|
| Генеральный директор/General Manager | Требуемый | Стратегические решения |
| QMR | Стул | Общее состояние СМК |
| Руководители отделов | Требуемый | Производительность процесса |
| Менеджер RA | Требуемый | Изменения в законодательстве |
| Менеджер по производству | Требуемый | Соответствие продукции |
| Качество обслуживания клиентов | Требуемый | Данные о жалобах |

## Управление качественными показателями эффективности воркфлоу { #quality-kpi-management-workflow }

Устанавливайте, контролируйте показатели эффективности качества и сообщайте о них в отчетах.

### Воркфлоу: Создание фреймворка ключевых показателей качества. { #workflow-establish-quality-kpi-framework }

1. Определить цели в области качества, требующие измерения
2. Выберите ключевые показатели эффективности для каждой цели, используя интеллектуальные критерии:
   - Конкретика: Четкое определение и расчет
   - Измеримый: Поддающийся количественной оценке с помощью имеющихся данных
   - Выполнимо: Команда может влиять на результаты
   - Актуально: Соответствует целям в области качества
   - Привязка по времени: Определенная частота измерений
3. Определите целевые значения на основе исходных данных и контрольных показателей
4. Назначьте ответственных за источник данных и сбор
5. Установите частоту отчетности для каждой категории ключевых показателей эффективности
6. Настройка отображения дашбордов и анализа тенденций
7. Определите пороговые значения эскалации и триггеры оповещений
8. ** Проверка:** У каждого ключевого показателя эффективности есть владелец, цель, источник данных и критерии эскалации

### Основные показатели качества { #core-quality-kpis }

| Категория | Ключевые показатели эффективности | Цель | Расчет |
|----------|-----|--------|-------------|
| Процесс | Выход при первом проходе | >95% | (Единицы, пройденные с первого раза / Общее количество единиц) × 100 |
| Процесс | Уровень несоответствия | <1% | (Количество ЧПУ / общее количество единиц измерения) × 100 |
| КАПА | Скорость закрытия КАПЫ | >90% | (Своевременное закрытие / должные закрытия) × 100 |
| КАПА | Эффективность CAPA | >85% | (Эффективные CAPAs / проверенные CAPAs) × 100 |
| Аудит | Определение коэффициента закрытия | >90% | (Своевременное закрытие / должные закрытия) × 100 |
| Аудит | Частота повторных поисков | <10% | (Повторные результаты / Общее количество результатов) × 100 |
| Клиент | Количество жалоб | <0.1% | (Жалобы / проданные единицы) × 100 |
| Клиент | Оценка удовлетворенности | >4.0/5.0 | Среднее значение баллов опроса |

### Частота ревью ключевых показателей эффективности { #kpi-review-frequency }

| Тип KPI | Частота ревью | Период тренда | Аудитория |
|----------|------------------|--------------|----------|
| Безопасность/соответствие требованиям | Ежедневный мониторинг | Еженедельно | Операции |
| Качество продукции | Еженедельно | Ежемесячно | Руководители отделов |
| Качество обслуживания клиентов | Ежемесячно | Ежеквартально | Исполнительная команда |
| Стратегическое качество | Ежеквартально | Ежегодный | Пансион/C-suite |

### Матрица откликов на производительность { #performance-response-matrix }

| Уровень производительности | Статус | Требуемые действия |
|-------------------|--------|-----------------|
| >110% от целевого показателя | Превышающий | Подумайте о повышении целевого показателя |
| 100-110% от целевого показателя | Встреча | Поддерживать текущий подход |
| 90-100% от целевого показателя | Приближающийся | Внимательно следите за происходящим |
| 80-90% от целевого показателя | Ниже | Требуется план улучшения |
| <80% от целевого показателя | Критический | Немедленное вмешательство |

## Цели в области качества Воркфлоу { #quality-objectives-workflow }

Устанавливайте и поддерживайте измеримые цели в области качества в соответствии с пунктом 5.4.1 стандарта ISO 13485.

### Воркфлоу: Ежегодная постановка целей в области качества { #workflow-annual-quality-objectives-setting }

1. Ревью достижения целей за предыдущий год
2. Анализ тенденций и пробелов в показателях качества
3. Согласовать со стратегическим планом организации
4. Сформулируйте цели с поддающимися измерению целевыми показателями
5. Проверка наличия ресурсов для достижения
6. Получить одобрение руководства
7. Информирование о целях в масштабах всей организации
8. ** Проверка:** Каждая цель поддается измерению, имеет владельца, цель и временные рамки

### Объективные категории { #objective-categories }

| Категория | Примерные цели | Типичные цели |
|----------|-------------------|-----------------|
| Качество обслуживания клиентов | Снизить количество жалоб | <0,1% от проданных единиц |
| Качество процесса | Повышение производительности при первом проходе | >96% |
| Соответствие требованиям | Поддерживать сертификацию | Ноль основных NCS |
| Эффективность | Снизить затраты на качество | <4% от выручки |
| Культура | Увеличить количество завершенных тренировок | >98% своевременной доставки |

### Ежеквартальный объективный ревью { #quarterly-objective-review }

| Элемент Ревью | Оценка | Действие |
|----------------|------------|--------|
| Прогресс в сравнении с целью | На трассе / Позади / Впереди | Скорректируйте ресурсы, если они отстают |

| Барьеры | Выявленные препятствия | Эскалация для разрешения |

## Оценка культуры качества Воркфлоу { #quality-culture-assessment-workflow }

Оценивайте и улучшайте организационную культуру качества.

### Воркфлоу: Ежегодная оценка культуры качества { #workflow-annual-quality-culture-assessment }

1. Разработайте или выберите инструмент для исследования культуры качества
2. Определите совокупность участников опроса (всех сотрудников или выборку)
3. Сообщать о цели опроса и конфиденциальности
4. Администрирование опроса с 2-недельным интервалом для ответов
5. Анализ результатов в разбивке по отделам, ролям и срокам пребывания
6. Определите сильные стороны и области совершенствования
7. Разработать план действий по устранению культурных пробелов
8. ** Проверка:** Процент ответов >60%; план действий учитывает 3 нижних балла

### Аспекты культуры качества { #quality-culture-dimensions }

| Измерение | Индикаторы | Метод оценки |
|-----------|------------|-------------------|
| Приверженность лидерству | Видимая поддержка качества со стороны руководства | Опрос, наблюдение |
| Качественное владение | Сотрудники чувствуют ответственность за качество | Опрос |
| Общение | Качественная информация поступает эффективно | Обследование, аудит |
| Постоянное совершенствование | Представленные и реализованные предложения | Показатели |
| Подготовка и компетентность | Сотрудники чувствуют себя должным образом подготовленными | Опрос, записи |
| Решение проблем | Проблемы, устраняемые по первопричине | Анализ CAPA |

### Категории культурного опроса { #culture-survey-categories }

| Категория | Примеры вопросов |
|----------|------------------|
| Лидерство | "Руководство демонстрирует приверженность качеству" |
| Ресурсы | "У меня есть инструменты и подготовка для выполнения качественной работы" |
| Общение | "Ожидания в отношении качества четко изложены" |
| Наделение полномочиями | "Мне рекомендуется сообщать о проблемах с качеством" |
| Признание | "Достижения в области качества признаны" |

### Действия по улучшению культуры { #culture-improvement-actions }

| Выявленный пробел | Возможные действия |
|----------------|-------------------|
| Низкая видимость лидерства | Качественные прогулки по гембе, обновления качества на все руки |
| Недостаточная подготовка | Программа обучения, основанная на компетенциях |
| Плохая коммуникация | Качественные информационные бюллетени, отдел сбивается в кучу |
| Низкий уровень отчетности | Система анонимной отчетности, культура непричастности |
| Отсутствие признания | Программа награждения за качество, командные торжества |

## Надзор за соблюдением нормативных требований { #regulatory-compliance-oversight }

Контролируйте и поддерживайте соблюдение нормативных требований в разных юрисдикциях.

### Матрица соблюдения требований в нескольких юрисдикциях { #multi-jurisdictional-compliance-matrix }

| Юрисдикция | Регулирование | Требование | Отслеживание статуса |
|--------------|------------|-------------|-----------------|
| ЕС | МЛУ 2017/745 | Маркировка CE, уполномоченный орган | Техническое досье, ежегодный ревью |
| США | 21 CFR 820 (QMSR) | Регистрация FDA, соответствие требованиям QMSR — 21 CFR 820 включает ISO 13485:2016 путем ссылки (вступает в силу 2026-02-02; ранее QSR) | Ежегодная регистрация, проверки |
| Международный | ISO 13485 | Сертификация СМК | Надзорные аудиты |
| Германия | МИЛЬ на галлон/MPDG | Национальное осуществление | Заявки в компетентный орган |

### Мониторинг соответствия требованиям Воркфлоу { #compliance-monitoring-workflow }

1. Ведение реестра нормативных требований
2. Подпишитесь на услуги по обновлению нормативных актов
3. Ежемесячно оценивайте влияние нормативных изменений
4. Обновите затронутые процессы в течение 90 дней с даты вступления в силу
5. Проверьте завершение обучения на предмет внесения изменений в нормативные акты
6. Статус соответствия документов при ревью руководства
7. Поддерживайте чек-лист готовности к инспекциям (checklist).
8. ** Проверка:** Сопоставлены все применимые требования; регистраций с истекшим сроком действия нет.

> ** Дисциплина принятия решений:** Данная матрица соответствия предназначена для поддержки принятия решений, а не для определения соответствия. Окончательные запросы о статусе регулирующих органов вы можете сделать как QMR и они должны быть подписаны указанным владельцем; направляйте вопросы, касающиеся FDA, в Отдел регулирования и проверяйте текущий текст 21 CFR 820 (QMSR) / ISO 13485:2016 по адресу fda.gov прежде чем полагаться на какую-либо цитату здесь.

### Дерево решений по эскалации { #escalation-decision-tree }

```
Issue Identified
      │
      ▼
Is it a regulatory violation?
      │
  Yes─┴─No
  │      │
  ▼      ▼
Escalate to    Is it a safety issue?
Executive          │
immediately    Yes─┴─No
               │      │
               ▼      ▼
          Escalate to   Does it affect
          Safety Team   multiple departments?
                             │
                         Yes─┴─No
                         │      │
                         ▼      ▼
                    Escalate to  Handle at
                    Executive    department level
```

### Определение приоритетов качественных инвестиций { #quality-investment-prioritization }

| Критерии | Вес | Метод подсчета очков |
|----------|--------|--------------|
| Нормативное требование | 30% | Требуется=10, рекомендуется=5, необязательно=2 |
| Влияние на потребителя | 25% | Прямое=10, косвенное=5, Нет=0 |
| Потенциал экономии средств | 20% | >100 тысяч долларов=10, 50-100 тысяч долларов=7, <50 тысяч долларов=3 |
| Сложность реализации | 15% | Простой=10, Умеренный=5, Сложный=2 |
| Стратегическое согласование | 10% | Ядро=10, поддержка=5, периферийное устройство=2 |
