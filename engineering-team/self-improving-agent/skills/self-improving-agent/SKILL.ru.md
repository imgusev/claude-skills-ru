# Самосовершенствующийся агент { #self-improving-agent }

> Автоматический захват в память. Этот плагин курирует.

Автоматическая память Claude Code (версия 2.1.32+) автоматически записывает шаблоны проектов, информацию об отладке и ваши предпочтения в `MEMORY.md`. Этот плагин добавляет уровень интеллекта: он анализирует то, чему научился Клод, внедряет проверенные шаблоны в правила проекта и извлекает повторяющиеся решения в многоразовые скиллы.

## Краткий справочник { #quick-reference }

| Команда | Что он делает |
|---------|-------------|
| `/si:review` | Анализировать MEMORY.md — поиск кандидатов на повышение по службе, устаревших заявок, возможностей консолидации |
| `/si:promote` | Создайте шаблон из MEMORY.md → CLAUDE.md или `.claude/rules/` |
| `/si:extract` | Превратите проверенный шаблон в самостоятельный скилл |
| `/si:status` | Дашборд работоспособности памяти — количество строк, файлы тем, рекомендации |
| `/si:remember` | Явное сохранение важных знаний в автоматической памяти |

## Архитектура памяти { #memory-architecture }

### Где живут вещи { #where-things-live }

| Файл | Кто пишет | Сфера применения | Заряженный |
|------|-----------|-------|--------|
| `./CLAUDE.md` | Ты (+ `/si:promote`) | Правила проекта | Полный файл, каждый сеанс |
| `~/.claude/CLAUDE.md` | Ты | Глобальные предпочтения | Полный файл, каждый сеанс |
| `~/.claude/projects/<path>/memory/MEMORY.md` | Клод (авто) | Обучение в рамках проекта | Первые 200 строк |
| `~/.claude/projects/<path>/memory/*.md` | Клод (переполнение) | Примечания по конкретной теме | По требованию |
| `.claude/rules/*.md` | Ты (+ `/si:promote`) | Ограниченные правила | При открытии соответствующих файлов |

### Жизненный цикл продвижения { #the-promotion-lifecycle }

```
1. Claude discovers pattern → auto-memory (MEMORY.md)
2. Pattern recurs 2-3x → /si:review flags it as promotion candidate
3. You approve → /si:promote graduates it to CLAUDE.md or rules/
4. Pattern becomes an enforced rule, not just a note
5. MEMORY.md entry removed → frees space for new learnings
```

## Основные концепции { #core-concepts }

### Автоматическое запоминание - это захват, а не кураторство { #auto-memory-is-capture-not-curation }

Автоматическая память отлично справляется с записью того, что узнает Клод. Но у него нет никакого суждения о:
- Какие знания являются временными, а какие постоянными
- Какие шаблоны должны стать принудительными правилами
- Когда ограничение в 200 строк приводит к пустой трате места на устаревшие записи
- Какие решения достаточно хороши, чтобы стать скиллами многократного использования

Это то, что делает этот плагин.

### Продвижение по службе = окончание учебы { #promotion--graduation }

Когда вы продвигаете обучение, оно перемещается из блокнота Клода (MEMORY.md ) в систему правил вашего проекта (CLAUDE.md или `.claude/rules/`). Разница имеет значение:

- **MEMORY.md **: "Я заметил, что в этом проекте используется pnpm" (фоновый контекст)
- **CLAUDE.md **: "Используйте pnpm, а не npm" (принудительная инструкция)

Продвигаемые правила имеют более высокий приоритет и загружаются полностью (не усекаются на 200 строк).

### Каталог правил для получения ограниченных знаний { #rules-directory-for-scoped-knowledge }

Не все принадлежит CLAUDE.md . Использование `.claude/rules/` для шаблонов, которые применяются только к определенным типам файлов:

```yaml
# .claude/rules/api-testing.md
---
paths:
  - "src/api/**/*.test.ts"
  - "tests/api/**/*"
---
- Use supertest for API endpoint testing
- Mock external services with msw
- Always test error responses, not just happy paths
```

Это загружается только тогда, когда Claude работает с тестовыми файлами API — в противном случае накладные расходы равны нулю.

## Агенты { #agents }

### память-аналитик { #memory-analyst }
Анализирует MEMORY.md и тематические файлы для идентификации:
- Записи, которые повторяются в разных сессиях (кандидаты на повышение)
- Устаревшие записи, ссылающиеся на удаленные файлы или старые шаблоны
- Связанные записи, которые следует консолидировать
- Промежутки между тем, что MEMORY.md знает и что CLAUDE.md обеспечивает соблюдение

### скилл-экстрактор { #skill-extractor }
Использует проверенный шаблон и генерирует полный скилл:
- SKILL.md с надлежащим передним материалом
- Справочная документация
- Примеры и крайние случаи
- Готов к `/plugin install` или `clawhub publish`

## Крючки { #hooks }

### фиксация ошибок (PostToolUse → Bash) { #error-capture-posttooluse--bash }
Отслеживает вывод команды на наличие ошибок. При обнаружении добавляет структурированную запись в автоматическую память с помощью:
- Команда, которая завершилась неудачей
- Вывод ошибки (усеченный)
- Временная метка и контекст
- Предлагаемая категория

** Накладные расходы на токены: ** Ноль в случае успеха. ~30 токенов только при обнаружении ошибки.
