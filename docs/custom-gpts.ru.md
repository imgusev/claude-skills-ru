## Как это работает { #how-it-works }

1. ** Нажмите** на любую ссылку "Открыть в ChatGPT" выше
2. ** Начать общение в чате ** — GPT предварительно настроен с учетом знаний о домене
3. ** Получите структурированный вывод** — не общие рекомендации, а фреймворки и действенные воркфлоу

** Требования:** ChatGPT Plus, Pro или командный план.

## GPTs против. Установленные скиллы { #gpts-vs-installed-skills }

| | Пользовательские GPTS | Установленные скиллы |
|---|---|---|
| **Платформа** | Общайтесь в чате | Код Клода, Codex, Gemini CLI, курсор, + еще 7 |
| **Настройка** | Перейдите по ссылке | `git clone` + установить скрипт |
| **Глубина** | 1 скилл за GPT | 345 скилл, более 90 агентов, 3 персонажа |
| **Настройка на заказ** | Используйте как есть | Полный исходный код, лицензия MIT, свободно распространяется |
| **Контекст** | Основанный на чате | Интегрирован в вашу кодовую базу и воркфлоу |
| **Лучше всего подходит для** | Быстрый доступ, исследование | Ежедневный воркфлоу-процесс разработки |

GPT - это ** предварительный просмотр ** того, что предлагает полная библиотека. Если вы сочтете GPT полезным, установленная версия для скилла будет более глубокой — с доступом к вашим файлам, кодовой базе и контексту проекта.
