# Лучшие плагины и скиллы Claude Code (2026) { #best-claude-code-plugins--skills-2026 }

Ищете лучшие плагины Claude Code для оптимизации вашего воркфлоу? В этом руководстве рассматриваются 20 готовых к производству плагинов и скиллы агентов - от проектирования и DevOps до маркетинга, управления продуктами и консультирования на уровне C.

Все перечисленные здесь плагины имеют открытый исходный код (MIT), протестированы в рабочей среде и могут быть установлены одной командой.

---

## В чем разница между плагинами и Скиллами? { #whats-the-difference-between-plugins-and-skills }

**Плагины Claude Code** используйте `.claude-plugin/plugin.json` форматирование и установка с помощью `/plugin install`. **Скиллы агента** использование `SKILL.md` файлы и работа с Claude Code, Codex, Gemini CLI, Cursor и 8 другими агентами кодирования.

Это репозиторий предоставляет ** оба формата** — каждый скилл включает в себя `.claude-plugin` каталог для поддержки встроенного плагина Claude Code, а также `SKILL.md` для кросс-платформенной совместимости.

---

## Быстрая установка { #quick-install }

```bash
# Install the full marketplace (all 345 skills as Claude Code plugins)
claude /plugin install https://github.com/alirezarezvani/claude-skills

# Install by domain
claude /plugin install engineering-skills
claude /plugin install marketing-skills
claude /plugin install devops-skills

# Install individual plugins
claude /plugin install frontend-design
claude /plugin install pr-review-expert
claude /plugin install autoresearch-agent
```

## Зачем нужны эти плагины? { #why-these-plugins }

В отличие от универсальных плагинов, это ** скиллы агента высокого уровня - каждый включает в себя:

- ** Структурированные воркфлоу** с слэш-командами (не только промпт)
- **Инструменты Python CLI** (всего 254, ноль зависимостей от pip)
- **Справочные документы** — шаблоны, чек-листы, знания по предметной области
- ** Кроссплатформенная поддержка ** — работает с 11 агентами кодирования, а не только с Claude Code

## Кроссплатформенная совместимость { #cross-platform-compatibility }

Каждый плагин в этой коллекции работает с несколькими агентами по кодированию искусственного интеллекта:

| Инструмент | Формат | Способ установки |
|------|--------|---------------|
| Код Клода | `.claude-plugin` | `/plugin install` |
| Кодекс OpenAI | `.codex/skills/` | `./scripts/codex-install.sh` |
| Интерфейс Gemini CLI | `.gemini/skills/` | `./scripts/gemini-install.sh` |
| Курсор | `.cursor/skills/` | `./scripts/convert.sh --tool cursor` |
| Открытый коготь | `clawhub install` | Через маркетплейс ClawHub |
| Помощник, Виндсерфинг, Килограммовый код, Открытый код, Дополнение, Антигравитация | Преобразованные форматы | `./scripts/convert.sh --tool <name>` |
