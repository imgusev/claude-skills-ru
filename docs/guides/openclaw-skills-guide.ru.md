# Руководство по скиллам OpenClaw — Установите и используйте скиллы агента с OpenClaw { #openclaw-skills-guide--install--use-agent-skills-with-openclaw }

> ** Последнее обновление:** Июнь 2026 · ** Количество скилл:** 345 · ** Совместимость:** OpenClaw v2024.12+

## Что такое Скиллы OpenClaw? { #what-are-openclaw-skills }

Скиллы OpenClaw — это модульные пакеты инструкций, которые расширяют знания вашего агента OpenClaw в предметной области - от проектирования и DevOps до маркетинга, соответствия требованиям и консультаций на уровне C. Каждый скилл попадает в ваше рабочее пространство OpenClaw и сразу же работает с нулевой настройкой.

В отличие от общих промптов, скиллы OpenClaw включают структурированные воркфлоу, фреймворки принятия решений, инструменты Python и справочные материалы, которым ваш агент следует автономно.

## Зачем использовать Скиллы с OpenClaw? { #why-use-skills-with-openclaw }

| Без Скилл | Обладающий скиллами |
|---|---|
| Общие ответы | Результаты на уровне эксперта по предметной области |
| Разработка ручных промптов | Предварительно созданные воркфлоу с слэш-командами |
| Никаких инструментов | Скрипты на Python для анализа, проверки, форматирования |
| Начинает с нуля | Включены ссылки, шаблоны, лучшие практики |

Система скилл OpenClaw наиболее органично вписывается в экосистему — скиллы хранятся в каталоге вашего рабочего пространства и автоматически загружаются в зависимости от контекста задачи.

## Установка { #installation }

### Быстрая установка (рекомендуется) { #quick-install-recommended }

```bash
bash <(curl -s https://raw.githubusercontent.com/imgusev/claude-skills-ru/main/scripts/openclaw-install.sh)
```

Это установит все 345 скилла в ваше рабочее пространство OpenClaw с правильной структурой каталогов.

### Ручная установка { #manual-install }

```bash
git clone https://github.com/imgusev/claude-skills-ru.git
cd claude-skills-ru
./scripts/install.sh --tool openclaw
```

### Устанавливайте специальные пакеты Скилл { #install-specific-skill-packs }


## Как работают скиллы в OpenClaw { #how-skills-work-in-openclaw }

OpenClaw поддерживает встроенные скиллы — он сканирует `<available_skills>` в вашем рабочем пространстве и автоматически выбирает нужный скилл для каждой задачи.

** Автоматический выбор:** Когда вы просите своего агента OpenClaw "оптимизировать этот файл Docker", он считывает `docker-development` скиллы SKILL.md и следует своему воркфлоу. Ручная активация не требуется.

**Слэш-команды:** Каждый скилл определяет слэш-команды (например,, `/docker:optimize`, `/research:summarize`), которые запускают определенные триггеры воркфлоу.

** Инструменты Python:** Скиллы включают исполняемые скрипты в `scripts/` который ваш агент может запускать для выполнения задач анализа, проверки и генерации.

## Анатомия Скиллы { #skill-anatomy }

Каждый скилл в репозитории имеет одинаковую структуру:

```
skill-name/
├── SKILL.md              # Instructions, workflows, slash commands
├── .claude-plugin/
│   └── plugin.json       # Metadata for plugin registries
├── scripts/
│   ├── tool_one.py       # Executable Python tools
│   └── tool_two.py
└── references/
    ├── patterns.md       # Domain knowledge, templates
    └── best-practices.md
```

## Создаем пользовательские скиллы OpenClaw { #creating-custom-openclaw-skills }

Вы можете создавать свои собственные скиллы в том же формате:

1. Создайте каталог в папке "Скиллы" вашего рабочего пространства
2. Написать `SKILL.md` с описанием, слэш-командами и воркфлоу
3. Добавьте скрипты Python в `scripts/` для любой автоматизации
4. Добавьте справочные материалы в `references/`
5. OpenClaw автоматически обнаружит и использует ваши скиллы

Используйте `skill-creator` мета-скилл для создания управляемого скилла:
```
/skill:create my-custom-skill
```
