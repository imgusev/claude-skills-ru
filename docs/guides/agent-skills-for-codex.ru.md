# Скиллы агента для OpenAI Codex CLI { #agent-skills-for-openai-codex-cli }

Используйте скиллы агента 345, готовые к работе, с помощью OpenAI Codex CLI. Каждый скилл в этой коллекции изначально работает с Codex через `.codex/skills/` формат каталога.

---

## Быстрая установка { #quick-install }

```bash
# Clone the repository
git clone https://github.com/alirezarezvani/claude-skills.git
cd claude-skills

# Option 1: Install all skills for Codex
./scripts/codex-install.sh

# Option 2: Convert specific skills
./scripts/convert.sh --skill frontend-design --tool codex
./scripts/convert.sh --skill autoresearch-agent --tool codex

# Option 3: Convert all skills at once
./scripts/convert.sh --all --tool codex
```

### Как это работает { #how-it-works }

Кодекс считывает скиллы агента из `.codex/skills/<skill-name>/SKILL.md` в вашем проекте или домашнем каталоге. Тот `convert.sh` сценарий преобразует код Клода SKILL.md форматирование в инструкции, совместимые с Codex, с сохранением всех воркфлоу, слэш-команд и ссылок.

## Советы, относящиеся к конкретному Кодексу { #codex-specific-tips }

### AGENTS.md Запасной вариант { #agentsmd-fallback }

Если в вашей настройке кодекса используется `AGENTS.md` вместо директории "скиллы" вы можете использовать сгенерированный файл "агенты":

```bash
# Copy the bundled AGENTS.md to your project
cp claude-skills/agents/AGENTS.md ~/.codex/AGENTS.md
```

### Использование с `--full-auto` { #using-with---full-auto }

Скиллы легко работают в режиме автоматического утверждения Кодекса:

```bash
# Run a skill in full-auto mode
codex exec --full-auto "Use the frontend-design skill to build a dashboard component"

# Run autoresearch overnight
codex exec --full-auto "Use autoresearch-agent to optimize src/api/search.py for response time"
```

### Уровень проекта по сравнению с глобальным { #project-level-vs-global }

```bash
# Project-level (only this repo)
cp -r claude-skills/.codex/skills/ ./.codex/skills/

# Global (available everywhere)
cp -r claude-skills/.codex/skills/ ~/.codex/skills/
```
