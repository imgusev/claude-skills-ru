# :material-account-group: Персонажи { #material-account-group-personas }

<p class="domain-count">3 persona-based agents for role embodiment</p>

</div>

Персонажи выходят за рамки агентов по заданиям. Они определяют, как агент мыслит, расставляет приоритеты и общается — в комплекте с идентификацией, фреймворками суждений и кураторскими скиллами.

### Персонажи против агентов по выполнению задач { #personas-vs-task-agents }

| | Агенты задач | Персонажи |
|---|---|---|
| **Цель** | Выполнить конкретную задачу | Распределяйте роли по задачам |
| **Сфера применения** | Единый домен | Междоменный, курируемый |
| **Голос** | Нейтральный, профессиональный | Личностный подход с предысторией |
| **Воркфлоу** | Одноступенчатый | Многоступенчатый процесс с точками принятия решений |
| **Вариант использования** | "Выполните это задание" | "Думай как этот человек" |

И то, и другое сосуществует. Используйте агентов задач для целенаправленной работы, персонажей для постоянного сотрудничества.

## Использование { #usage }

### Код Клода { #claude-code }
```bash
cp agents/personas/startup-cto.md ~/.claude/agents/
# Then: "Activate startup-cto mode"
```

### Любой поддерживаемый инструмент { #any-supported-tool }
```bash
./scripts/convert.sh --tool cursor   # Converts personas too
./scripts/install.sh --tool cursor --target /path/to/project
```

### Создайте свой собственный { #create-your-own }

Используйте [TEMPLATE.md](https://github.com/alirezarezvani/claude-skills/blob/main/agents/personas/TEMPLATE.md) чтобы создавать пользовательских персонажей с вашей собственной индивидуальностью, скиллами и воркфлоу.
