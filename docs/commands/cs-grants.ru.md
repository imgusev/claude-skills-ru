**Команда:** `/cs:grants <research-idea>`

Тот `cs-grants` персона публикует стратегический обзор финансирования NIH в виде редактируемого `.docx` для клинических исследователей.

## Когда запускать { #when-to-run }

- Определение объема финансирования NIH для новой исследовательской идеи
- Подготовка к подаче заявки на получение премии R01 / R21 / K
- Определение целей института + разделы исследования
- Создание формулировки значимости проекта/инновации

## Область применения только для NIH { #nih-only-scope }

Спонсоры, не входящие в NIH (PCORI, DOD CDMRP, VA, фонды), находятся ** вне сферы охвата** — всплывают и помечаются при приеме. Используйте другой скилл или выполните поиск вручную.

## Принудительный прием пищи (6 вопросов, по одному за раз) { #forcing-intake-6-questions-one-at-a-time }

| Вопрос | Спрашивает | Примечания |
|---|---|---|
| Вопрос 1 | Исследовательская идея (2-3 предложения) | отказывается расплывчато; "Искусственный интеллект для здравоохранения" отодвигается на второй план |
| Q2 | Стадия карьеры: докторантура / постдокторантура / ранняя карьера / независимый / старший | вынуждающий выбор |
| Вопрос 3 | Предварительные данные: отсутствуют / пилотные / надежные / подтвержденные | вынуждающий выбор |
| Q4 | Среда: Подходящая для R01 / средний уровень / ограниченные ресурсы / отраслевой коллаборационизм | вынуждающий выбор |
| Q5 | Позиция подачи: новая / повторная подача / изучение | вынуждающий выбор |
| Q6 | Известные цели института, или "нет предпочтений — найдите правильные" | примите либо |

Условие остановки: после Q6 зафиксируйте и начните фазу 2A. Никогда повторно не открывайте впуск.

## Что Вы получаете { #what-you-get }

В конце концов, 6 вопросов + Фаза 2A (консенсус) + Фаза 2B (репортер) + Обнаружение NOSI + Фаза 3 DOCX:

```
grants_<topic-slug>_<YYYY-MM-DD>.docx

9 sections:
1. Executive Summary (career stage, environment, 3-4 key findings)
2. Research Positioning (3-5 gap quotes + draft Significance/Innovation)
3. Target Institutes (ranking table + interpretation)
4. Grant Opportunities (NOSI callout if any + top-3 FOAs)
5. Funded Overlap (top-5 projects + differentiation)
6. Study Sections (ranking + best-match)
7. Strategic Recommendations & Next Steps (3-4 recs + program officer + timeline)
8. References (numbered, hyperlinked to Consensus)
9. Audit Log (Consensus + RePORTER + NOSI tables + counts + plan tier)
```

## Критические ограничения, связанные с инструментами { #critical-tool-constraints }

- **Консенсус**: 1 вопрос/sec последовательный. План-уровень, обнаруженный по шаблонам "Найдено N, показывающих верхние M".
- **Репортер**: ** Только для публикации**. Использование `bash_tool` + `curl`. НИКОГДА `web_fetch` (GET-only — завершится молчаливым сбоем).
- ** НОСИ принеси**: `web_fetch` для `NOT-*` URL-адреса. Если выборка завершается неудачей, войдите в систему `[NOSI {number} — fetch failed]` и продолжайте.

## Дисциплина (Соглашение об исследовательском пакете) { #discipline-research-pack-convention }

- **Один прием Q за оборот.** Никогда не связывайте.
- **Последовательный консенсус.** 1 вопрос/sec.
- ** СООБЩЕНИЕ репортера.** `bash_tool` + `curl`. Не `web_fetch`.
- **Дисциплина источника.** Приводите только результаты сеанса.
- ** Отслеживание по трем показателям.** Отправлено / показано / процитировано (консенсус) + проекты / процитировано (репортер).
- **Обнаружение на уровне плана при первом согласовании.** Всплывающее окно в аудите.
- ** Динамическое окно FY.** Вычисление во время выполнения; никогда не вводите годы жесткого кода.
- ** Механизмы, учитывающие сферу применения. ** Карьерный этап + сфера применения + предварительный этап, а не только этап.
- ** Рекомендация сотрудника обязательной программы.** Единственный самый ценный совет.

## Ссылка на механизм (встроенный) { #mechanism-reference-embedded }

| Механизм | Этап карьеры | Сфера применения | Необходима предварительная подготовка | Бюджет (типичный) |
|---|---|---|---|---|
| F31, F32 | Стажер | Одиночная тренировка | Нет –пилот | $40-50 тыс./yr × 2-3 года |
| T32 | Инст. гранты на обучение | Предварительный документ/postdoc | Институциональный | Меняется |
| R03 | Независимый | Маленький/pilot | Нет –пилот | 50 тысяч долларов/yr × 2 года |
| R21 | Независимый | Пилот/exploratory | Нет –пилот | $275 тыс. постоянного тока × 2 года |
| Серия K | Ранняя карьера | Карьерный разработчик. | Пилот | $100-180 тыс. × 5 лет |
| K99/R00 | Постдок → инд. | Переход | Сильный | $90 тыс. + $250 тыс. × 3 года |
| R01 | Независимый | Основанный на гипотезах | Сильный | $250-499 тыс. × 4-5 лет |
| R35 | Старший частный детектив | Программа | Подтвержденный | $750 тыс. × 5-8 лет |
| U01 | Многосайтовый | Кооперативный | Строго проверенный | Варьируется; обычно >500 тысяч долларов |
| P01/P30 | Старший | Программа | Подтвержденный | Мульти-ПИ; >1 млн долларов/yr |

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Распараллеливание согласованных вызовов
- Используя `web_fetch` для репортера (только для публикации)
- Жестко заданные значения за финансовый год
- Рекомендации механизма только на этапе карьеры
- Безмолвно заполняя тонкие грани обучающими знаниями
- Пропуск журнала аудита
- Рекомендация сотрудника по пропуску программы
- Объединение "найдено" / "показано" / "процитировано"
- Создание сведений о NOSI при сбое выборки
