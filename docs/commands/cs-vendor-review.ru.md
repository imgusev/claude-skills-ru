Запустите `vendor-management` скилл на основе этого ввода:

**$ARGUMENTS**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`vendor_scorer.py`** — Оцените каждого поставщика от 0 до 100 баллов по 5 взвешенным параметрам: надежность, поддержка, безопасность, коммерческая эффективность, стратегическое соответствие. Отраслевая настройка с помощью `--profile {saas,fintech,healthcare,enterprise}`. Вердикт: СОХРАНИТЬ / РЕВЬЮ / ЗАМЕНИТЬ.

2. **`sla_compliance_tracker.py`** — Вычислить процент соответствия требованиям для каждого поставщика, тенденцию нарушений (улучшение/stable/degrading), право на получение кредита.

3. **`vendor_risk_classifier.py`** — Классифицируйте риски в соответствии с фреймворком SIG-Lite для общих оценок: критический/высокий/средний/низкий по 4 векторам (чувствительность данных, финансовая подверженность, операционная зависимость, нормативная подверженность). Настраиваемый в отрасли.

## Выход { #output }

- Система показателей для каждого поставщика (Markdown)
- Разбивка соответствия SLA с указанием флагов кредитных требований
- Матрица рисков с действиями по смягчению последствий для каждого вектора
- Топ-3 поставщиков для ревью или ЗАМЕНЫ

## Отличный от { #distinct-from }

- `c-level-advisor/general-counsel-advisor` — это договорное право + красная линия. Это **операционная эффективность поставщика**.
- `business-growth/contract-and-proposal-writer` — это разработка внешнего предложения. Это **оценка входящих поставщиков**.
- Родной брат `procurement-optimizer` — это категоризация расходов + рационализация поставщиков. Это ** производительность поставщика + риск**.
