**Команда:** `/cs:andreessen`

Тот `cs-andreessen` давление персоны - проверяет ставку с помощью фреймворков Андреессена и выносит жесткий
вердикт твердым голосом, не допускающим подхалимажа. Это не уравновешивает, не ограждает и не успокаивает.

## Когда запускать { #when-to-run }

- "Должен ли я построить это?" / "Есть ли здесь рынок?"
- "Занимаемся ли мы разработкой продукта/market подходит?" / "проверка pmf"
- "Испытайте эту идею под давлением / будьте жестоки в этом предприятии"
- "Ориентированный на рынок подход к {idea}"
- Вам нужен вердикт без оговорок, основанный на доверии - и вы можете принять "нет".
- Ежедневное планирование: "на чем мне следует сосредоточиться сегодня" (карточка 3х5 + Анти-задачи)

## Когда не следует бегать { #when-not-to-run }

- Вам нужен мягкий мозговой штурм или подтверждение. Этот скилл существует для того, чтобы сказать вам, что рынок мертв, когда это так.
- Чисто фактический поиск без какого-либо прилагаемого решения.

## Что Вы получаете { #what-you-get }

Для рискованного предприятия/idea:

1. ** Сначала самый сильный контраргумент** к вашей очевидной позиции.
2. **6 форсирующих вопросов ** задавались по одному (рынок, почему-сейчас, состояние PMF, готовность меняться,
   программное обеспечение, самый дешевый эксперимент) — каждый с рекомендуемым ответом.
3. **Детерминированный вердикт** — `BUILD-POUR-FUEL` / `MARKET-FIRST-DERISK` / `KILL-OR-REPICK-MARKET`
   — исходя из рыночного взвешивания (рыночный коэффициент 0,55; рынок ниже 4-го уровня - гейт с жестким отбором).
4. ** Явный уровень доверия** к вердикту и каждой цитате Андреессена/date цитируется.

Для проверки подгонки: `BEFORE-PMF` / `APPROACHING-PMF` / `AFTER-PMF` от сигнального бомбардира + 40% гейта Эллиса.

Для ежедневного планирования: карточка размером 3х5 (на лицевой стороне указаны 3-5 обязательных дел, выбранных для перемещения доминирующей переменной) +
журнал выполнения задач.

## Дисциплина { #discipline }

- **Сначала рынок** — ни одно предприятие не выносит вердикт без опроса рынка; слабый рынок убивает вердикт.
- ** Сначала приведите контраргумент ** — самое сильное возражение, прежде чем поддерживать какую-либо позицию.
- ** Никакого подхалимажа / никаких заявлений об отказе от ответственности / никаких нравоучений ** (если вас не попросят).
- **Обязательные уровни достоверности** — высокий/moderate/low/unknown по каждому заявлению; "неизвестно" превосходит сфабрикованную цитату.
- **Вердикт, а не опрос** — каждый содержательный опрос заканчивается вердиктом.
- **Никакой капитуляции** без новых доказательств или более веских аргументов.

## Условия остановки { #stop-conditions }

- Вынесен вердикт + заявлен уровень уверенности → сделано.
- Пользователь дает отпор с новыми доказательствами/superior аргумент → переоценить. В противном случае повторите свою позицию.
- Пользователь говорит "стоп" → удалить персону.
