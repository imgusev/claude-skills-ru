**Команда:** `/cs:notebooklm`

Тот `cs-notebooklm` персона управляет Google NotebookLM с помощью автоматизации браузера с помощью 4 основных действий.

## Важнейшая предпосылка { #critical-prerequisite }

** Требуется среда автоматизации браузера.** Работает в:

- Claude Code CLI с использованием компьютера
- Расширение Claude Chrome
- Драматург / кукловод со скриншотом + инструменты для кликов

НЕ работает в:

- Клод.ai web (без автоматизации браузера) — скилл завершается без сбоев на шаге 0

## Когда запускать { #when-to-run }

- Хотите задать вопрос своему существующему блокноту NotebookLM (действие 1)
- Хотите добавить источник (URL / текст / файл / Google Doc / YouTube) в записную книжку (действие 2)
- Хотите сгенерировать студийный результат (аудиообзор / инфографику / слайды / Учебное пособие / и т.д.) (Действие 3)
- Хотите создать новый блокнот с нуля (действие 4)

## Ввод маршрута действия (2-4 форсирующих вопроса) { #action-routing-intake-2-4-forcing-questions }

| Вопрос | Спрашивает | Примечания |
|---|---|---|
| Вопрос 1 | Действие: прочитать / добавить исходный код / выходные данные студии / создать новый | Принуждение — отказывается начинать без обязательств |
| Q2 | Название или URL-адрес записной книжки (действия 1-3) ИЛИ заголовок для новой записной книжки (действие 4) | Управляет навигацией |
| Вопрос 3 | Параметр, зависящий от конкретного действия (текст вопроса / тип источника / Тип выходных данных студии / исходные источники) | Филиалы за 1 квартал |
| Q4 | Пользовательская информация о промпте студии | Задается только в том случае, если Q1=3 (студия); обязательно |

Большинство вызовов останавливаются на Q3. Q4 запускается только для генерации Studio.

## Что Вы получаете { #what-you-get }

За каждое действие:

| Действие | Результат |
|---|---|
| Чтение/извлечение | Чистый ответ из чата записной книжки (не необработанный дамп) |
| Добавление источников | Подтверждение приема пищи (со скриншотом) |
| Студийный результат | Подтверждение того, что генерация запущена + "NotebookLM уведомит вас, когда будет готов" — запуск и уведомление |
| Создавать новые | Добавлен новый URL-адрес записной книжки + подтверждение исходных источников |

## Типы студийных выходных данных { #studio-output-types }

Поддерживаются все 9 типов:

- Обзор аудио (5-10 мин. генерация — запуск и уведомление)
- Учебное пособие
- Документ для брифинга
- Временная шкала
- Часто задаваемые вопросы
- Оглавление
- Инфографика
- Слайды (слайд-дека)
- Ментальная карта

## Обязательные пользовательские промпты { #mandatory-custom-prompts }

Промпты Studio по умолчанию выдают посредственный результат. Пользователь скилла ВСЕГДА открывает меню настройки и записывает подробную пользовательскую промпту перед отправкой.

Примеры для каждого типа вывода:

| Выход | Пример пользовательского промпта |
|---|---|
| Обзор аудио | "Беседа с двумя ведущими для нетехнического руководителя, 8-10 минут, сосредоточьтесь на бизнес-последствиях, а не на технической глубине" |
| Инфографика | "Стиль дерева решений, ориентированный на действие, максимум 6 панелей, монохромный темно-синий" |
| Учебное пособие | "Уровень бакалавра, определения + 3 практических вопроса по каждой концепции" |
| Слайды | "Максимум 12 слайдов, 1-2 предложения на слайд, заметки докладчика с примерами на слайд" |

## Дисциплина { #discipline }

- **Шаг 0 проверка среды ** — проверка автоматизации браузера; быстрый сбой, если нет
- **Сначала снимок экрана ** - каждому действию пользовательского интерфейса предшествует снимок экрана
- **find()-перед щелчком мыши** - семантический поиск по пиксельным координатам
- ** Никогда не выполняйте автоматическую обработку входа в систему ** — обнаружьте стену входа, остановитесь, попросите пользователя войти вручную
- ** Пользовательские промпты Studio всегда ** — откройте меню настройки, напишите подробный промпт
- ** Запуск и уведомление при медленных операциях ** — Генерация Studio не блокирует этот сеанс
- ** Язык, не зависящий от инструментов ** - "инструмент автоматизации браузера", а не "Расширение Claude Chrome".

## Условия остановки { #stop-conditions }

- Автоматизация браузера недоступна → остановка на шаге 0 с четким сообщением
- Q1 отказано в выполнении обязательства по действию → приостановить, повторно запросить
- Обнаружена стена входа в систему → приостановить, попросить пользователя войти вручную
- Макет страницы неожиданно изменился → скриншот, обратитесь к пользователю за советом
- 3 последовательных сбоя UI find() → остановка, предупреждение пользователя

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Имена, относящиеся к конкретному инструменту, без абстракции (например, жестко закодированное "Расширение Claude Chrome")
- Синхронное ожидание в студийных поколениях (особенно обзор аудио)
- Пропуск скриншотов между действиями
- Использование пиксельных координат, когда доступна функция семантического поиска()
- Попытка автоматически обрабатывать потоки входа в систему
- Создание студийных выходных данных без открытия меню настройки
- Использование промптов Studio по умолчанию (всегда пишите пользовательские)
