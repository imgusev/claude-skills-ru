Запустите `rfp-responder` скилл на основе этого ввода:

**$ARGUMENTS**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`rfp_parser.py`** — Извлекает разделы + требования + критерии оценки из текста запроса предложений. Пометьте каждое требование тегами: ОБЯЗАТЕЛЬНОЕ / ВЗВЕШЕННОЕ / ПРИЯТНОЕ ДЛЯ ИСПОЛЬЗОВАНИЯ. Поверхности, оценивающие вес, если он указан.

2. **`response_drafter.py`** — Матрица контрольных точек в соответствии с требованиями (тематические исследования, сертификаты, предложения клиентов, технические аттестации). Отказывается выдумывать утверждения — требует либо проверяемый источник, либо явный ярлык "ПРОБЕЛ". Внедрение выигрышной темы в соответствии с методологией Шипли.

3. **`winrate_predictor.py`** — Оценка винрейта, полученная Шипли на основе: преимущества действующего игрока, % соответствия требованиям, прочности отношений с покупателем, соответствия критериям принятия решения, штрафа за поздний вход.

## Жесткое правило { #hard-rule }

** Каждый пункт доказательства должен иметь поддающийся проверке источник. ** Никаких выдуманных утверждений. Метки пробелов появляются явно, поэтому руководство решает, обращаться к ним или нет.

## Отличный от { #distinct-from }

- `business-growth/contract-and-proposal-writer` — ** составление предложения в свободной форме ** (на основе вашего повествования). RFP-ответчик обрабатывает ** структурированный** ответ, в котором покупатель диктует формат и вопросы.
- `c-level-advisor/general-counsel-advisor` — красная линия контракта. RFP-ответчик - это ответ **до** заключения контракта.
- `marketing-skill/*` — внешние маркетинговые ресурсы (интернет, реклама, контент). RFP-ответчик - это артефакт, способствующий продажам, привязанный к одному покупателю.
