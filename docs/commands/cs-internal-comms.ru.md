Запустите `internal-comms` скилл на основе этого ввода:

**$АРГУМЕНТЫ**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`comms_template_filler.py`** — Пакет связи с привязкой к ADKAR (предварительное сообщение / анонс / часто задаваемые вопросы / продолжение). Каждая точка соприкосновения помечена тем, какую стадию ADKAR она обслуживает (Осознание / желание / Знание / Способность / Подкрепление).

2. **`change_announcement_builder.py`** — Объявление, соответствующее 8 шагам Коттера (Срочность → Коалиция → Видение → Общение → Расширение прав и возможностей → Победы → Поддержка → Якорь). Подтверждает: никаких "захватывающих новостей" о разрушительных изменениях, никаких "незначительных обновлений" о масштабных изменениях. Калибровка тона с помощью `--profile {tech-startup,scaleup,enterprise,public-company,non-profit}`.

3. **`comms_calendar_builder.py`** — 7-точечное секвенирование (минимум Prosci для изменения поведения). Помечает пробелы: 2-точечные планы для разрушительных изменений, слабина - только для увольнений (анти-шаблон — требуется синхронный канал), несоответствия по величине.

## Жесткие правила { #hard-rules }

- ** Связь при увольнении ** никогда не отключается только для слабонервных. Требуется синхронный канал.
- **Разрушительные изменения** требуется более 5 точек соприкосновения с включенным каскадом управления.
- **Автоматически помечается преуменьшение величины** ("незначительная реструктуризация" для 30% RIF).

## Отличный от { #distinct-from }

- `marketing-skill/*` — внешняя облицовка
- `c-level-advisor/internal-narrative` — стратегическое построение повествования (голос генерального директора)
- `c-level-advisor/change-management` — стратегия смены руководства. Внутренняя связь - это нижележащий уровень разработки тактических решений.
