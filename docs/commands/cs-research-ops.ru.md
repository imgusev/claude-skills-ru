## Маршрутизация (детерминированная, порог с двумя сигналами) { #routing-deterministic-two-signal-threshold }

| Класс сигнала | Ключевые слова | Вспомогательный скилл |
|---|---|---|
| КЛИНИЧЕСКИЙ | клиническое испытание, дизайн исследования, протокол, конечная точка, размер выборки, мощность, фаза, биостатистика, осуществимость | `clinical-research` |
| RD_ФИНАНС | Бюджет НИОКР, бюджет программы, выгода, взлетно-посадочная полоса, F& A, косвенная ставка, соотношение капитализации и расходов, рентабельность инвестиций в портфель | `research-finance` |
| РЫНОК | TAM, SAM, SOM, определение размера рынка, опрос, выборка, предел погрешности, сегментация, конкурентная разведка | `market-research` |
| ПРОДУКТ | интервью с пользователем, JTBD, юзабилити, концептуальный тест, исследование открытий, хранилище исследований, понимание, насыщенность | `product-research` |

1. Сначала изучите рабочую область — разрешающее имя файла автоматически перенаправляется.
2. Одиночный сигнал или ничья → один уточняющий вопрос с рекомендуемым ответом.
3. Подлинная многополосность → сначала с наивысшей степенью достоверности запустите развилку, спросите, прежде чем соединять в цепочку. Никогда не цепляйтесь молча.

## Выходные данные (дайджест из ≤200 слов) { #output-200-word-digest }

- Что было проанализировано
- Топ-3 находки, каждая из которых привязана к цитате из канона
- Топ-3 следующих действия с именованным владельцем-человеком, где это применимо
- Путь к артефакту
- Одна из задач гриля для пользователя

## Жесткие правила { #hard-rules }

- Клинический результат — это оценка + имя владельца клиники - никогда не факт.
- Финансовые результаты основаны на предположениях; соотношение капитальных и эксплуатационных расходов направляется указанному финансовому владельцу.
- Размер рынка показывает метод (в обоих направлениях) + допущения — никогда ни одной цифры.
- Представление о продукте основывается на достоверности + количестве источников; одиночки - это анекдоты.

## Отличный от { #distinct-from }

- `research/` (академический) — находит литературу/гранты/патенты. Это планирует/финансирует/определяет масштабы/обобщает.
- `ra-qm-team` — нормативное представление. `finance/` — корпоративное закрытие. `marketing-skill` — аналитика кампаний.
