**Команда:** `/cs:patent <invention description>`

Тот `cs-patent` персона создает патентное досье, адаптированное к конкретному варианту использования. **Отказывается от универсальной "справки по патенту"** — должен принять участие в одном из 5 дополнительных вариантов использования во втором квартале.

## Принудительный прием пищи (6 вопросов, по одному за раз) { #forcing-intake-6-questions-one-at-a-time }

| Вопрос | Спрашивает | Примечания |
|---|---|---|
| Вопрос 1 | Изобретение (2-3 предложения, конкретное) | отказывается расплывчато; "Искусственный интеллект для здравоохранения" отодвинут на второй план |
| Q2 | Вспомогательный вариант использования: новизна / FTO / ландшафт / тщательность / судебный процесс | **Принуждение — отказывается от "них всех"** |
| Вопрос 3 | Юрисдикции (США/EP/CN/JP/KR/PCT/по всему миру) | Запрашивается только для FTO/landscape/diligence |
| Q4 | Известный уровень техники (номер патента или документ) | Привязка; принять "нет" |
| Q5 | Толерантность к риску: строгая / сбор сигналов | Просили о новизне + FTO |
| Q6 | Статус адвоката (вы говорили с кем-нибудь из них?) | Запрос на новизну + FTO; отказ от ответственности за триггеры |

Условие остановки: после Q6 (или ранее с пропусками). Никогда не открывайте снова.

## Что Вы получаете { #what-you-get }

```
patent_<invention-slug>_<sub-use-case>_<YYYY-MM-DD>.docx

8 sections:
1. Executive Summary + Verdict (NOVEL/CLEAR/FLAGGED/etc.) + legal disclaimer
2. Closest Prior Art (5-10 ranked, claim-text extracted, hyperlinked)
3. Patent Landscape (top filers, 10-yr trend, CPC distribution)
4. Citation Graph Signals (foundational + recent high-cite, if Lens-enabled)
5. Geographic Coverage (FTO/landscape/diligence only)
6. FTO Flags (FTO only — risk per claim per jurisdiction)
7. Strategy + Recommendations (sub-use-case-specific)
8. Audit Log (searches, counts, plan-tier, attorney reminder)
```

## Поведение для каждого отдельного варианта использования { #per-sub-use-case-behavior }

| Вспомогательный вариант использования | Акцент на поиске | Настройка DOCX |
|---|---|---|
| Новинка | Узкий + ориентированный на претензии; дата предварительной подачи не имеет значения | Разделы 5-6 сокращены; вердикт: РОМАН/ПОТЕНЦИАЛЬНО/НЕ РОМАН |
| ФТО | Только активные патенты; юрисдикция отфильтрована | Раздел 6 расширен; вердикт ЯСЕН/ПОМЕЧЕН/ВЫСОКИЙ РИСК для каждой юрисдикции |
| Конкурентный ландшафт | Ширина + количество заявок + тенденции цен за клик | Раздел 3 расширен; вердикт = топ-5 заявителей + 3 новых участника. |
| Тщательность при приобретении | Конкретный правопреемник + портфолио + цепочка назначений | Расширены разделы 3+5; флаги подтверждения владения |
| Предшествующий уровень судебного разбирательства | Целевой патент + смежный уровень техники до даты приоритета | Раздел 2 = ранжированные кандидаты на выбывание |

## Дисциплина { #discipline }

- **Обязательное обязательство по дополнительному варианту использования** во втором квартале
- **Последовательный поиск со скоростью 1 q/сек** по всем источникам
- ** Последующий просмотр класса CPC** после первоначального поиска по ключевым словам
- ** Семейное разрешение ** — о дубликатах одного и того же изобретения сообщается один раз
- **Порядок дат** — подача заявки/приоритет/публикация/выдача гранта выделены
- ** Юридический отказ от ответственности обязателен ** для новизны + FTO
- **Исходная дисциплина** — вызывается только инструмент этого сеанса
- **Отслеживание по трем счетам** — отправлено / получено / процитировано
- **Пометка "Вне сферы применения"** — товарный знак/авторское право/коммерческая тайна отклонены при приеме

## Отклоненные анти-паттерны { #anti-patterns-rejected }

- Запуск любого поиска до того, как пользователь перейдет к дополнительному варианту использования (отказывается от общей "справки по патенту")
- Группирование всех вопросов о приеме
- Принятие расплывчатых описаний изобретений
- Поиск только по ключевым словам без отслеживания класса CPC/IPC
- Обращение с членами семьи как с отдельными жертвами
- Путают дату подачи заявки с датой приоритета/публикации/предоставления
- Пропуск юридического заявления об отказе от ответственности, когда дополнительный вариант использования имеет юридические последствия
- Сообщение о вердикте без претензий-текстовые доказательства
- Изготовление Lens.org данные о цитировании при отсутствии ключа
- Предлагая обходные пути без подтверждения необходимости ревью со стороны адвоката
- Пропуск журнала аудита
