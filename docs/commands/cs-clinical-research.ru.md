Запустите `clinical-research` скилл на основе этого ввода:

**$АРГУМЕНТЫ**

## Воркфлоу с тремя инструментами { #three-tool-workflow }

1. **`endpoint_selector.py`** — Оценивайте конечные точки кандидатов по клинической значимости, измеримости, приемлемости для регулирующих органов, чувствительности к изменениям и нагрузке. Классифицировать ПЕРВИЧНЫЙ / КЛЮЧЕВОЙ-ВТОРИЧНЫЙ / ИССЛЕДОВАТЕЛЬСКИЙ. Помечает непроверенные суррогаты (не могут быть первичными). Отраслевая настройка с помощью `--profile`.

2. **`sample_size_estimator.py`** — Мощность закрытой формы / размер выборки для средних значений с двумя руками (d Коэна), пропорций (нормальное приближение) или выживаемости (события Шенфельда). Надувается для отсева. Эффект/разница/ЧСС должны быть прослежены до опубликованного источника или источника, основанного на привязке.

3. **`phase_gate_scorer.py`** — Оцените учебный план от 0 до 100 баллов в зависимости от осуществимости набора персонала, готовности к конечным точкам, статистической мощности, сложности эксплуатации и соответствия бюджету. Вердикт + названные владельцы (PI, медицинский наблюдатель, биостатист, владелец регулирующего органа).

## Выход { #output }

- Классификация конечных точек + суррогатные флаги
- Оценка размера выборки с блоком допущений
- Вердикт по фазовому гейту с именованной цепочкой владельцев
- Топ-3 следующих действия

## Жесткое правило { #hard-rule }

** Каждый результат является оценкой, а не протоколом.** Биостатист, медицинский наблюдатель и владелец регулирующего органа подписывают окончательный проект.

## Первый запуск + оптимизация { #first-run--optimization }

- **Первым поднялся на борт онбординга:** `python3 skills/clinical-research/scripts/onboard.py` (область, альфа, мощность, отсев, именованные владельцы) — сохраненная конфигурация предварительно настраивает каждый инструмент. `--show` перечисляет вопросы.
- ** Оптимизировать (регистрация): ** только если пользователь попросит оптимизировать / запустить цикл, переключитесь на автоматический поиск через `skills/clinical-research/scripts/ar_evaluator.py` (`feasibility_composite`, чем выше, тем лучше).
