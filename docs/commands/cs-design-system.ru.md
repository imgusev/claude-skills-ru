Запустите мастер проектирования системы:

```bash
python3 markdown-html/skills/design-system/scripts/onboard.py $ARGUMENTS
```

## Режимы { #modes }

| Флаг | Поведение |
|---|---|
| (без флага) | Интерактивный — отвечает на 10 вопросов по одному за раз. По умолчанию. |
| `--defaults` | Нулевое касание: записывает встроенные значения по умолчанию (`#0A1628` военно-морской флот + `#00D4AA` бирюзовый + Интер + технический + липкий TOC + `./markdown-html-out/`) без промптов. Полезно для CI или первого тестирования. |
| `--set key=value` | Неинтерактивное переопределение (повторяемое). Поддерживаемые точечные клавиши: `brand.primary=#FF6B35`, `typography.heading_font=Lora`, `design_style=editorial`. |
| `--show` | Выведите 10 вопросов + текущую действующую конфигурацию (проект > глобальный > значения по умолчанию). |
| `--reset` | Удалите сохраненную конфигурацию в выбранной области. |
| `--scope project` | Сохранить в `./.markdown-html/design-system.json` (переопределение для каждого репозитория) вместо глобального `~/.config/markdown-html/design-system.json`. |

## 10 вопросов { #the-10-questions }

1. Выходной каталог по умолчанию (путь; должен быть доступен для записи)
2. Первичный шестигранник марки
3. Шестнадцатеричный акцент бренда (необязательно; автоматически выводится, если пусто)
4. Шрифт заголовка Google (12 безопасных значений по умолчанию)
5. Основной шрифт Google
6. Стиль дизайна: редакционный / технический / минималистичный / игривый
7. Тема подсветки синтаксиса: светлая / темная / автоматическая
8. Поведение TOC: sticky-боковая панель / складной верх / встроенный / нет
9. Название компании / проекта (необязательно, отображается в нижнем колонтитуле)
10. URL-адрес логотипа (необязательно, base64-встроен во время рендеринга)

## Жесткие отказы { #hard-refusals }

- `default_output_dir` пусто или не доступно для записи → выход 3. Выберите путь, который вы контролируете.
- Ошибка сопоставления основного текста WCAG AA (< 4,5:1) → выход 4. Выберите более темный основной, пустой `brand.bg`/`brand.text` чтобы позволить деривации выбрать проходящую пару или переопределить `brand.text` явно.
- Контрастность ссылки WCAG проверяется итеративно; возвращается к переходящему цвету, если акцент на bg не может достичь 4,5:1.

## После онбординга { #after-onboarding }

Проверьте действующую конфигурацию:

```bash
python3 markdown-html/skills/design-system/scripts/config_loader.py --show
python3 markdown-html/skills/design-system/scripts/config_loader.py --status
```

Затем преобразуйте Markdown с помощью `/cs:markdown-html <path>.md`.

## Обход { #bypass }

`MARKDOWN_HTML_NO_CONFIG=1` пропускает сохраненную конфигурацию и возвращает только значения по умолчанию. Полезно для безголового CI, эфемерных тестовых контейнеров и циклов вычислителя. Никогда не устанавливайте его автоматически для интерактивного пользователя.
