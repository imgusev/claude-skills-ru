Запустите пайплайн для извлечения гейтов с закрытым доступом для `$ARGUMENTS` используя `skills/universal-scraping-architect/SKILL.md`.

## Предполетные гейты (останавливаются, если какие-либо из них выходят из строя) { #pre-flight-gates-stop-if-any-fails }

1. **Цель указана?** Если `$ARGUMENTS` пусто, запросите URL—адрес или путь к файлу плюс желаемый формат вывода - не угадывайте.
2. ** Этикет живого сайта:** для получения URL-адресов проверьте `robots.txt` и планируйте ограничения скорости; отказывайтесь от запрещенных целей.
3. ** Конфиденциальность:** если целью является местный/sensitive файл, не отправляйте его во внешний API — принудительный режим 2 (локальный Python).
4. ** Секреты:** Ключ Firecrawl только через `os.getenv('FIRECRAWL_API_KEY')`; если ключ появляется встроенным в любом месте, сначала исправьте это.

## Воркфлоу { #workflow }

1. **Маршрут** — укажите режим и почему (в соответствии с правилами маршрутизации скилла):
   Режим 1 Firecrawl (общедоступный / JS-тяжелый URL, массовый обход) · Режим 2 локальный Python (локальные файлы, личные данные, простой статический HTML) · Режим 3 гибридный (извлечение Firecrawl + очистка pandas).
2. **Бюджет** — оцените лимиты квот API / токенов перед многостраничными заданиями; добавьте контрольные точки + разбиение на страницы.
3. **Извлечь** — запустить из соответствующего шаблона runner (запустить из корневого каталога плагина; `--sample` предварительный просмотр сводной формы в автономном режиме):
   ```bash
   python3 skills/universal-scraping-architect/scripts/firecrawl_example.py --sample
   python3 skills/universal-scraping-architect/scripts/local_bs4_example.py --sample
   ```
4. **Проверка (обязательна, гейт с кодом выхода):**
   ```bash
   python3 skills/universal-scraping-architect/scripts/validate_extraction.py extracted_output.json --json
   ```
   - выход 0 (`status: ok`) → продолжить
   - выход 1 (`warning` = пустой вывод, `error` = искаженный JSON) → исправить и повторно извлечь; **никогда не предоставляйте непроверенные данные**

   Затем проверьте обязательные поля и дубликаты в соответствии со спецификацией задания.
5. **Доставить** — CSV (табличный) / JSON (вложенный) / Markdown (документы, разделенные на части) в соответствии с запрошенным пользователем форматом, с краткой информацией о выбранном режиме, количестве строк, пустых значениях и вердикте проверки.
