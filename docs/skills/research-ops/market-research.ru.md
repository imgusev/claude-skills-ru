Методология исследования восходящего рынка: определение размера рынка, опрос/sampling дизайн и сегментация. Дисциплина здесь такова ** метод + допущения **: TAM никогда не является единичным числом, опрос никогда не используется только в совокупности, а сегмент никогда не является демографическим срезом.

## Цель { #purpose }

Аналитикам, занимающимся исследованиями рынка, специалистам по маркетингу продуктов и стратегическим командам нужны строгие доказательства, прежде чем кто-либо оптимизирует кампанию или определяет стратегию. Этот скилл формирует три методологических решения:

Три детерминированных инструмента:

1. `market_sizer.py` — Вычисляет TAM/SAM/SOM с помощью ** как нисходящего, так и восходящего методов параллельно, сообщает о расхождении и помечает неудачную триангуляцию. Никогда не возвращает ни одного числа.
2. `sample_size_planner.py` — Размер выборки опроса на основе достоверности, допустимой погрешности и ожидаемой пропорции с поправкой на конечную совокупность и минимальными значениями ** для каждого сегмента** (опрос, проведенный в целом, не учитывается для каждого отчетного сегмента).
3. `segmentation_scorer.py` — Оценивает сегменты-кандидаты по пяти критериям Котлера и применяет гейт "существенность + доступность"; фрагмент, который слишком мал или недоступен, отбрасывается.

## Когда использовать { #when-to-use }

Используйте этот скилл, когда:

- Совет директоров или исполнительный директор спрашивает: "Насколько велик этот рынок?", и вам нужен обоснованный, триангулированный ответ.
- Вы проводите опрос, и вам нужен размер выборки, соответствующий каждому сегменту, а не только в целом.
- У вас есть список сегментов-кандидатов, и вам нужно знать, какие из них являются реальными рынками, а какие - демографическими срезами.
- Вы занимаетесь синтезом конкурентной разведки, и вам нужна методологическая основа.

**Не используйте этот скилл для**: измерения текущей кампании (атрибуция, ROAS, CPA → `marketing-skill/campaign-analytics`), создавать медиапланы по запросу / платные медиа-планы (`marketing-skill/marketing-demand-acquisition`), установите стратегию позиционирования / GTM (`marketing-skill/marketing-strategy-pmm`), или устанавливать цены (`commercial/pricing-strategist`).

## Воркфлоу { #workflow }

1. **Напишите краткое описание** — Заполните `assets/market_research_brief_template.md` (цель, решение, на основе которого оно принимается, подход к определению размера, план выборки, реестр допущений).
2. **Определите размер рынка** — Запустите `market_sizer.py --input market.json --method both --profile {b2b-saas|consumer|enterprise|marketplace|hardware|services}`. Согласуйте нисходящий/bottoms-up дельта, прежде чем что-либо цитировать.
3. **Спланируйте опрос** — Запустите `sample_size_planner.py --input survey.json`. Финансируйте этажи для каждого сегмента, а не только общее количество этажей.
4. **Подсчитайте сегменты** — Запустите `segmentation_scorer.py --input segments.json --profile <same>`. Отбрасывать сегменты, не обладающие существенностью/accessibility гейт.
5. **Соберите пакет доказательств** — Объедините в краткое изложение. Каждое число содержит свой метод + предположения + уверенность.

## Сценарии { #scripts }

```bash

python3 scripts/onboard.py --show     # see the questions + current effective config
```

Ответы сохраняются в `~/.config/research-ops/market-research.json` (глобальный) или `./.research-ops/market-research.json` (`--scope project`) и считываются автоматически `config_loader.py`. Они устанавливают рыночный ** профиль** по умолчанию, опрос по умолчанию ** достоверность** и **предел погрешности**, а также метод определения размера по умолчанию**. Флаги CLI всегда переопределяют сохраненную конфигурацию; `RESEARCH_OPS_NO_CONFIG=1` игнорирует это.

## Оптимизация с помощью автоматического поиска (опция) { #optimize-with-autoresearch-opt-in }

Этот скилл предоставляет ** изолированный, согласованный** мост для `engineering/autoresearch-agent`. Только когда вы просите "оптимизировать" / "согласовать размеры" / "запустить цикл", эксперимент с автоматическим поиском итеративно согласовывает вашу рыночную модель таким образом, чтобы триангулировать сверху вниз и снизу вверх. `scripts/ar_evaluator.py` является основным средством оценки истинности; он печатает `tam_divergence: <fraction>` (**чем ниже**, тем лучше).

```bash
/ar:setup --domain custom --name tam-triangulation \
  --target market.json \
  --eval "python3 ar_evaluator.py --target market.json" \
  --metric tam_divergence --direction lower
/ar:loop custom/tam-triangulation
```

Изолированный: нет жесткой зависимости — автоматический поиск выполняется только по требованию, а цикл редактируется `market.json`, но никогда не оценщик.

## Допущения { #assumptions }

- Оценщик сообщает об обоих методах, но не может подтвердить ваши данные — нисходящий "1% от рынка в 40 миллиардов долларов" хорош только в том случае, если цитируемый источник и пригодная для использования доля.
- При определении размера выборки используется консервативное значение p=0,5 (максимальная дисперсия), если только вы не указали ожидаемую пропорцию.
- Оценки сегментов - это вводимые вами данные; инструмент применяет гейты и взвешивание, он не собирает лежащие в основе доказательства.
- Конкурентная разведка должна следовать этическому кодексу SCIP — никакого искажения информации, никакой защищенной информации.

## Анти-паттерны { #anti-patterns }

- ** Один номер TAM без указания метода.** Всегда проводите триангуляцию сверху вниз и снизу вверх.
- ** Ложная точность.** Размер соответствует допустимому значению решения; "3,7142 миллиарда долларов" подразумевает уверенность, которой у вас нет.
- ** Учитывается только общее количество.** Для каждого отчетного сегмента требуется свой собственный уровень выборки.
- ** Наводящие или двуствольные вопросы опроса.** Предварительно протестируйте формулировку на соответствие литературе о предвзятости.
- **Называть демографический срез сегментом.** Она должна быть содержательной И доступной.

## Краткие примеры { #quick-examples }

```bash
python3 scripts/market_sizer.py --sample
python3 scripts/sample_size_planner.py --population 62000 --confidence 0.95 --moe 0.05
python3 scripts/segmentation_scorer.py --sample --output json
```

Выборочный рынок триангулирует показатель SAM в размере ~ 1,47 млрд долларов сверху вниз по отношению к показателю снизу вверх и отмечает расхождение; выборка сегментации отбрасывает срез "предприниматели-одиночки, которым может понадобиться аналитика" из-за несоответствия гейтам существенности и доступности.

## Библиотека принудительных вопросов (дисциплина Matt Pocock grill) { #forcing-question-library-matt-pocock-grill-discipline }

Проходили по одному мимо `/cs:grill-research-ops` или оркестратор. Рекомендуемый ответ + цитата из канона на каждый вопрос. Никогда не упаковывался.

1. ** "Является ли ваш TAM нисходящим или восходящим снизу вверх - и вычислили ли вы его обоими способами для триангуляции?"**
   Рекомендуется: и то, и другое; выверяйте дельту, прежде чем указывать число.
   Канон: Оценка рынка Bessemer / a16z; оценка Ферми.

2. ** "Какое решение на самом деле будет принято при таком размере рынка — и с какой точностью это имеет значение?"**
   Рекомендуется: размер в соответствии с допуском решения, а не с числом ложной точности.
   Канон: соглашения о рыночных моделях (Gartner/Forrester); анализ, основанный на принятии решений.

3. ** "Какова ваша целевая погрешность и степень достоверности — и соответствует ли ваша выборка показателям по сегментам, а не только в целом?"**
   Рекомендуется: включите каждый отчетный сегмент, а не только общее количество.
   Канон: Кокран * Методы отбора проб*; Стандарты AAPOR.

4. ** "Свободны ли ваши вопросы опроса от вводных и двусмысленных формулировок?"**
   Рекомендуется: предварительно протестируйте формулировку; укажите источник предвзятости.
   Канон: Schuman & Presser; Dillman * Индивидуальный метод проектирования*.

5. ** "Являются ли ваши сегменты поддающимися измерению / существенными / доступными / действенными — или это просто демографические срезы?"**
   Рекомендуется: отбросьте сегменты, которые не соответствуют действительности или доступности.
   Канон: критерии сегментации Котлера.

Сначала пройдите вглубь. Зафиксируйте 1-2 перед открытием 3-5. После того, как на все будут даны ответы, вызовите `market_sizer.py` → `sample_size_planner.py` → `segmentation_scorer.py`.
