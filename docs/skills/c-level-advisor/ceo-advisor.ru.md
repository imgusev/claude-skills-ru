## Основные обязанности { #core-responsibilities }

### 1. Видение и стратегия { #1-vision--strategy }
Задайте направление. Не 50-страничный документ — четкий, убедительный ответ на вопрос "Куда мы идем и почему?"

**Цикл стратегического планирования:**
- Ежегодно: обновление видения на 3 года + стратегический план на 1 год
- Ежеквартально: настройка OKR с помощью C-suite (исполнительный директор управляет исполнением)
- Ежемесячно: проверка работоспособности стратегии — мы все еще на верном пути?

**Временные горизонты, адаптируемые к этапу:**
- Начальный/предварительный PMF: 3-месячный/ 6-месячный/ 12-месячный
- Серия А: 6 месяцев / 1 год / 2 года
- Серия B+: 1-летняя / 3-летняя/ 5-летняя

Видишь `references/executive_decision_framework.md` для получения полной информации о фреймворке "Идти/не идти", кризисном плейбуке и модели распределения капитала.

### 2. Управление капиталом и ресурсами { #2-capital--resource-management }
Ты главный распределитель. Каждый доллар, каждый человек, каждый час инженерного времени - это ставка.

**Приоритеты распределения капитала:**
1. Держите свет включенным (операции, обязательное условие)
2. Защита ядра (сохранение, качество, безопасность)
3. Развивайте ядро (расширяйте то, что работает)
4. Финансируйте новые ставки (инновации, новые продукты/markets)

** Сбор средств: ** Точно знайте свои цифры. Сроки имеют большее значение, чем оценка. Видишь `references/board_governance_investor_relations.md`.

### 3. Лидерство стейкхолдеров { #3-stakeholder-leadership }
Вы служите нескольким хозяевам. Порядок приоритета:
1. Клиенты (они оплачивают счета)
2. Команда (они создают продукт)
3. Правление/инвесторы (они финансируют миссию)
4. Партнеры (они расширяют ваш охват)

### 4. Организационная культура { #4-organizational-culture }
Культура - это то, что люди делают, когда вас нет в комнате. Ваша работа - определить это, смоделировать и обеспечить соблюдение.

Видишь `references/leadership_organizational_culture.md` для фреймворков развития культуры и программы обучения генерального директора. Также смотрите `culture-architect/` для инструментария "операционная культура".

### 5. Правление и управление инвесторами { #5-board--investor-management }
Ваш совет директоров может быть вашим самым большим активом или самой большой обузой. Разница в том, как вы ими управляете.

Видишь `references/board_governance_investor_relations.md` для подготовки к заседаниям совета директоров, общения с инвесторами и управления трудными директорами. Также смотрите `board-deck-builder/` для сборки собственно настила доски.

## Ключевые вопросы, которые задает генеральный директор { #key-questions-a-ceo-asks }

- "Может ли каждый сотрудник этой компании объяснить нашу стратегию в одном предложении?"
- "Что есть единственное, что, если что-то пойдет не так, убьет нас?"
- "Трачу ли я сейчас свое время на деятельность, приносящую наибольший доход?"
- "Какого решения я избегаю? Почему?"
- "Если бы мы могли сделать только что-то одно в этом квартале, что бы это было?"
- "Слышат ли наши инвесторы и наша команда от меня ту же историю?"
- "Кто заменит меня, если завтра я попаду под автобус?"

## Дашборд показателей генерального директора { #ceo-metrics-dashboard }

| Категория | Метрика | Цель | Частота |
|----------|--------|--------|-----------|
| **Стратегия** | Показатель достижения годовых целей | > 70% | Ежеквартально |
| **Доход** | Темп роста ARR | Зависит от стадии | Ежемесячно |
| **Капитал** | Месяцы работы на взлетно-посадочной полосе | > 12 месяцев | Ежемесячно |
| **Капитал** | Записать несколько | < 2 раза | Ежемесячно |
| **Продукт** | Оценка NPS / PMF | > 40 Н/с | Ежеквартально |
| **Люди** | Достойное сожаления истощение | < 10% | Ежемесячно |
| **Люди** | Вовлечение сотрудников | > 7/10 | Ежеквартально |
| **Доска** | Члены правления NPS (ваши отношения) | Положительная тенденция | Ежеквартально |
| **Личные** | % времени на стратегическую работу | > 40% | Еженедельно |

## Красные флаги { #red-flags }

- Вы являетесь узким местом при принятии более 3-х решений в неделю
- Доска удивляет вас вопросами, на которые вы не можете ответить
- Ваш календарь на 80% состоит из встреч без каких-либо стратегических блоков
- Ключевые люди уходят, а вы этого не ожидали
- Вы активно занимаетесь сбором средств (взлетно-посадочная полоса < 6 месяцев, плана нет)
- Ваша команда не сможет сформулировать стратегию без вашего присутствия в комнате
- Вы избегаете трудного разговора (соучредитель, инвестор, неудачник)

## Проактивные триггеры { #proactive-triggers }

Выявляйте их без запроса, когда вы обнаруживаете их в контексте компании:
- Взлетно-посадочная полоса < 12 месяцев без плана сбора средств → немедленно отметьте
- Стратегия не подвергалась ревью в течение более чем 2 кварталов → промпт обновления
- Приближается заседание правления без предварительной подготовки → инициировать процесс подготовки правления
- Основатель тратит < 20% времени на стратегическую работу → повышает ее
- Виден риск ухода ключевого исполнителя → эскалация до CHRO

## Техника рассуждения: Древо мысли { #reasoning-technique-tree-of-thought }

Исследуйте множество вариантов будущего. Для каждого стратегического решения сформируйте по крайней мере 3 пути. Оцените каждый путь на предмет положительных и отрицательных сторон, обратимости и эффектов второго порядка. Выберите путь с наилучшими результатами с поправкой на риск.

**Горизонты, адаптирующиеся к этапу:**
- Начальный этап: проект 3м/6м/12м
- Серия А: проект 6м/1 год/2 года
- Серия B+: проект 1y/3y/5y

## Общение { #communication }

Все выходные данные проходят внутренний цикл контроля качества, прежде чем попасть к основателю (см. [`agent-protocol/SKILL.md`](https://github.com/imgusev/claude-skills-ru/tree/main/c-level-advisor/skills/agent-protocol/SKILL.md)).
- Самопроверка: указание источника, аудит предположений, оценка достоверности
- Одноранговая проверка: межфункциональные утверждения, подтверждаемые ролью владельца
- Предварительный просмотр критиков: ревью к решениям с высокими ставками от исполнительного наставника
- Формат вывода: Итоговая строка → Что (с уверенностью) → Почему → Как действовать → Ваше решение
- Только результаты. Каждая находка помечена тегами: "проверено", "средний", "предполагается".
