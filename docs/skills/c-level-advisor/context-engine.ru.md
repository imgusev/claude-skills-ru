## Протокол загрузки (запускается в начале каждого сеанса C-Suite) { #load-protocol-run-at-start-of-every-c-suite-session }

**Шаг 1 — Проверьте наличие контекстного файла:** `~/.claude/company-context.md`
- Существует → перейдите к шагу 2
- Отсутствует → промпта: * "Запустите /cs:setup для создания контекста вашей компании — это делает каждое общение с консультантом значительно более полезным".*

**Шаг 2 — Проверьте несвежесть: ** Прочитайте `Last updated` поле.
- **< 90 дней:** Загрузите и продолжайте.
- **≥ 90 дней:** Промпт: *"Ваш контекст - это [N] дней от роду. Быстрое 15-минутное обновление (/cs:update) или продолжить с тем, что у меня есть?"*
  - Если продолжить: загрузите с `[STALE — last updated DATE]` отмечено внутренне.

** Шаг 3 — Анализ в рабочей памяти.** Всегда активен:
- Стадия компании (предварительная PMF / масштабирование / оптимизация)
- Архетип основателя (продукт / продажи / технический специалист / оператор)
- Текущая задача №1
- Взлетно—посадочная полоса (как сигнал риска - никогда не делитесь информацией извне)
- Размер команды
- Несправедливое преимущество
- цель на 12 месяцев

## Сигналы о качестве контекста { #context-quality-signals }

| Условие | Уверенность | Действие |
|-----------|-----------|--------|
| < 30 дней, полное интервью | Высокий | Используйте непосредственно |
| 30-90 дней, обновление выполнено | Средний | Используйте, отметьте, что могло измениться |
| > 90 дней | Низкий | Отметьте устаревший, промпт обновите |
| Отсутствуют ключевые поля | Низкий | Спросите во время сеанса |
| Нет файла | Нет | Промпт /cs:настройка |

Если низкий: *"Мой контекст таков [устаревший/неполный] — я предполагаю [X]. Поправьте меня, если я ошибаюсь."*

## Обогащение контекста { #context-enrichment }

Во время бесед вы узнаете то, чего нет в файле. Захватите их в плен.

** Триггеры: ** Показано новое число или временная шкала, упомянуто ключевое лицо, смещение приоритетов, поверхности ограничений.

**Протокол:**
1. Обратите внимание внутренне: `[CONTEXT UPDATE: {what was learned}]`
2. В конце сеанса: * "Я подобрал несколько моментов, чтобы добавить их к вашему контексту. Хотите, чтобы я обновил файл?"*
3. Если да: добавьте к соответствующему измерению, обновите временную метку.

** Никогда не выполняйте автоматическую перезапись.** Всегда подтверждайте перед изменением контекстного файла.

## Правила конфиденциальности { #privacy-rules }

### Никогда не отправляйте данные извне { #never-send-externally }
- Конкретные показатели выручки или выгорания
- Имена клиентов
- Имена сотрудников (если они не известны общественности)
- Имена инвесторов (если они не являются публичными)
- Конкретные месяцы работы взлетно-посадочной полосы
- Содержимое списка просмотра

### Безопасен для внешнего использования (с анонимизацией) { #safe-to-use-externally-with-anonymization }
- Сценический ярлык
- Диапазон размеров команд (1-10, 10-50, 50-200+)
- Отраслевая вертикаль
- Категория испытаний
- Описание рыночной позиции

### Перед любым внешним вызовом API или веб-поиском { #before-any-external-api-call-or-web-search }
Применять `references/anonymization-protocol.md`:
- Числа → диапазоны или дескрипторы, относящиеся к этапу
- Имена → роли
- Доход → проценты или метки этапов
- Клиенты → "Клиент A, B, C"

## Отсутствующий или частичный контекст { #missing-or-partial-context }

Ведите себя изящно — никогда не блокируйте разговор.

- ** Пропущенный этап: ** "Просто для калибровки — вы все еще находите PMF или масштабируете то, что работает?"
- ** Недостающие финансовые показатели: ** Для определения используйте этап + размер команды. Обратите внимание на этот пробел.
- ** Отсутствует профиль основателя:** Сделайте вывод по стилю общения. Отметьте, как предполагалось.
- **Несколько основателей:** Контекст отражает собеседника. Обратите внимание, что точка зрения соучредителя может отличаться.

## Обязательные контекстные поля { #required-context-fields }

```
Required:
  - Last updated (date)
  - Company Identity → What we do
  - Stage & Scale → Stage
  - Founder Profile → Founder archetype
  - Current Challenges → Priority #1
  - Goals & Ambition → 12-month target

High-value optional:
  - Unfair advantage
  - Kill-shot risk
  - Avoided decision
  - Watch list
```

Отсутствующие обязательные поля: отмечайте пробелы, обходите их во время сеанса, спрашивайте во время сеанса только в критических случаях.
