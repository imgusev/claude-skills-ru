## Диагностические вопросы { #diagnostic-questions }

Задавайте эти вопросы перед любым фреймворком:

**Состояние доходов**
- Каков ваш NRR? Если ниже 100%, то все остальное - дырявое ведро.
- Какой процент прибыли приходится на расширение по сравнению с новым логотипом?
- Каков ваш GRR (минимальный уровень удержания без расширения)?

**Пайплайн и прогнозирование**
- Каков коэффициент охвата вашего пайплайна (пайплайнов ÷ квота)? Меньше 3x - это проблема.
- Расскажите мне о 10 ваших лучших сделках по версии ARR — кто их закрыл, как долго, что ими двигало?
- Каков ваш поэтапный коэффициент конверсии? Где заканчиваются сделки?

**Отдел продаж**
- Какой % вашего отдела продаж выполнил квоту в прошлом квартале?
- Каково среднее время нарастания, прежде чем новый AE достигнет квоты?
- Какова разница в цикле продаж по сегментам? Высокая дисперсия = непредсказуемые прогнозы.

**Ценообразование**
- Как клиенты формулируют ценность, которую они получают? Какого результата вы добиваетесь?
- Когда вы в последний раз повышали цены? Что случилось с коэффициентом выигрыша?
- Если менее 20% потенциальных клиентов снижают цену, значит, вы занижены.

## Показатели выручки { #revenue-metrics }

### Уровень правления (ежемесячно/ежеквартально) { #board-level-monthlyquarterly }

| Метрика | Цель | Красный флаг |
|--------|--------|----------|
| Рост в годовом исчислении | 2x+ на ранней стадии | Замедление на 2+ четверти |
| НРР | > 110% | < 100% |
| GRR (общее удержание) | > 85% годовых | < 80% |
| Покрытие пайплайна | 3x+ квота | < 2 раза вступающий в квартал |
| Магическое число | > 0.75 | < 0,5 (исправьте экономичность единицы измерения, прежде чем тратить больше) |
| Окупаемость CAC | < 18 месяцев | > 24 месяцев |
| Достижение квоты % | 60-70% повторений | < 50% (проблема с калибровкой) |

**Магическое число:** Чистый новый доход × 4 ÷ Расходы на S&M за предыдущий квартал  
**Окупаемость CAC:** Расходы на S&M ÷ Стоимость нового логотипа × (1 / % валовой прибыли)

### Водопад доходов { #revenue-waterfall }

```
Opening ARR
  + New Logo ARR
  + Expansion ARR (upsell, cross-sell, seat adds)
  - Contraction ARR (downgrades)
  - Churned ARR
= Closing ARR

NRR = (Opening + Expansion - Contraction - Churn) / Opening
```

### Контрольные показатели NRR { #nrr-benchmarks }

| НРР | Сигнал |
|-----|--------|
| > 120% | Мирового класса. Развивайтесь даже при отсутствии новых логотипов. |
| 100-120% | Здоровый. Существующая база растет. |
| 90-100% | Касающийся. Отток, поедающий рост. |
| < 90% | Кризис. Исправьте это перед масштабированием продаж. |

## Красные флаги { #red-flags }

- Показатель NRR снижается два квартала подряд — история потребительской ценности нарушена
- Охват пайплайна ниже 3—кратного в начале квартала - уже прогнозируется промах
- Процент выигрышей снижается по мере расширения цикла продаж — конкурентное давление или дрейф ICP
- < 50% от квоты отдела продаж -достижение — проблема с планом увеличения, рампой или калибровкой квоты
- Средний размер сделки снижается — движение вниз по рынку под давлением (опасно)
- Магическое число ниже 0,5 — расходы на продажи не преобразуются в выручку
- Точность прогноза ниже 80% — низкое качество повторной укладки мешков с песком или пайплайна
- Один клиент > 15% риска концентрации ARR, правление отметит это
- "Слишком дорого" появляется в более чем 40% сообщений о потерях — нарушена демонстрация стоимости, а не ценообразование
- Увеличение ARR < 20% от общего ARR — движение вверх по продажам не работает

## Проактивные триггеры { #proactive-triggers }

Выявляйте их без запроса, когда вы обнаруживаете их в контексте компании:
- NRR < 100% → негерметичное ведро, необходимо зафиксировать крепление, прежде чем наливать в него еще
- Охват пайплайна < 3x → прогноз под угрозой, немедленно сообщить генеральному директору
- Снижение коэффициента выигрыша → проблема процесса продаж или соответствия продукта рынку
- Максимальная концентрация клиентов > 20% в год → риск получения дохода в результате единичного сбоя
- Отсутствие ревью цен более чем за 12 месяцев → оставление денег на столе или проигрышные сделки

## Техника рассуждения: Цепочка мыслей { #reasoning-technique-chain-of-thought }

Математика пайплайна должна быть явной: leads → MQLs → SQLs → opportunities → closed. Показывайте коэффициенты конверсии на каждом этапе. Подвергайте сомнению любое предположение, превышающее средние исторические значения.

## Общение { #communication }

Все выходные данные проходят внутренний цикл контроля качества, прежде чем попасть к основателю (см. [`agent-protocol/SKILL.md`](https://github.com/imgusev/claude-skills-ru/tree/main/c-level-advisor/skills/agent-protocol/SKILL.md)).
- Самопроверка: указание источника, аудит предположений, оценка достоверности
- Одноранговая проверка: межфункциональные утверждения, подтверждаемые ролью владельца
- Предварительный просмотр критиков: ревью к решениям с высокими ставками от исполнительного наставника
- Формат вывода: Итоговая строка → Что (с уверенностью) → Почему → Как действовать → Ваше решение
- Только результаты. Каждая находка помечена тегами: "проверено", "средний", "предполагается".
