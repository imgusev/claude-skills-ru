Создавайте настольные колоды, которые рассказывают историю, а не просто показывают данные. У каждого раздела есть владелец, повествование и "ну и что".

## Ключевые слова { #keywords }
доска объявлений, новости для инвесторов, заседание правления, пакет документов для правления, отношения с инвесторами, ежеквартальный ревью, презентация правления, доска объявлений по сбору средств, колода инвесторов, описание правления, QBR, ежеквартальный ревью бизнеса

## Быстрый старт { #quick-start }

Попросите настольную колоду на естественном языке, назвав ритм и сцену:

> "Постройте ежеквартальную доску объявлений — мы из серии А".
> "Подготовьте проект доски объявлений по сбору средств для компании на начальной стадии".

Предоставьте доступные показатели. Конструктор заполняет пробелы явными заполнителями — никогда не выдумывает числа.

## Конструкция палубы (стандартный заказ) { #deck-structure-standard-order }

Далее следует каждый раздел: ** Заголовок → Данные → Повествование → Задать / Следующий**

### 1. Краткое содержание (генеральный директор) { #1-executive-summary-ceo }
** 3 предложения. Не больше.**
- Предложение 1: Состояние бизнеса (где мы находимся)
- Предложение 2: Самое большое событие, произошедшее за этот период
- Предложение 3: Куда мы направляемся в следующем квартале

* Плохо:* "У нас был хороший квартал с большим прогрессом во всех областях".
* Хорошо: * "Мы завершили третий квартал на уровне $2,4 млн в годовом исчислении (+22% кв/кв), подписали наш крупнейший корпоративный контракт и вступаем в четвертый квартал с 14-месячной взлетно-посадочной полосой. Стратегический сдвиг в сторону среднего рынка работает - ACV вырос на 40%, а цикл продаж сократился на 3 недели. Приоритет 4-го квартала: закрыть серию A стоимостью 3 млн долларов и достичь 2,8 млн долларов в год."

### 2. Дашборд ключевых показателей (COO) { #2-key-metrics-dashboard-coo }
**максимум 6-8 показателей. Используйте таблицу.**

| Метрика | Этот период | Последний период | Цель | Статус |
|--------|-------------|-------------|--------|--------|
| ОБР | $2,4млн | $1,97млн | $2,3млн | ✅ |
| Рост мамы | 8.1% | 7.2% | 7.5% | ✅ |
| Записать несколько | 1.8x | 2.1x | <2 раза | ✅ |
| НРР | 112% | 108% | >110% | ✅ |
| Окупаемость CAC | 11 месяцев | 14 месяцев | <12 месяцев | ✅ |
| Численность персонала | 24 | 21 | 25 | 🟡 |

Выберите показатели, которые на самом деле отслеживает правление. Поменяйте местами все, что, по их словам, их не волнует.

### 3. Обновленная финансовая информация (финансовый директор) { #3-financial-update-cfo }
- Сводная информация о прибылях и убытках: Выручка, COGS, валовая прибыль, операционные расходы, чистый расход
- Денежная позиция и взлетно-посадочная полоса (месяцы)
- Записать множественный тренд (обзор за 3 квартала)
- Отклонение от плана (в чем было отличие и почему)
- Обновление прогноза на следующий квартал

**По одному предложению о каждом отклонении.** Советы директоров ненавидят "доход был ниже целевого показателя" без объяснения причин. Скажи почему.

### 4. Выручка и Пайплайн (CRO) { #4-revenue--pipeline-cro }
- Водопад ARR: начало → новое → расширение → отток → окончание
- Показатели оттока NRR и логотипов
- Пайплайн по этапам (в долларах, а не просто в количестве)
- Прогноз: следующий квартал с уровнем уверенности
- Топ-3 сделок: название/сумма/дата закрытия/риск

** Прогноз должен иметь уровень достоверности.** "Мы ожидаем 2,8 млн долларов" - это слабо. "Высокая уверенность в размере 2,6 млн долларов, рост до 2,9 млн долларов в случае закрытия двух сделок на поздней стадии" - это полезно.

### 5. Обновление продукта (CPO) { #5-product-update-cpo }
- Отправлено в этом квартале: 3-5 патронов, влияние на пользователя для каждого
- Отгрузка в следующем квартале: 3-5 патронов с установленными сроками
- Сигнал PMF: тренд NPS, соотношение DAU/MAU, принятие функции
- Один из ключевых уроков, извлеченных из исследований клиентов

** Нет списков функций. ** Только те функции, которые оказывают влияние на пользователя.

### 6. Рост и маркетинг (CMO) { #6-growth--marketing-cmo }
- CAC по каналам (таблица)
- Вклад пайплайна по каналам ($)
- Показатели узнаваемости бренда, относящиеся к сцене (трафик, доля голосов)
- Что работает, что сокращается, что тестируется

### 7. Инженерно-технический отдел (технический директор) { #7-engineering--technical-cto }
- Динамика скорости доставки (последние 4 квартала)
- Коэффициент технического долга и план
- Инфраструктура: время безотказной работы, инциденты, динамика затрат
- Положение безопасности (одна строка, отметьте все, что находится на рассмотрении)

** Делайте это коротко, если только нет существенных проблем. ** Советам не нужны подробности о спринте.

### 8. Команда и люди (CHRO) { #8-team--people-chro }
- Численность персонала: фактическая по сравнению с планом
- Найм: рассылка предложений, пайплайн, тенденция к сокращению времени заполнения
- Истощение: достойное сожаления против не вызывающего сожаления
- Вовлеченность: последняя оценка опроса, тенденция
- Ключевые сотрудники в этом квартале, ключевые открытые должности

### 9. Риски и безопасность (CISO) { #9-risk--security-ciso }
- Положение в области безопасности: состояние важнейших средств контроля
- Соответствие требованиям: сертификация в процессе, крайние сроки
- Инциденты в этом квартале (если таковые имели место): воздействие, разрешение, предотвращение
- Топ-3 рисков и статус их снижения

### 10. Стратегический прогноз (генеральный директор) { #10-strategic-outlook-ceo }
- Приоритеты на следующий квартал: 3-5 пунктов, ранжированных
- Ключевые решения, необходимые правлению
- Спрашивает: бюджет, представления, советы, голоса

** Слайд "спрашивает" - самый важный.** Будьте конкретны. "Мы хотели бы тепло представить 3 финансовых директора компаний серии B "beats ", любая помощь была бы признательна".

### 11. Приложение { #11-appendix }
- Подробная финансовая модель
- Полный пайплайн данных
- Диаграммы удержания когорт
- Тематические исследования клиентов
- Подробная разбивка численности персонала

## Повествовательный фреймворк { #narrative-framework }

Доски показывают более 10 колод за квартал. Вашему нужна сквозная линия.

**Структура из 4-х актов:**
1. ** Там, где мы обещали быть** (цели на прошлый квартал)
2. **Где мы на самом деле находимся** (честная оценка)
3. **Почему существует разрыв** (одна причина на каждое отклонение, а не оправдания)
4. **Что мы делаем по этому поводу** (конкретные, датированные действия)

Это работает как для хороших, так и для плохих новостей. Это вызывает доверие, потому что признает реальность.

** Вступительный кадр: ** Начните с самого важного — совет директоров должен знать ключевое сообщение по слайду 3, а не по слайду 30.

## Приносящий плохие новости { #delivering-bad-news }

Никогда не хорони это. Правления в конце концов узнают об этом. Когда узнаешь об этом поздно, становится только хуже.

**Фреймворк:**
1. ** Сформулируйте это прямо ** — "Мы не достигли целевого показателя за 3 квартал на 300 тысяч долларов (разрыв 12%)"
2. ** Назовите причину** — "Основным фактором стал более длительный, чем ожидалось, цикл продаж в корпоративном сегменте"
3. ** Покажите, что вы это понимаете ** — "Мы проанализировали 8 проигранных/приостановленных сделок; паттерн X"
4. ** Представляем исправление** — "Мы внесли 3 изменения: [конкретные, датированные изменения]"
5. ** Обновите прогноз ** — "Пересмотренный целевой показатель на 4 квартал составляет $2,6 млн; вот восходящий прогноз".

**Чего не следует делать:**
- Не начинайте с хороших новостей, чтобы смягчить плохие — доски объявлений замечают это и не доверяют оформлению
- Не объясняйте, не владея собой — "рыночные условия" - это не причина, это контекст
- Не представляйте исправление без данных, лежащих в его основе
- Не показывайте пересмотренный прогноз, не показав своих предположений

## Распространенные ошибки в настольной колоде { #common-board-deck-mistakes }

| Ошибка | Исправить |
|---------|-----|
| Слишком много слайдов (>25) | Вырезайте безжалостно — если вы не можете объяснить это в аудитории, слайд неправильный |
| Показатели без целевых показателей | Для каждой метрики нужны цель и статус |
| Никакого повествования | Данные без истории вынуждают советы директоров делать свои собственные выводы |
| Скрывая плохие новости | Руководи этим, владей этим, исправляй это |
| Неопределенный вопрос | Конкретные, выполнимые, назначаемые только для конкретного человека запросы |
| Никаких объяснений отклонений | Каждый отрыв от цели требует объяснения в одном предложении |
| Устаревший аппендикс | Приложение полезно только в том случае, если оно актуально |
| Дизайн для читателя, а не для помещения | Представлены колоды — они должны сработать, произнесенные вслух |

## Ноты ритма { #cadence-notes }

** Ежеквартально (стандартно):** Полная колода, все разделы, 20-30 слайдов. Отправлено за 48 часов.
** Ежемесячно (для ранней стадии):** Сокращенный дашборд показателей, финансовые показатели, пайплайн, основные риски. 8-12 слайдов.
** Сбор средств:** Начинается с market/vision, заканчивается ask. Видишь `references/deck-frameworks.md` для формата Sequoia.
