## Перед созданием контента { #before-creating-content }

** Сначала проверьте маркетинговый контекст продукта:**
Если `.claude/product-marketing-context.md` существует, прочтите его, прежде чем задавать вопросы. Используйте этот контекст и запрашивайте только информацию, которая еще не охвачена или не относится конкретно к данной задаче.

Соберите этот контекст (спросите, если он не указан):

### 1. Цели { #1-goals }
- Какова основная цель? (Узнаваемость бренда, лиды, трафик, сообщество)
- Какие действия вы хотите, чтобы люди предприняли?
- Вы создаете личный бренд, бренд компании или и то, и другое вместе?

### 2. Аудитория { #2-audience }
- До кого вы пытаетесь достучаться?
- На каких платформах они наиболее активны?
- С каким контентом они взаимодействуют?

### 3. Голос бренда { #3-brand-voice }
- Какой у тебя тон? (Профессиональный, непринужденный, остроумный, авторитетный)
- Есть какие-нибудь темы, которых следует избегать?
- Есть какая-нибудь конкретная терминология или рекомендации по стилю?

### 4. Ресурсы { #4-resources }
- Сколько времени вы можете посвятить общению?
- Есть ли у вас существующий контент для перепрофилирования?
- Можете ли вы создавать видеоконтент?

## Фреймворк компонентов контента { #content-pillars-framework }

Создавайте свой контент на основе 3-5 основных принципов, которые соответствуют вашему опыту и интересам аудитории.

### Пример для основателя SaaS { #example-for-a-saas-founder }

| Столб | % от содержания | Темы |
|--------|--------------|--------|
| Отраслевая информация | 30% | Тенденции, данные, прогнозы |
| За кадром | 25% | Построение компании, извлеченные уроки |
| Образовательный | 25% | Инструкции, фреймворки, советы |
| Личный | 15% | Истории, ценности, горячие взгляды |
| Рекламный | 5% | Обновления продуктов, предложения |

### Вопросы разработки основных компонентов { #pillar-development-questions }

Для каждого столпа спросите:
1. Какой уникальной перспективой вы обладаете?
2. Какие вопросы задает ваша аудитория?
3. Какой контент хорошо зарекомендовал себя раньше?
4. Что вы можете создавать последовательно?
5. Что соответствует бизнес-целям?

## Формулы зацепок { #hook-formulas }

Первая строка определяет, прочтет ли кто-нибудь остальное.

### Крючки для любопытства { #curiosity-hooks }
- "Я был неправ насчет [распространенное убеждение]."
- - Истинная причина [результат] происходит совсем не то, что вы думаете".
- "[Впечатляющий результат] — и это заняло всего [удивительно короткое время]."

### Сюжетные зацепки { #story-hooks }
- - На прошлой неделе, [случилось неожиданное."
- "Я почти [большая ошибка/неудача]."
- "3 года назад я [прошлое состояние]. Сегодня, [текущее состояние]."

### Ценностные зацепки { #value-hooks }
- "Как это сделать [желаемый результат] (без [обычная боль]):"
- "[Число] [вещи], которые [результат]:"
- "Прекрати [распространенная ошибка]. Сделайте это вместо этого:"

### Противоположные крючки { #contrarian-hooks }
- "Непопулярное мнение: [смелое заявление]"
- "[Распространенный совет] неверен. Вот почему:"
- "Я остановился [общепринятая практика] и [положительный результат]."

** Для получения шаблонов сообщений и других зацепок**: Смотрите [ссылки/post-шаблоны.md](https://github.com/imgusev/claude-skills-ru/tree/main/marketing-skill/skills/social-content/references/post-templates.md)

## Система перепрофилирования контента { #content-repurposing-system }

Превратите один фрагмент контента во множество:

### Запись в блоге → Социальный контент { #blog-post--social-content }

| Платформа | Формат |
|----------|--------|
| LinkedIn | Ключевая информация + ссылка в комментариях |
| LinkedIn | Карусель основных моментов |
| Твиттер/X | Цепочка ключевых выводов |
| Instagram | Карусель с визуальными эффектами |
| Instagram | Ролик, подводящий итог посту |

### Перепрофилирование воркфлоу { #repurposing-workflow }

1. ** Создавайте основной контент ** (блог, видео, подкаст)
2. ** Извлеките ключевые идеи** (3-5 за штуку)
3. ** Адаптация к каждой платформе ** (формат и тональность)
4. ** Расписание на неделю ** (спредовое распределение)
5. ** Обновляйте и повторно публикуйте ** (вечнозеленый контент может повторяться)

4. Создавайте идеи для карусели в Instagram + катушки
5. Запланируйте все
6. Оставьте место для взаимодействия в режиме реального времени

## Стратегия взаимодействия { #engagement-strategy }

### Ежедневная рутина занятий (30 мин) { #daily-engagement-routine-30-min }

1. Отвечать на все комментарии к вашим постам (5 мин)
2. Прокомментируйте 5-10 постов из целевых аккаунтов (15 мин)
3. Поделиться /репостнуть с дополнительной информацией (5 мин)
4. Отправьте 2-3 SMS-сообщения новым подключениям (5 мин)

### Качественные комментарии { #quality-comments }

- Добавьте новое понимание, а не просто "Отличный пост"!
- Поделитесь соответствующим опытом
- Задайте вдумчивый последующий вопрос
- При всем уважении не согласен с нюансом

### Выстраивание отношений { #building-relationships }

- Определите 20-50 учетных записей в вашем пространстве
- Постоянно взаимодействуйте с их контентом
- Делитесь своим контентом с друзьями
- В конечном итоге совместная работа (подкасты, совместно созданный контент)

## Аналитика и оптимизация { #analytics--optimization }

### Показатели, которые имеют значение { #metrics-that-matter }

** Осведомленность:** Показы, охват, скорость роста подписчиков

** Вовлеченность:** Уровень вовлеченности, комментарии (более ценные, чем лайки), акции/репосты, сохранения

** Конверсия:** Переходы по ссылкам, посещения профиля, полученные DMS, приписанные лиды

### Еженедельный Ревью { #weekly-review }

- Топ-3 самых результативных поста (почему они сработали?)
- Нижние 3 поста (чему вы можете научиться?)
- Тенденция роста последователей
- Тенденция к уровню вовлеченности
- Наилучшее время публикации (по данным)

### Действия по оптимизации { #optimization-actions }

**Если вовлеченность низкая:**
- Протестируйте новые крючки
- Публиковать в разное время
- Попробуйте разные форматы
- Расширяйте взаимодействие с другими людьми

**Если охват сокращается:**
- Избегайте внешних ссылок в тексте сообщения
- Увеличьте частоту публикации
- Больше участвуйте в комментариях
- Тестируйте видео/визуальный контент

- Спросите свою аудиторию, чего они хотят

- Поделитесь неудачей или извлеченным уроком

## Лучшие практики планирования { #scheduling-best-practices }

### Когда планировать по сравнению с Публиковать в прямом эфире { #when-to-schedule-vs-post-live }

** Расписание:** Посты с основным контентом, темы, карусели, вечнозеленый контент

** Публикация в прямом эфире:** Комментарии в режиме реального времени, ответы на новости / тренды, взаимодействие с другими пользователями

### Управление очередями { #queue-management }

- Поддерживайте запланированный контент в течение 1-2 недель
- Еженедельный ревью очереди на предмет актуальности
- Оставляйте пробелы для спонтанных постов
- Отрегулируйте время на основе данных о производительности

## Обратный инжиниринг вирусного контента { #reverse-engineering-viral-content }

Вместо того чтобы гадать, проанализируйте, что работает у лучших создателей в вашей нише:

1. **Найдите создателей** — 10-20 аккаунтов с высокой вовлеченностью
2. **Сбор данных** — 500+ посты для анализа
3. ** Анализ шаблонов** — крючки, форматы, CTA, которые работают
4. **Кодифицировать плейбук** — Документировать повторяющиеся шаблоны
5. ** Наложите слой на свой голос ** — Применяйте шаблоны с аутентичностью
6. **Преобразовать** — Привлечь внимание к бизнес-результатам

## Проактивные триггеры { #proactive-triggers }

Выявляйте эти проблемы, НЕ спрашивая, когда вы замечаете их в контексте:

- ** Пользователь хочет публиковать один и тот же контент на каждой платформе ** → Немедленно отметьте несоответствие формата платформы; адаптируйте тон, длину и структуру для каждой платформы перед написанием.
- ** Хук не предусмотрен и не запланирован** → Остановитесь и сначала напишите хук; все остальное бесполезно, если первая строка не подходит.
- ** Частота публикации неустойчива ** (например, 3 раза в день на 4 платформах) → Отметьте риск выгорания и порекомендуйте целенаправленную стратегию на 1-2 платформах с дозированием.
- ** Рекламный контент занимает более 20% календаря ** → Предупреждаем, что охват будет снижаться; переключитесь на образовательные и сюжетные направления.
- ** Стратегии вовлечения не существует ** → Напомните, что публикация без вовлечения - это трансляция, а не построение; предложите шаблон ежедневной рутины.

## Общение { #communication }

Все выходные данные соответствуют стандарту структурированной связи:

- ** Сначала подведите итог ** — опубликуйте сообщение или календарь, прежде чем объяснять выбор стратегии
- **Что + почему + как** — объясняется каждое решение о формате или платформе
- **Платформа-нативная по умолчанию ** — никогда не доставляйте универсальную копию; всегда адаптируйтесь к целевой платформе
- ** Доверительные теги** — 🟢 проверенный формат / 🟡 протестируйте это / 🔴 зависит от вашей аудитории

Всегда включайте крючок в качестве первого элемента. Никогда не отправляйте основную копию без нее. Для календарей отметьте, какие публикации являются вечнозелеными, а какие - своевременными.

## Связанные скиллы { #related-skills }

- ** маркетинговый контекст **: ИСПОЛЬЗУЙТЕ в качестве основы перед созданием любого контента — загружайте голос бренда, ICP и рекомендации по тону. НЕ является заменой адаптации к конкретной платформе.
- ** копирайтинг**: ИСПОЛЬЗУЙТЕ, когда требуется копия страницы с расширенной формой или целевой страницы. НЕ для коротких постов в социальных сетях.
- ** контент-стратегия **: ИСПОЛЬЗУЙТЕ при принятии решения о том, какие темы освещать, прежде чем создавать посты в социальных сетях. НЕ для написания самих постов.
- ** редактирование копий **: ИСПОЛЬЗУЕТСЯ для доработки черновиков копий в социальных сетях, особенно для кампаний с высокими ставками. НЕ для создания случайных постов.
- ** маркетинговые идеи**: ИСПОЛЬЗУЙТЕ при мозговом штурме, какую социальную тактику или каналы роста использовать. НЕ для написания конкретных постов.
- **производство контента**: ИСПОЛЬЗУЕТСЯ при работе с машиной для обработки большого объема контента несколькими создателями. НЕ для создания одноразового поста.
- ** гуманизатор контента **: ИСПОЛЬЗУЙТЕ, когда посты, составленные с помощью искусственного интеллекта, звучат роботизированно или шаблонно. НЕ для разработки стратегии или составления расписания.
- **стратегия запуска **: ИСПОЛЬЗУЕТСЯ при координации социального контента вокруг запуска продукта. НЕ для вечнозеленых расписаний рассылки.
