## Перед началом работы { #before-starting }

** Сначала проверьте маркетинговый контекст:**
Если `.claude/product-marketing-context.md` существует, прочтите его, чтобы узнать о бренде, персонажах аудитории и целях. Просите только о том, чего не хватает.

Соберите этот контекст (спросите, если он не указан):

### 1. Текущее состояние { #1-current-state }
- На каких платформах вы активны?
- Текущее количество подписчиков и уровень вовлеченности?
- Как часто вы публикуете посты? Кто этим управляет?
- Что работает? А что нет?

### 2. Цели { #2-goals }
- Узнаваемость бренда, лидогенерация, создание сообщества или интеллектуальное лидерство?
- Как выглядит успех через 90 дней?

### 3. Ресурсы { #3-resources }
- Кто создает контент? Сколько времени в неделю?
- Бюджет на платные социальные услуги (если таковые имеются)?
- Инструменты, которые вы используете (планирование, аналитика)?

## Как работает этот Скилл { #how-this-skill-works }

### Режим 1: Создайте стратегию с нуля { #mode-1-build-strategy-from-scratch }
Никакого социального присутствия или нового старта на платформе. Определите платформы, частоту, основные компоненты контента и план роста.

### Режим 2: Аудит и оптимизация { #mode-2-audit--optimize }
Активное социальное присутствие, которое не дает результатов. Проанализируйте, что работает, выявите пробелы и перестройте подход.

### Режим 3: Масштабирование и систематизация { #mode-3-scale--systematize }
Растущее присутствие в социальных сетях, для которого необходимы календари со структурированным контентом, воркфлоу, командные процессы и фреймворки измерения.

## Выбор платформы { #platform-selection }

Не каждая платформа заслуживает вашего времени. Выбирайте, основываясь на том, где ваша аудитория уже проводит время, а не на том, где, по вашему мнению, вы должны быть.

### Соответствие платформы и аудитории { #platform-audience-fit }

| Платформа | Лучше всего подходит для | Стиль контента | Частота постинга |
|----------|----------|---------------|-----------------|
| **LinkedIn** | B2B, интеллектуальное лидерство, рекрутинг | Длинные посты, карусели, статьи | 3-5 раз в неделю |
| **Твиттер/X** | Технологии, МЕДИА, реальное время, сообщество | Короткие дубли, резьбы, зацепление | 1-3 раза в день |
| **Instagram** | B2C, визуальные бренды, стиль жизни | Ролики, истории, карусели | 4-7 раз в неделю |
| **ТикТок** | Молодая аудитория, вирусный потенциал | Короткое видео, тренды, аутентичное | 1-3 раза в день |
| **YouTube** | Образование, учебные пособия, расширенная форма | Видеоролики, короткометражки | 1-2 раза в неделю |

** Эмпирическое правило: ** Сделайте 1-2 платформы исключительно хорошо, прежде чем добавлять третью. Половинчатое присутствие на 5 платформах превосходит нулевую вовлеченность на всех них.

## Фреймворк компонента содержимого { #content-pillar-framework }

Каждая социальная стратегия нуждается в 3-5 компонентах контента, которые уравновешивают предоставление ценности с бизнес-результатами.

### Конструкция столба { #pillar-structure }

| Тип стойки | Цель | Смешать | Пример |
|-------------|---------|-----|---------|
| **Образовательный** | Научите свою аудиторию чему-нибудь полезному | 40% | Инструкции, советы, фреймворки |
| **За кулисами** | Укрепляйте доверие с помощью прозрачности | 20% | Процесс, команда, путешествие |
| **Социальное доказательство** | Демонстрировать результаты и доверие | 15% | Тематические исследования, отзывы, победы |
| **Вовлеченность** | Начинайте разговоры и создавайте сообщество | 15% | Вопросы, опросы, дебаты |
| **Рекламный** | Влиять на результаты бизнеса | 10% | Характеристики продукта, запуски, предложения |

Ограничение на участие в акции в размере 10% является преднамеренным. Если ваша лента выглядит как рекламный канал, люди отписываются от вас.

## Дизайн календаря контента { #content-calendar-design }

### Еженедельный шаблон { #weekly-template }

| День | Столб | Формат | Примечания |
|-----|--------|--------|-------|
| Понедельник | Образовательный | Длинный пост или карусель | Удачное начало недели |
| Вт | Помолвка | Вопрос или опрос | Приводите комментарии для улучшения алгоритма |

| Пятница | Социальное доказательство или промо-акция | Тематическое исследование или запуск | Фокус на конверсии в конце недели |

### Сгенерировать календарь (прилагаемый инструмент) { #generate-the-calendar-bundled-tool }

```bash
python3 scripts/social_calendar_generator.py --config calendar.json --start 2026-06-15 --weeks 4 --markdown
```

Дайте ему ваши pillars + platforms + cadence (без конфигурации = встроенная демонстрация; `--json` для пайплайнов); он выдает календарь со сбалансированным распределением столбов. Используйте его выходные данные в качестве рабочего календаря для приведенного ниже пакетного воркфлоу — перебалансируйте вручную только в том случае, если кампании (запуску, событию) необходимо переопределить слот pillar.

### Воркфлоу для пакетного создания { #batch-creation-workflow }

```
Week -1: Plan topics for next week (30 min)
Day 1: Batch-create 5 posts (2 hours)
Daily: 15 min engagement (reply to comments, engage with others)
Week +1: Review analytics, adjust next week (30 min)
```

## Вовлечение сообщества { #community-engagement }

Публикация без вовлечения - это трансляция, а не социальные сети. Вовлеченность - это половина игры.

### Правило 1:1 { #the-11-rule }
Для каждой публикации, которую вы публикуете, тратьте равное количество времени на ознакомление с контентом других пользователей. Комментируйте, делитесь, отвечайте.

### Фреймворк реагирования { #response-framework }
- **Вопросы о вашем продукте** → Ответьте в течение 2 часов в рабочее время
- **Жалобы** → Подтверждать публично, разрешать в частном порядке, следить публично
- ** Похвалите ** → Поблагодарите их, дополните репликой или цитатой
- **Тролли** → Игнорируют, если только они на самом деле не ошибаются. Никогда не кормите троллей.
- ** Отраслевое обсуждение ** → Добавляйте подлинную ценность, а не саморекламу

## Тактика роста { #growth-tactics }

### Рычаги органического роста { #organic-growth-levers }

1. **Согласованность** — Публикация по расписанию. Алгоритмы вознаграждают за надежность.
2. ** Приманка для вовлечения сделана правильно ** — Искренние вопросы, а не "нравится, если вы согласны". Опросы работают. Горячее требует работы. Выяснение мнений работает.
3. ** Сотрудничество ** — Совместное создание контента с помощью дополнительных учетных записей.
4. ** Перепрофилирование ** — Одна запись в блоге → 5-10 постов в социальных сетях на разных платформах.
5. ** Отслеживание тенденций ** — Быстро ориентируйтесь на актуальные тренды, но только в том случае, если они соответствуют вашему бренду.
6. ** Создание сообщества ** — Создавайте пространства (Discord, Slack, группы), а не только аудитории.

### Показатели, которые имеют значение { #metrics-that-matter }

| Метрика | Что Это Вам говорит | Цель |
|--------|-------------------|--------|
| Уровень вовлеченности | Резонанс содержания | >3% (LinkedIn), >1% (Twitter), >2% (Instagram) |
| Темп роста подписчиков | Аудитория набирает обороты | >5% ежемесячно |
| Показатель кликабельности | Контент, стимулирующий действие | >1% |
| Скорость обмена/сохранения | Контент, который стоит сохранить | Выше = содержание действительно полезно |
| Беседы с DM | Построение реальных отношений | Растет из месяца в месяц |

** Показатели тщеславия для определения приоритетности: ** Общее количество подписчиков, показы (без вовлеченности), охват (без действий).

## Чек-лист по аудиту социальных сетей Audit Audit { #social-media-audit-checklist }

### Аудит профиля { #profile-audit }
- [ ] Фотография профиля: узнаваемая, согласованная на разных платформах
- [ ] Биография: четкое ценностное предложение, а не перечисление должностей
- [ ] Ссылка: ведет на соответствующую целевую страницу (не только домашнюю страницу)
- [ ] Закрепленный пост: наиболее эффективный или самый важный контент

### Аудит контента { #content-audit }
- [ ] Последовательность постинга: регулярный ритм или спорадический?
- [ ] Состав контента: сбалансирован по всем направлениям или только рекламный?
- [ ] Разнообразие форматов: текст, изображения, видео, карусели?
- [ ] Согласованность голоса: соответствует бренду во всех постах?

### Аудит взаимодействия { #engagement-audit }
- [ ] Время отклика: в течение 2 часов или дней спустя?
- [ ] Качество комментариев: искренние ответы или "спасибо!"?
- [ ] Исходящее взаимодействие: взаимодействие с чужим контентом?
- [ ] Участие в сообществе: в соответствующих группах/беседах?

## Проактивные триггеры { #proactive-triggers }

- ** Частота публикаций упала ниже 3 раз в неделю ** → Последовательность имеет большее значение, чем качество. Пакетное создание для поддержания частоты вращения.
- ** Уровень вовлеченности ниже среднего по платформе ** → Контент не находит отклика. Аудит последних 20 постов на предмет шаблонов — какие из них привлекли внимание, а какие нет?
- **100% рекламный контент ** → Поступает информация об усталости аудитории. Перейдите к разделению стоимости на 80/20/промо-акции.
- **Никакого взаимодействия с чужим контентом ** → Социальные сети являются двусторонними. Тратьте 15 минут в день на комментирование соответствующих постов.
- ** Одинаковый формат контента для каждого поста ** → Усталость от алгоритма. Смешивайте форматы: текст, карусель, видео, опрос.

## Общение { #communication }

Вся продукция проходит проверку качества:
- Самопроверка: указание источника, аудит предположений, оценка достоверности
- Формат вывода: Итоговая строка → Что (с уверенностью) → Почему → Как действовать
- Только результаты. Каждая находка помечена тегами: "проверено", "средний", "предполагается".

## Связанные скиллы { #related-skills }

- ** социальный контент **: Для написания отдельных постов в социальных сетях. НЕ для стратегии (это и есть этот скилл).
- **анализатор социальных сетей**: Для анализа данных о производительности социальных сетей.
- ** контент-стратегия**: Для планирования более широкого контента, который попадает в социальные сети.
- ** копирайтинг**: Для целевых страниц и веб-копий, на которые ссылаются социальные сети.
- **маркетинг-контекст **: Основа — считывает голос бренда для обеспечения последовательного социального тона.
- **рекламный креатив**: Для платной копии социальной рекламы, отличной от обычного социального контента.
