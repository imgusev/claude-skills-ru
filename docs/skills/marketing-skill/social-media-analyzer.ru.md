## Анализ воркфлоу { #analysis-workflow }

Проанализируйте эффективность кампании в социальных сетях:

1. Проверка полноты входных данных (reach > 0, даты действительны)
2. Рассчитайте показатели вовлеченности для каждой публикации
3. Агрегированные показатели на уровне кампании
4. Рассчитайте рентабельность инвестиций, если указаны расходы на рекламу
5. Сравнение с эталонными показателями платформы
6. Определите лучших и низших исполнителей
7. Генерировать рекомендации
8. ** Проверка:** Уровень вовлеченности < 100%, рентабельность инвестиций соответствует данным о расходах

### Входные требования { #input-requirements }

| Поле | Требуемый | Описание |
|-------|----------|-------------|
| платформа | Да | instagram, facebook, twitter, linkedin, tiktok |
| посты[] | Да | Массив почтовых данных |
| посты[].нравится | Да | Количество лайков/реакций |
| посты[].комментарии | Да | Количество комментариев |
| посты[].достичь | Да | Привлечены уникальные пользователи |
| посты[].впечатления | Нет | Общее количество просмотров |
| посты[].акции | Нет | Количество репостов/ретвитов |
| посты[].сохраняет | Нет | Количество сохранений/закладок |
| посты[].щелчки | Нет | Переходы по ссылкам |
| итого_расход | Нет | Расходы на рекламу (для рентабельности инвестиций) |

### Проверки достоверности данных { #data-validation-checks }

Перед анализом проверьте:

- [ ] Достичь > 0 для всех сообщений (избегайте деления на ноль)
- [ ] Количество вовлечений неотрицательно
- [ ] Диапазон дат действителен (начало < конец)
- [ ] Платформа распознана
- [ ] Потратить > 0, если запрошена рентабельность инвестиций

## Показатели вовлеченности { #engagement-metrics }

### Расчет коэффициента вовлеченности { #engagement-rate-calculation }

```
Engagement Rate = (Likes + Comments + Shares + Saves) / Reach × 100
```

### Определения метрик { #metric-definitions }

| Метрика | Формула | Интерпретация |
|--------|---------|----------------|
| Уровень вовлеченности | Обязательства / Охват × 100 | Уровень взаимодействия с аудиторией |
| CTR | Клики / показы × 100 | Обращение к содержимому по щелчку мыши |
| Скорость достижения | Охват / Подписчики × 100 | Распространение контента |
| Уровень вирусности | Количество акций / показов × 100 | Ценность участия |
| Коэффициент экономии | Экономия / охват × 100 | Ценность контента |

### Категории эффективности { #performance-categories }

| Рейтинг | Уровень вовлеченности | Действие |
|--------|-----------------|--------|
| Превосходно | > 6% | Масштабирование и тиражирование |
| Хороший | 3-6% | Оптимизировать и расширять |
| Средний | 1-3% | Улучшения в тестировании |
| Бедный | < 1% | Анализ и поворот |

## Расчет рентабельности инвестиций { #roi-calculation }

Рассчитайте отдачу от затрат на рекламу:

1. Суммируйте общее количество заданий по всем должностям
2. Рассчитать стоимость каждого задания (CPE)
3. Рассчитайте стоимость за клик (CPC), если клики доступны
4. Оцените ценность взаимодействия, используя базовые показатели
5. Рассчитать процент рентабельности инвестиций
6. ** Проверка:** Рентабельность инвестиций = (Стоимость - затраты) / Затраты × 100

### Формулы рентабельности инвестиций { #roi-formulas }

| Метрика | Формула |
|--------|---------|
| Стоимость одного задания (CPE) | Общие расходы / Общее количество заданий |
| Стоимость за клик (CPC) | Общее количество потраченных средств / Общее количество кликов |
| Стоимость за тысячу (CPM) | (Расходы / показы) × 1000 |
| Рентабельность расходов на рекламу (ROAS) | Доход / Расходы на рекламу |

### Оценки ценности взаимодействия { #engagement-value-estimates }

| Действие | Значение | Обоснование |
|--------|-------|-----------|
| Как | $0.50 | Узнаваемость бренда |
| Комментарий | $2.00 | Активное участие |
| Поделиться | $5.00 | Усиление |
| Сохранить | $3.00 | Сигнал о намерении |
| Щелчок | $1.50 | Значение трафика |

### Интерпретация рентабельности инвестиций { #roi-interpretation }

| РЕНТАБЕЛЬНОСТЬ ИНВЕСТИЦИЙ % | Рейтинг | Рекомендация |
|-------|--------|----------------|
| > 500% | Превосходно | Значительно увеличьте бюджет |
| 200-500% | Хороший | Умеренно увеличивайте бюджет |
| 100-200% | Приемлемый | Оптимизируйте перед масштабированием |
| 0-100% | Безубыточность | Ревью таргетинг и креатив |
| < 0% | Отрицательный | Приостановка и реструктуризация |

## Инструменты { #tools }

```bash
python scripts/calculate_metrics.py assets/sample_input.json
```

```bash
python scripts/analyze_performance.py assets/sample_input.json
```

Генерирует полный анализ производительности с указанием рентабельности инвестиций, контрольных показателей и рекомендаций.

**Выходные данные включают в себя:**
- Показатели на уровне кампании
- Разбивка по постам
- Сравнительные показатели
- Рейтинг лучших исполнителей
- Практические рекомендации

```json
{
  "campaign_metrics": {

    "avg_engagement_rate": 8.36,
    "ctr": 1.55

  "roi_metrics": {
```

### Интерпретация { #interpretation }

Пример кампании показывает:
- ** Уровень вовлеченности 8,36%** против 1,22% контрольных показателей = Отлично (в 6,8 раза выше среднего)
- **CTR 1,55%** против 0,22% в тесте = отлично (в 7 раз выше среднего)
- **Рентабельность инвестиций 660%** = Выдающаяся отдача от потраченных 500 долларов
- **Рекомендация:** Масштабируйте бюджет, повторяйте успешные элементы

## Проактивные триггеры { #proactive-triggers }

- ** Уровень вовлеченности ниже среднего по платформе ** → Контент не находит отклика. Проанализируйте лучших исполнителей на предмет закономерностей.
- ** Рост числа подписчиков приостановился ** → Проблема с распространением контента или частотой. Аудит шаблонов проводки.
- **Высокие впечатления, низкая вовлеченность ** → Охват без резонанса. Проблема с качеством контента.
- **Конкурент значительно превосходит конкурентов ** → Разрыв в содержании. Проанализируйте их успешные посты.
