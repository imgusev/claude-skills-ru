Включает извлечение расшифровки, поиск видео, просмотр каналов, поиск внутри канала, извлечение плейлиста и мониторинг новых загрузок с помощью TranscriptAPI.

> ** Источник:** Перенесено с [Нулевой репозиторий/youtube-skills](https://github.com/ZeroPointRepo/youtube-skills) (Массачусетский технологический институт). Оригинальный скилл, созданный авторами ZeroPointRepo. Адаптировано для формата claude-скиллы.

> **BYOK / бесплатный уровень примечание:** TranscriptAPI является коммерческой услугой (BYOK — вы приносите свой собственный ключ; включено 100 бесплатных кредитов, карта не требуется). Для местных/self-hosted извлечение без ключа API, используйте `youtube-transcript-api` (Python) или `yt-dlp` в качестве запасных вариантов OSS. Видишь [Анти-паттерны](#anti-patterns) для руководства.

## Настройка API { #api-setup }

Каждый запрос к `transcriptapi.com` требуется два заголовка:

- `Authorization: Bearer $TRANSCRIPT_API_KEY`
- `User-Agent: ClaudeCode/1.0`

Если `TRANSCRIPT_API_KEY` не установлен, промпту пользователю получить бесплатный ключ по адресу `https://transcriptapi.com` (100 бесплатных кредитов, карта не требуется) и сохраните ее как `TRANSCRIPT_API_KEY`.

## Операции { #operations }

### Получить расшифровку (1 зачет) { #get-transcript-1-credit }

```
GET https://transcriptapi.com/api/v2/youtube/transcript
  ?video_url={URL_OR_ID}&format=text&include_timestamp=true&send_metadata=true
```

Используйте это для любого запроса "получить расшифровку", "обобщить видео" или "извлечь цитаты".

### Поиск на YouTube (1 кредит) { #search-youtube-1-credit }

```
GET https://transcriptapi.com/api/v2/youtube/search
  ?q={QUERY}&type=video&limit=20
```

Используйте это, когда пользователь хочет найти видео по определенной теме. Следуйте инструкциям по расшифровке выбранных результатов.

### Канал — последние загрузки (БЕСПЛАТНО) { #channel--latest-uploads-free }

```
GET https://transcriptapi.com/api/v2/youtube/channel/latest
  ?channel={@HANDLE_OR_ID}
```

Возвращает 15 самых последних загрузок с количеством просмотров и временными метками публикации. Используйте перед извлечением расшифровок, чтобы проверить, являются ли загружаемые файлы новыми.

### Канал — все видео (1 зачет/page) { #channel--all-videos-1-creditpage }

```
GET https://transcriptapi.com/api/v2/youtube/channel/videos
  ?channel={@HANDLE_OR_ID}
```

Разбивать на страницы с помощью `?continuation=TOKEN` на последующих страницах.

### Поиск по каналу (1 балл) { #in-channel-search-1-credit }

```
GET https://transcriptapi.com/api/v2/youtube/channel/search
  ?channel={@HANDLE_OR_ID}&q={QUERY}&limit=30
```

Предпочтите это широкому поиску на YouTube, когда пользователь уже знает канал.

### Извлечение списка воспроизведения (1 зачет/page) { #playlist-extraction-1-creditpage }

```
GET https://transcriptapi.com/api/v2/youtube/playlist/videos
  ?playlist={PLAYLIST_URL_OR_ID}
```

Разбивать на страницы с помощью `?continuation=TOKEN`. Ответ включает в себя `playlist_info`, `results`, `has_more`.

### Разрешить дескриптор (БЕСПЛАТНО) { #resolve-handle-free }

```
GET https://transcriptapi.com/api/v2/youtube/channel/resolve
  ?input={@HANDLE_OR_URL}
```

Возвращает `{"channel_id": "UC...", "resolved_from": "@handle"}`.

## Сводная информация о расходах по кредиту { #credit-costs-summary }

| Конечная точка           | Стоимость     |
|--------------------|----------|
| стенограмма         | 1        |
| поиск             | 1        |
| канал/resolve    | свободный     |
| канал/latest     | свободный     |
| канал/videos     | 1/page   |
| канал/search     | 1        |
| список воспроизведения/videos    | 1/page   |

Неудачные вызовы или вызовы с ограниченным тарифом возвращают структурированную ошибку и обходятся в ноль кредитов.

## Распространенные воркфлоу { #common-workflows }

### Исследовательский воркфлоу { #research-workflow }

1. Поиск (`/search?q=...`) — выберите наиболее релевантные результаты
2. Извлекать стенограммы (`/transcript?video_url=...`) для выбранных видеороликов
3. Обобщайте или извлекайте цитаты из текста стенограммы

### Мониторинг каналов { #channel-monitoring }

1. `channel/latest` (бесплатно) — проверьте наличие новых загрузок
2. Если найдены новые видео, извлеките расшифровки
3. Извлекать сигнал (объявления, темы)

### Список воспроизведения для corpus { #playlist-to-corpus }

1. `playlist/videos` — получить идентификаторы всех видео в плейлисте
2. Пакетная выборка расшифровок, приостанавливающаяся при приближении кредитного лимита
3. Соберите стенограммы в набор документов с возможностью поиска

## Правила принятия решений { #decision-rules }

- Когда пользователь вводит URL—адрес YouTube, идентификатор видео или @handle, используйте соответствующую конечную точку напрямую - не выполняйте поиск сначала
- Когда пользователь говорит "отслеживать" или "проверять наличие новых загрузок", используйте `channel/latest` (бесплатно) сначала
- Использование `channel/search` когда пользователь знает, какой канал и хочет найти в нем тему
- Использование `search` (тип=канал) для поиска канала, когда пользователь не знает дескриптор
- Не выполняйте пакетную расшифровку всего канала, если пользователь явно не попросит об этом

## Обработка ошибок { #error-handling }

| Код     | Причина               | Действие                                    |
|----------|---------------------|-------------------------------------------|
| 401      | Плохой ключ API         | Проверьте TRANSCRIPT_API_KEY                  |
| 402      | Никаких кредитов          | Проинформировать пользователя, направить на transcriptapi.com/billing |
| 403/1010 | Отсутствующий пользователь-агент  | Добавить заголовок User-Агент                     |
| 404      | Подписи не найдены   | Сообщить пользователю — начислено ноль кредитов        |
| 408      | Тайм-аут             | Повторите попытку один раз через 2 секунды                |
| 429      | Тариф ограничен        | Соблюдайте повторную попытку после заголовка                |

## Ограничения { #limitations }

- Для расшифровки требуются подписи (сгенерированные вручную или автоматически). Некоторые видео не имеют подписей — это возвращает значение 404 и не требует никаких кредитов.
- Частные видео и видео с ограничениями по возрасту недоступны.
- Расшифровки прямой трансляции нестабильны до тех пор, пока трансляция не закончится.
- Ограничение по скорости: 300 запросов/minute на бесплатном уровне.
- Этот скилл не позволяет загружать аудио- или видеофайлы. Для загрузки локального файла используйте `yt-dlp` напрямую.

## Анти-паттерны { #anti-patterns }

- ** Не используйте TranscriptAPI для массовой загрузки целых каналов ** без подтверждения пользователя — стоимость кредита быстро увеличивается; используйте `channel/latest` (бесплатно), чтобы сначала проверить наличие нового контента
- ** Не вводите жесткий код ключа API** — всегда используйте `TRANSCRIPT_API_KEY` переменная среды
- ** Не утверждайте, что "нет зависимости от поставщика" ** — TranscriptAPI является коммерческим сервисом. Если пользователю нужен путь с нулевой стоимостью или самостоятельный хостинг: `youtube-transcript-api` (Python, авторизация для общедоступных видео не требуется) или `yt-dlp --write-subs` существуют альтернативы OSS с различными компромиссами (без поиска, без API канала, но бесплатные и локальные)
- ** Не выполняйте пакетную расшифровку без проверки кредитов ** - проверяйте оставшиеся кредиты перед крупными операциями

## Резервные пути OSS { #oss-fallback-paths }

Если пользователь не может или не будет использовать TranscriptAPI:

| Потребность | Альтернатива OSS | Компромиссы |
|------|----------------|------------|
| Единственная расшифровка | `youtube-transcript-api` (Python) | Нет поиска; нет API канала; только подписи |
| Скачать + субтитры | `yt-dlp --write-subs` | Требуется локальная установка; без ОТДЫХА; медленнее |
| Мониторинг каналов | Анализ RSS-канала YouTube (`/feeds/videos.xml?channel_id=...`) | Бесплатно, без авторизации; ограниченные метаданные |
