## Перед планированием { #before-planning }

** Сначала проверьте маркетинговый контекст продукта:**
Если `.claude/product-marketing-context.md` существует, прочтите его, прежде чем задавать вопросы. Используйте этот контекст и запрашивайте только информацию, которая еще не охвачена или не относится конкретно к данной задаче.

Соберите этот контекст (спросите, если он не указан):

### 1. Бизнес-контекст { #1-business-context }
- Чем занимается компания?
- Кто является идеальным клиентом?
- Какова основная цель контента? (трафик, лиды, узнаваемость бренда, идейное лидерство)
- Какие проблемы решает ваш продукт?

### 2. Исследование клиентов { #2-customer-research }
- Какие вопросы задают покупатели перед покупкой?
- Какие возражения возникают при звонках по продажам?
- Какие темы неоднократно появляются в обращениях в службу поддержки?
- На каком языке клиенты описывают свои проблемы?

### 3. Текущее состояние { #3-current-state }
- Есть ли у вас существующий контент? Что работает?
- Какими ресурсами вы располагаете? (сценаристы, бюджет, время)
- Какие форматы контента вы можете создавать? (письменно, видео, аудио)

### 4. Конкурентный ландшафт { #4-competitive-landscape }
- Кто ваши основные конкуренты?
- Какие пробелы в контенте существуют на вашем рынке?

## Доступный для поиска или общий доступ { #searchable-vs-shareable }

Основное классификационное решение по каждой теме:

- ** Доступно для поиска ** — люди уже запрашивают это (объем ключевых слов существует). Цель: ранжировать и конвертировать. Формат: страницы с примерами использования, сравнения, инструкции, кластеры hub/speak. Оценивается по рейтингам + органическим конверсиям за 6-12 месяцев.
- ** Доступно для общего доступа ** — его пока никто не ищет, но оно распространяется (исходные данные, противоположный POV, сильное повествование). Цель: охват + ссылки + бренд. Оценивается по распространению (акции, реферальный трафик, обратные ссылки) в первые недели.

** Правило принятия решения: ** если тема имеет значимый объем поиска И четкие намерения покупателя → доступна для поиска (объедините ее в кластер). Если у него нет тома, но есть крючок распространения → общий доступ (спланируйте канал запуска перед записью). Если оба → структура с возможностью поиска и общим углом обзора (наилучшая рентабельность инвестиций). Если ни то, ни другое → не пишите этого.

## Сопоставление тематических кластеров (инструмент в комплекте) { #topic-cluster-mapping-bundled-tool }

Как только появятся приоритетные темы, сгруппируйте их механически:

```bash
python3 scripts/topic_cluster_mapper.py --file keywords.txt          # one topic/keyword per line
python3 scripts/topic_cluster_mapper.py --file keywords.txt --json  # for pipelines
```

Его выходные данные по кластеру являются отправной точкой для приведенной ниже карты кластеров по теме §3 — ревью границ кластера по намерению (инструмент группирует лексически; вы проверяете согласованность на этапе покупателя).

## Выходной формат { #output-format }

При создании контент-стратегии предоставьте:

### 1. Основные элементы контента { #1-content-pillars }
- 3-5 основных принципов с обоснованием
- Кластеры подтем для каждого компонента
- Как pillars подключаются к продукту

### 2. Приоритетные темы { #2-priority-topics }
Для каждого рекомендуемого изделия:
- Тема/название
- Доступный для поиска, общий доступ или и то, и другое вместе
- Тип контента (прецедент, концентратор/спица, идейное руководство и т.д.)
- Целевое ключевое слово и стадия покупателя
- Почему эта тема (поддержка исследований клиентов)

### 3. Карта тематических кластеров { #3-topic-cluster-map }
Визуальное или структурированное представление того, как контент взаимосвязан.

## Вопросы, относящиеся к конкретной задаче { #task-specific-questions }

1. Какие закономерности выявились в результате ваших последних 10 бесед с клиентами?
2. Какие вопросы постоянно возникают при звонках по продажам?
3. Где усилия конкурентов по созданию контента терпят неудачу?
4. Какими уникальными выводами из исследований клиентов не делятся в других местах?
5. Какой существующий контент обеспечивает наибольшую конверсию и почему?

## Проактивные триггеры { #proactive-triggers }

Выявляйте эти проблемы, НЕ спрашивая, когда вы замечаете их в контексте:

- ** Контент-плана не существует ** → Немедленно предложите стартовую стратегию из 3 компонентов с 10 начальными темами, прежде чем задавать дополнительные вопросы.
- ** У пользователя есть контент, но низкий трафик ** → Отметьте дисбаланс между возможностью поиска и общим доступом; проведите быстрый аудит существующих заголовков на предмет соответствия ключевым словам.
- ** Пользователь пишет контент без целевого ключевого слова ** → Предупредите, что усилия могут быть потрачены впустую; предложите определить правильное ключевое слово, прежде чем они начнут писать.
- ** Контент охватывает слишком много аудиторий** → Отметьте размывание ICP; рекомендуем разделить столбцы по персоне или варианту использования.
- ** Контент конкурентов явно превосходит их по основным темам ** → Триггер для анализа пробелов и выявления возможностей быстрого выигрыша там, где конкуренция ниже.

## Общение { #communication }

Все выходные данные соответствуют стандарту структурированной связи:

- **Сначала итог** — рекомендация перед обоснованием
- **Что + почему + Как** — в каждой стратегии есть все три
- ** У действий есть владельцы и крайние сроки** — никаких "вы могли бы рассмотреть".
- **Пометка достоверности** — 🟢 высокая достоверность / 🟡 средняя / 🔴 предположение

Формат вывода по умолчанию: таблицы для определения приоритетов, маркированные списки для вариантов, проза для обоснования. Соответствие глубины запросу — быстрый вопрос дает быстрый ответ, а не документ о стратегии.

## Связанные скиллы { #related-skills }

- ** маркетинг-контекст**: ИСПОЛЬЗУЙТЕ в качестве основы перед началом работы любой стратегии — учитывайте контекст продукта, аудитории и бренда. НЕ является заменой этому скиллу.
- ** копирайтинг**: ИСПОЛЬЗУЙТЕ, когда тема одобрена и пришло время писать собственно статью. НЕ для того, чтобы решать, о чем писать.
- ** копирование-редактирование **: ИСПОЛЬЗУЕТСЯ для шлифовки черновиков контента после написания. НЕ для планирования или принятия стратегических решений.
- **социальный контент **: ИСПОЛЬЗУЕТСЯ при распространении одобренного контента на социальных платформах. НЕ для стратегии органического поиска.
- ** маркетинговые идеи**: ИСПОЛЬЗУЙТЕ при мозговом штурме каналов роста, выходящих за рамки контента. НЕ для глубокого планирования ключевых слов или тем.
- **seo-аудит**: ИСПОЛЬЗУЕТСЯ при аудите существующего контента на предмет технических проблем и проблем на странице. НЕ для создания новой стратегии с нуля.
- **производство контента**: ИСПОЛЬЗУЕТСЯ при масштабировании объема контента с помощью повторяемого производственного воркфлоу. НЕ для первоначального определения стратегии.
- ** гуманизатор контента **: ИСПОЛЬЗУЙТЕ, когда контент, созданный искусственным интеллектом, должен звучать более аутентично. НЕ для выбора темы.
