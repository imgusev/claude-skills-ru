Разрабатывайте, расставляйте приоритеты и оценивайте эксперименты с продуктами на основе четких гипотез и обоснованных решений.

## Когда использовать { #when-to-use }

Используйте этот скилл для:
- A/B и планирование многомерного эксперимента
- Написание гипотезы и определение критериев успеха
- Планирование размера выборки и минимального обнаруживаемого эффекта
- Поэкспериментируйте с расстановкой приоритетов при подсчете очков на льду
- Считывание статистических данных для принятия решений о продукте

## Основной воркфлоу { #core-workflow }

1. Напишите гипотезу в формате If/Then/Because
- Если мы изменимся `[intervention]`
- Затем `[metric]` изменится на `[expected direction/magnitude]`
- Потому что `[behavioral mechanism]`

2. Определите показатели перед запуском теста
- Первичный показатель: единичный показатель принятия решения
- Показатели защитного барьера: качество/защита от рисков
- Вторичные показатели: только диагностика

3. Оцените размер выборки
- Преобразование базовой линии или среднее значение базовой линии
- Минимальный обнаруживаемый эффект (MDE)
- Уровень значимости (альфа) и мощность

Использование:
```bash
python3 scripts/sample_size_calculator.py --baseline-rate 0.12 --mde 0.02 --mde-type absolute
```

4. Расставьте приоритеты в экспериментах со ЛЬДОМ
- Влияние: потенциальный потенциал роста
- Уверенность: качество доказательств
- Простота: стоимость/скорость/сложность

Оценка ICE = (Воздействие * Уверенность * Легкость) / 10

5. Запуск с правилами остановки
- Заранее определите фиксированный размер выборки или фиксированную продолжительность
- Избегайте повторного подглядывания без надлежащего метода
- Постоянно следите за защитными барьерами

6. Интерпретировать результаты
- Статистическая значимость не является значимостью для бизнеса
- Сравните точечную оценку + доверительный интервал с порогом принятия решения
- Исследуйте эффекты новизны и неоднородность сегмента

## Чек-лист для проверки качества гипотез Quality Quality { #hypothesis-quality-checklist }

- [ ] Содержит явное вмешательство и аудиторию
- [ ] Определяет измеримое изменение показателя
- [ ] Указывает правдоподобную причинную причину
- [ ] Включает ожидаемый минимальный эффект
- [ ] Определяет условие отказа

## Распространенные ошибки в экспериментах { #common-experiment-pitfalls }

- Недостаточно мощные тесты, приводящие к ложноотрицательным результатам
- Выполнение слишком большого количества одновременных изменений без изоляции
- Изменение таргетинга или внедрение в середине тестирования
- Ранняя остановка при случайных скачках
- Игнорирование несоответствия соотношения выборок и смещения приборов
- Объявление успеха из p-значения без контекста размера эффекта

## Статистическая интерпретация Защитных барьеров { #statistical-interpretation-guardrails }

- p-значение < альфа указывает на доказательства против null, а не на гарантированную истинность.
- Пересечение доверительного интервала с нулевым значением/отсутствие эффекта означает неопределенное утверждение о направлении.
- Большие интервалы подразумевают низкую точность, даже если она значительна.
- Используйте пороговые значения практической значимости, привязанные к влиянию на бизнес.

- `references/statistics-reference.md`

## Оснастка { #tooling }

### `scripts/sample_size_calculator.py` { #scriptssample_size_calculatorpy }

Вычисляет требуемый размер выборки (для каждого варианта и всего) из:
- базовый уровень
- MDE (абсолютный или относительный)
- уровень значимости (альфа)
- статистическая мощь

Пример:
```bash
python3 scripts/sample_size_calculator.py \
  --baseline-rate 0.10 \
  --mde 0.015 \
  --mde-type absolute \
  --alpha 0.05 \
  --power 0.8
```
