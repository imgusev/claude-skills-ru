> ** Переносимость: ** Работает как в Claude Code CLI, так и в Claude.ai . Дополнительная фаза X/Twitter требует автоматизации браузера и автоматически пропускается, если она недоступна.

Исследовательский скилл, ориентированный на недавние события, который обобщает то, что люди говорят по теме в Reddit, Hacker News, open Web и (опционально) X / Twitter - в пределах настраиваемого временного интервала. Результатом является единый последовательный брифинг с цитатами, сигналами вовлеченности и кросс-платформенным анализом шаблонов. Скилл фиксирует ** текущую беседу**, а не каноническую ссылку.

## Призыв { #invocation }

**Явные фразы-триггеры:**
- "пульс включен [тема]"
- "что происходит с [тема]"
- "что люди говорят о [тема]"
- "текущий разговор о [тема]"
- "пощупай пульс у [тема]"
- "в тренде: [тема]"
- "найди мне информацию о [тема]"

Также охватывает: исследование конкурентов с учетом последних тенденций, выявление трендов, сравнение инструментов, анализ настроений аудитории.

## Правила добросовестности агента (Соглашение об исследовательском пакете) { #agent-integrity-rules-research-pack-convention }

Следующие правила применяются на протяжении всего прогона. Они унаследованы от соглашения research-pack и заблокированы аудитом согласованности между скиллами PR #657.

- ** Исполнительная дисциплина.** Этапы 1-3 выполняются параллельно (Reddit + HN + Web независимы). В рамках каждой фазы выполняются только последовательные вызовы. **1 вопрос/sec ограничение скорости для каждой платформы.** Подтвердите полученный ответ перед следующим вызовом в рамках той же фазы.
- **Дисциплина источника.** Цитируйте только источники, возвращаемые ** вызовами инструментов этого сеанса.** Учебные знания помечены `[Background — not from search]` и исключен из подсчета первичных результатов.
- ** Отслеживание по трем счетам.** Отправленные запросы / полученные источники (показаны) / цитируемые источники. Появилось в журнале аудита, встроенном в раздел обобщения. Использование `scripts/citation_tracker.py` для детерминированного подсчета.
- **Политика повторных попыток.** При сбое → подождите 3 секунды → повторите попытку один раз → войдите в систему. После **3 последовательных сбоев во всех источниках:** остановитесь, предупредите пользователя, поделитесь собранным. Никогда не отправляйте пустой файл.
- ** Обнаружение на уровне плана.** Reddit + HN - это неаутентифицированные общедоступные API JSON (скорость ограничена для каждого IP-адреса, а не для каждого плана). Поверхностная скорость - ограничивает сигналы из заголовков ответов, когда они доступны; в противном случае они корректно ухудшаются.

Видишь `references/research_pack_conventions.md` для канона и `references/parallel_execution_discipline.md` для обоснования ограничения скорости.

## Фаза 0: Прием пищи на гриле (2-4 форсирующих вопроса, по одному за раз) { #phase-0-grill-me-intake-24-forcing-questions-one-at-a-time }

Упорядоченный по зависимостям. Каждый вопрос содержит явное "почему я спрашиваю". Условие остановки: максимум 4.

### Q1 (корень) — Специфика темы { #q1-root--topic-specificity }

> ** Какова тема? Изложите это в 1-2 предложениях — будьте конкретны. "Искусственный интеллект" или "технология" дадут вам расплывчатый опрос; "самостоятельное развертывание LLM для небольших команд" или "Внедрение кода Claude среди корпоративных инженерных организаций" даст вам полезный ответ.**
>
> * Почему я спрашиваю: * Специфика диктует качество поиска. Расплывчатые темы приводят к расплывчатым брифингам. Если ваша тема обширна, я бы предпочел сузить ее сейчас, чем тратить бюджет поиска на шум.

** Откажитесь от кашицы. ** Если пользователь говорит "ИИ", ответьте один раз: "А как насчет ИИ — внедрения, безопасности, возможностей, регулирования или сравнения? Выбери ракурс." Если пользователь по-прежнему не сузит круг поиска после одного повторного нажатия, сделайте явное предостережение "неопределенная тема — уровень опроса, а не глубина".

### Q2 (зависит от Q1) — Угол { #q2-depends-on-q1--angle }

> ** Какой ракурс имеет наибольшее значение? Выбери что-нибудь одно:**
>
> 1. ** Тренд** — что ускоряется или замедляется
> 2. ** Настроение** — что люди чувствуют по этому поводу
> 3. **Проблемы** — болевые точки и жалобы
> 4. **Возможности** — пробелы и неудовлетворенные потребности
> 5. ** Сравнение** — как оно соотносится с альтернативами
>
> *Почему я спрашиваю:* Угол зрения определяет, какие источники имеют больший вес (Reddit для настроений, HN для технической критики, Web для освещения тенденций) и как я оцениваю обобщение.

Вынуждающий выбор. ** Рекомендуемое значение по умолчанию:** тенденция, если только тема явно не требует другого ракурса.

### Q3 (всегда) — Временное окно { #q3-always--time-window }

> **Временное окно: 7 / 14 / 30 / 60 / 90 дней? Значение по умолчанию - 30.**
>
> * Почему я спрашиваю: * 7 дней фиксируется прерывание разговора; 90 дней фиксируется устойчивый сдвиг повествования. Выбирайте в зависимости от того, насколько важны последние новости.

Принудительный выбор по умолчанию.

### Q4 (зависит от Q1) — Область применения платформы { #q4-depends-on-q1--platform-scope }

> ** Какую платформу можно пропустить? По умолчанию я буду освещать Reddit + Hacker News + open Web, а также X / Twitter, если доступна автоматизация браузера. Пропустите все, что вам безразлично.**
>
> * Почему я спрашиваю: * Отказ от платформы экономит бюджет поиска. Reddit доминирует над настроениями; HN доминирует над технической критикой; Web доминирует над широтой охвата; X доминирует в разговорной речи. Пропустите то, что не подходит под ваш ракурс.

Спрашивается только в том случае, если Q1 + Q2 указывают на то, что некоторые платформы явно нецелевые (например, тема потребительских настроений → HN менее полезна). В противном случае по умолчанию используется значение "все платформы".

** Условие остановки: ** После Q4 (или ранее с пропусками зависимостей) зафиксируйте и начните фазу 1. Максимум 4 вопроса, никогда не связывайте.

## Предполетная подготовка { #pre-flight }

Перед срабатыванием любой фазы:

1. **Вычислите временное окно** с помощью `scripts/time_window_calculator.py --window <Nd>`. Верните временную метку Unix для `created_at_i>` (HN) и the `t=` параметр (`hour|day|week|month|year|all`) для Reddit.
2. **Сгенерируйте выходной фрагмент** с помощью `scripts/topic_slug_generator.py --topic "<topic>" --date $(date +%Y-%m-%d)`. Обнаружить, если `${RESEARCH_DIR}/pulse/<slug>-<date>.md` уже существует; если да, добавьте `-v2` суффикс или предупреждение пользователя.
3. **Запустите журнал аудита по трем счетам** с помощью `scripts/citation_tracker.py --action start --session pulse-<date>-<slug>`. Этот файл находится по адресу `~/.pulse_sessions/<session>.json` сохраняется на протяжении всего прогона.

## Фаза 1: Reddit (параллельно с HN + Web) { #phase-1-reddit-parallel-with-hn--web }

**API:** `reddit.com/search.json` (не прошедший проверку подлинности, общедоступный JSON).

**Запросы (последовательные в Reddit, 1 вопрос/sec):**
1. `sort=top&t=<window>&q=<topic>` — верхние посты в окне
2. `sort=new&t=<window>&q=<topic>` — новые сообщения в окне (ловит сигнал о взломе)
3. Для каждого из 3-5 лучших постов по баллам: извлеките комментарии в формате JSON (`<post-url>.json?limit=top`) за 10-20 лучших комментариев.

** Заголовки / ограничения скорости.** Скорость Reddit - ограничения по IP, а не по плану. Дроссель до 1 q/sec. Если ответ имеет `X-Ratelimit-Remaining: 0` или возвращает 429, подождите 3 секунды, повторите попытку один раз. Если по-прежнему не удается, вернитесь к поиску с ограничением по субреддиту (`r/<topic-subreddit>/search.json`) или `?raw_json=1`.

**Записывайте каждый запрос:** `citation_tracker.py --action record_sent --session NAME --query "..."`.
**Запишите количество полученных сообщений:** `citation_tracker.py --action record_received --session NAME --count N`.

## Фаза 2: Хакерские новости (параллельно с Reddit + Web) { #phase-2-hacker-news-parallel-with-reddit--web }

**API:** Поиск по Algolia HN (`hn.algolia.com/api/v1/`).

**Запросы (последовательные в пределах HN, 1 q/sec):**
1. `search?query=<topic>&numericFilters=created_at_i><timestamp>&tags=story` — истории в окне
2. `search?query=<topic>&numericFilters=created_at_i><timestamp>&tags=comment` — комментарии в окне (улавливает сигнал обсуждения)

**Обработка сбоев.** Если HN возвращает пустое значение: расширьте запрос (удалите необычные существительные); если все еще пусто, в крайнем случае отбросьте фильтр временных меток и пометьте результаты как "за пределами окна".

** Примечание о предвзятости HN.** HN искажает технические данные / данные строителя. Обобщите это: "Голос HN ориентирован на реализацию; потребительские настроения здесь будут недостаточно представлены".

## Этап 3: Веб-поиск (параллельно с Reddit + HN) { #phase-3-web-search-parallel-with-reddit--hn }

** Инструменты:** Доступный веб-поиск + выборка (например,, `WebSearch` + `WebFetch`).

**Стратегия запроса (последовательный в Сети, 1 вопрос/sec):**
1. **Надежные издатели** — `"<topic>" site:nytimes.com OR site:wsj.com OR site:wired.com OR site:theverge.com OR site:techcrunch.com after:<date>`
2. **Последние ревью** — `"<topic>" review <year>` или `"<topic>" "honest review" after:<date>`
3. **Честные источники мнений** — `"<topic>" problems OR complaints OR "worth it" after:<date>`

Извлекайте 3-5 лучших URL-адресов по каждому запросу. Обрезать в теле, пропустить печенье/nav разметка.

**Дисциплина цитирования.** Каждое утверждение в веб-разделе должно быть прослежено до выбранного URL-адреса. НЕ цитируйте только по фрагментам; сначала извлеките.

## Фаза 4: X/Twitter (последовательный, необязательный) { #phase-4-xtwitter-sequential-optional }

Беги последним. Причины:
- Скорее всего, произойдет сбой / потребуется автоматизация браузера
- Контент X значительно перекрывается с Reddit / HN — таким образом, он добавляет дельту, а не основной сигнал

**Интерфейс (в порядке приоритета):**
1. **Грок** при наличии в ремне безопасности
2. **X API** при проверке подлинности
3. **Автоматизация браузера ** если жгут поддерживает это (Claude Code CLI с `playwright` или что-то подобное)
4. **Пропустить с примечанием**, если ничего из вышеперечисленного недоступно

**Документированное поведение:**
> Если этап 4 пропущен: включите заголовок раздела `## X/Twitter` с телом `Skipped — [reason: no browser automation / no Grok / no X API]`. Не притворяйтесь, что у вас есть данные.

## Синтез (Кроссплатформенные шаблоны) { #synthesis-cross-platform-patterns }

После завершения фаз 1-4 (или пропуска фазы 4) произведите синтез:

1. **Сигналы консенсуса** — точки, в которых согласны более 3 платформ (наивысшая степень достоверности). Пометьте каждый из них цитируемыми исходными URL-адресами.
2. **Сигналы разногласий** — точки, в которых платформы расходятся во мнениях. Обратите внимание, кто что говорит.
3. **Болевые точки** — повторяющиеся жалобы из разных источников (особенно. Reddit + Web).
4. ** Сигналы возбуждения** — повторяющийся энтузиазм (особенно. HN + X, если имеется).
5. ** Новые тенденции ** — первые упоминания в новых постах, но отсутствующие в старых (сравните `sort=new` против `sort=top`).
6. **Пробелы** — что заметно отсутствует из того, что вы ожидали бы найти.

Для каждого шаблона ** укажите исходные URL-адреса**, которые его поддерживают. Использование `citation_tracker.py --action record_cited --session NAME --url "..."` за цитату.

Видишь `references/cross_platform_synthesis.md` для эвристики обнаружения.

## Обработка ошибок { #error-handling }

| Неудача | Поведение |
|---|---|
| Тема слишком расплывчатая (Q1) | Отказываюсь начинать. Повторите вопрос 1 один раз с примерами. После 1-го отката сделайте сообщение с оговоркой "неопределенная тема". |
| Reddit блокирует / ограничивает скорость | Попробуй `?raw_json=1` или вернитесь к поиску с ограничением по субреддиту. Honor 3s - повторите попытку. |
| HN возвращает пустой | Расширьте запрос, в крайнем случае отбросьте фильтр временных меток, пометьте результаты как "за пределами окна". |
| Веб-поиск не возвращает ничего полезного | Примечание в выходных данных; не подделывайте исходные тексты. |
| Автоматизация браузера недоступна | Пропустите этап 4 с документированным примечанием. |
| Время ожидания веб-выборки истекло | Используйте то, что загружено, пометьте источник как "усеченный". |
| 3 последовательных сбоя в разных источниках | Остановись. Верните то, что было собрано, с явной пометкой "остановлено досрочно". Не доставляйте пустой файл. |
| Все источники терпят неудачу | Возвращает ошибку с диагностической информацией. Не доставляйте пустой файл. |

## Анти-Паттерны для отклонения { #anti-patterns-to-reject }

- Запуск любого поиска до того, как пользователь определит специфику темы (Q1)
- Группирование вопросов о приеме вместо того, чтобы задавать их по одному за раз
- Жестко закодированные URL-адреса, которые не выдержат изменений API (формат примечания, объяснение может измениться)
- Упоминания о конкретном человеке / бренде в своде данных о скиллах
- Тесная связь с одним интерфейсом X/Twitter
- Отсутствует резервное поведение при сбое источника
- "Просто используй [конкретный инструмент]" без объяснения того, что делает этот инструмент
- Цитирование учебных знаний в процитированном количестве
- Создание источников для заполнения раздела
